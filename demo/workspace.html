Workspace

Layout เต็มหน้าต่างสำหรับงานเดียวที่ต้องใช้พื้นที่ แถบบน แผงข้าง และพื้นที่ทำงานเลื่อนแยกกัน

เปิดเต็มหน้า Open full page

Workspace คือทั้งหน้า A workspace is the whole page

.workspace สูงเต็มหน้าต่าง (100dvh) ใช้แทน app shell (sidebar ของแอป) สำหรับงานเดียว เช่นแก้ธีม ลูกคือ <header> แถบบน: ปุ่มกลับ, <h1> ชื่องาน, ปุ่มควบคุม และปุ่มหลักไว้ท้ายสุด, <aside> แผงข้าง และ <main> พื้นที่ทำงาน ในหน้าเอกสารนี้กล่องตัวอย่างถูกจำกัดความสูงไว้ ดูของจริงได้ที่ เปิดเต็มหน้า Open full page

ธีมหน้าร้อน Summer theme

ตัวอักษร Typography เมนู Navigation หน้าแรก Homepage ท้ายเว็บ Footer

พื้นที่ทำงาน The work area

<div class="workspace">
  <header>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" popovertarget="ws-panel" aria-label="เปิดแผง Open the panel">
      <i class="icon icon-panel-left" aria-hidden="true"></i>
    </button>
    <a href="#" class="btn" data-size="icon" aria-label="กลับไปหน้าธีม Back to themes">
      <i class="icon icon-arrow-left" aria-hidden="true"></i>
    </a>
    <h1>ธีมหน้าร้อน Summer theme</h1>
    <button type="button" class="btn" data-size="sm">ดูตัวอย่าง Preview</button>
    <button type="button" class="btn" data-variant="primary" data-size="sm">บันทึก Save</button>
  </header>
  <aside id="ws-panel" popover aria-label="ส่วนของหน้า Sections">
    <nav class="subnav" aria-label="ส่วนของหน้า Sections">
      <a href="#" aria-current="page">ตัวอักษร Typography</a>
      <a href="#">เมนู Navigation</a>
      <a href="#">หน้าแรก Homepage</a>
      <a href="#">ท้ายเว็บ Footer</a>
    </nav>
  </aside>
  <main>
    <p>พื้นที่ทำงาน The work area</p>
  </main>
</div>

แผงกว้าง data-panel="wide" A wide panel

แผงข้างกว้าง 20rem เป็นค่าเริ่มต้น data-panel="wide" ทำให้กว้าง 24rem สำหรับแผงที่มีฟอร์มหรือรายการยาว

ธีมหน้าร้อน Summer theme

แผงกว้าง 24rem A panel 24rem wide

พื้นที่ทำงาน The work area

<div class="workspace" data-panel="wide">
  <header>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" popovertarget="ws-wide-panel" aria-label="เปิดแผง Open the panel">
      <i class="icon icon-panel-left" aria-hidden="true"></i>
    </button>
    <h1>ธีมหน้าร้อน Summer theme</h1>
    <button type="button" class="btn" data-variant="primary" data-size="sm">บันทึก Save</button>
  </header>
  <aside id="ws-wide-panel" popover aria-label="ตั้งค่า Settings">
    <p>แผงกว้าง 24rem A panel 24rem wide</p>
  </aside>
  <main>
    <p>พื้นที่ทำงาน The work area</p>
  </main>
</div>

แผงท้าย: aside หลัง main An aside after the main is the end panel

<aside> ที่อยู่หลัง <main> คือแผงท้าย กว้างเท่าแผงต้น เส้นอยู่อีกฝั่ง workspace มีแผงต้น แผงท้าย หรือทั้งสองก็ได้ เช่นรายการหน้าทางซ้ายและแชตทางขวา

แคมเปญหน้าร้อน Summer campaign

แผงต้น The panel at the start

พื้นที่ทำงาน The work area

แผงท้าย The end panel

<div class="workspace">
  <header>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" popovertarget="ws-end-start" aria-label="เปิดรายการหน้า Open the pages">
      <i class="icon icon-panel-left" aria-hidden="true"></i>
    </button>
    <h1>แคมเปญหน้าร้อน Summer campaign</h1>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" popovertarget="ws-end-end" aria-label="เปิดแชต Open the chat">
      <i class="icon icon-panel-right" aria-hidden="true"></i>
    </button>
  </header>
  <aside id="ws-end-start" popover aria-label="หน้า Pages">
    <p>แผงต้น The panel at the start</p>
  </aside>
  <main>
    <p>พื้นที่ทำงาน The work area</p>
  </main>
  <aside id="ws-end-end" popover aria-label="แชต Chat">
    <p>แผงท้าย The end panel</p>
  </aside>
</div>

แผงท้ายอย่างเดียว Only an end panel

ไม่มีแผงต้นก็ได้: <main> ตามด้วย <aside> เช่นรายละเอียดคำสั่งซื้อพร้อมแผงลูกค้าทางขวา

คำสั่งซื้อ #1042 Order

รายการสินค้า 3 ชิ้น รวม ฿2,450.00

สมหญิง รักดี · somying@example.com

<div class="workspace">
  <header>
    <h1>คำสั่งซื้อ #1042 Order</h1>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" popovertarget="ws-only-end" aria-label="เปิดข้อมูลลูกค้า Open the customer">
      <i class="icon icon-panel-right" aria-hidden="true"></i>
    </button>
  </header>
  <main>
    <p>รายการสินค้า 3 ชิ้น รวม ฿2,450.00</p>
  </main>
  <aside id="ws-only-end" popover aria-label="ลูกค้า Customer">
    <p>สมหญิง รักดี · somying@example.com</p>
  </aside>
</div>

ต่ำกว่า 768px ปุ่มในแถบบนเปิดแผง Below 768px a button in the bar opens the panel

แผงข้างใส่ popover และ id ปุ่มในแถบบนที่มี popovertarget ชี้ไปที่ id นั้นจะเปิดแผงทับพื้นที่ทำงาน กด Esc หรือคลิกข้างนอกเพื่อปิด แผงท้ายเปิดจากขอบขวา ตั้งแต่ 768px ขึ้นไปแผงเป็นคอลัมน์ปกติและปุ่มที่มี popovertarget ในแถบบนจะซ่อนเอง ไม่ต้องใช้ JS ลองย่อหน้าต่างในตัวอย่างด้านบนหรือ หน้าเต็ม

Attributes

Attribute / element Values Description
.workspace layout เต็มหน้าต่าง (100dvh) ใช้เป็นลูกของ body โดยตรง
data-panel wide; ไม่ใส่ = 20rem (ค่าเริ่มต้น) แผงข้างกว้าง 24rem
> header แถบบนเต็มความกว้าง เรียงลูกเป็นแถว
header > h1 ชื่องาน ดันปุ่มที่ตามมาไปชิดขวา ตัดด้วย … เมื่อยาวเกิน
header [popovertarget] id ของแผง ปุ่มเปิดแผงบนจอแคบ ซ่อนเองตั้งแต่ 768px
> aside (ก่อน main) แผงต้น เส้นทางขวา เลื่อนแยก
> main พื้นที่ทำงาน เลื่อนแยก
> main ~ aside แผงท้าย เส้นทางซ้าย บนจอแคบเปิดจากขอบขวา
aside[popover], id ต่ำกว่า 768px แผงซ่อนและเปิดเป็น popover ทับพื้นที่ทำงาน (มี backdrop) ตั้งแต่ 768px เป็นคอลัมน์ ใส่ aria-label ตั้งชื่อแผง
