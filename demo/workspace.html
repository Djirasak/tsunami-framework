Workspace

Layout เต็มหน้าต่างสำหรับงานเดียว แผงข้างและพื้นที่ทำงานเลื่อนแยกกัน บนจอแคบแผงข้างเปิดเป็น overlay

แก้ไขธีม Theme editor
หัวเว็บ Header สินค้า Products ท้ายเว็บ Footer

พื้นที่ทำงาน Work area

<div class="workspace">
  <header>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" popovertarget="ws-panel" aria-label="เปิดแผง Open panel"><i class="icon icon-menu" aria-hidden="true"></i></button>
    <strong>แก้ไขธีม Theme editor</strong>
  </header>
  <aside id="ws-panel" popover aria-label="Sections">
    <nav class="subnav" aria-label="Sections">
      <a href="#" aria-current="page">หัวเว็บ Header</a>
      <a href="#">สินค้า Products</a>
      <a href="#">ท้ายเว็บ Footer</a>
    </nav>
  </aside>
  <main>
    <p>พื้นที่ทำงาน Work area</p>
  </main>
</div>

Attributes

Attribute / element Values Description
data-panel wide แผงกว้าง 24rem (ค่าเริ่มต้น 20rem)
> aside[popover][id] แผงข้าง ถ้าวางหลัง main จะเป็นแผงขวา
> header [popovertarget] ปุ่มเปิดแผงบนจอแคบ ซ่อนเองตั้งแต่ 48rem
