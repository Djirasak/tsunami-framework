ประกันการจัดส่ง Shipping protection

คุ้มครองคำสั่งซื้อที่สูญหาย ถูกขโมย หรือเสียหายระหว่างทางไปหาลูกค้า

ทำงานอย่างไร How it works

ลูกค้าเพิ่มประกันตอน checkout ราคา ฿39 ถ้าพัสดุไม่ถึง ลูกค้าเปิดเคลมได้จากหน้าสถานะคำสั่งซื้อ แล้วเลือกคืนเงินหรือส่งใหม่

คุ้มครองอะไรบ้าง What is covered

  • พัสดุที่ขึ้นว่าส่งแล้วแต่ไม่ถึงมือ
  • สินค้าเสียหายระหว่างขนส่ง
  • พัสดุที่ขนส่งทำหาย

เปิดเคลมได้ภายใน 30 วันหลังวันจัดส่ง

ตั้งค่า Setting it up

  1. เปิด ตั้งค่า Settings แล้วไปที่ การจัดส่ง Shipping
  2. เปิดประกันและกำหนดราคา
  3. บันทึก ระบบจะสร้างสินค้า shipping-protection ให้

Attributes

Attribute / element Values Description
.prose class กล่องครอบเนื้อหายาว ให้ระยะห่างระหว่าง block, heading h1-h6, list marker, quote, pre, hr
p[data-variant] lead, muted (ไม่ใส่ = ปกติ default) lead: 16px สีเทา, muted: สีเทา ใช้ใน .prose
small 12px สีเทา ใน .prose
ul, ol, li marker disc / circle (ซ้อน) / decimal สี --muted
dl > dt, dd สองคอลัมน์: dt ป้ายสีเทา, dd ค่า
blockquote เส้นซ้าย 2px --line ข้อความสีเทา
pre > code บล็อกโค้ด พื้น --subtle เลื่อนแนวนอนได้
code, mark, del, ins, abbr[title], sub, sup, a, strong รูปแบบในบรรทัดใน .prose (ลิงก์ขีดเส้นใต้, mark พื้น --warning-bg)
hr เส้น 1px --line ระยะ 24px บนล่างใน .prose
