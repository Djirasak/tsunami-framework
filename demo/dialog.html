Dialog

<dialog> แบบ native เปิดด้วย commandfor ไม่ต้องใช้ JS

ลบสินค้านี้? Delete this product?

สินค้าและประวัติสต็อกจะถูกลบถาวร The product and its stock history are removed permanently. 

<button type="button" class="btn" commandfor="dlg-delete" command="show-modal">ลบสินค้า Delete product</button>
<dialog class="dialog" id="dlg-delete" aria-labelledby="dlg-delete-title" closedby="any">
  <header>
    <h2 id="dlg-delete-title">ลบสินค้านี้? Delete this product?</h2>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" commandfor="dlg-delete" command="close" aria-label="ปิด Close"><i class="icon icon-x" aria-hidden="true"></i></button>
  </header>
  <div>
    <p>สินค้าและประวัติสต็อกจะถูกลบถาวร The product and its stock history are removed permanently.</p>
  </div>
  <footer>
    <button type="button" class="btn" commandfor="dlg-delete" command="close">ยกเลิก Cancel</button>
    <button type="button" class="btn" data-variant="danger" commandfor="dlg-delete" command="close">ลบ Delete</button>
  </footer>
</dialog>

Attributes

Attribute / element Values Description
commandfor + command show-modal, close บนปุ่ม เปิดหรือปิด dialog
closedby any ปิดด้วย Esc หรือคลิกนอกกรอบ
> header / > div / > footer ส่วนต่างๆ คั่นด้วยเส้น
