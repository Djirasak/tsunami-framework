Empty

สถานะว่างเมื่อยังไม่มีข้อมูล: ไอคอน หัวข้อ คำอธิบาย ปุ่มเริ่มต้น และลิงก์อ่านเพิ่ม

การใช้งาน Usage

<header> มี figure ไอคอน หัวข้อและคำอธิบาย <footer> มีแถวปุ่มแล้วตามด้วยลิงก์

ยังไม่มีสินค้า No products yet

คุณยังไม่ได้เพิ่มสินค้า เริ่มด้วยการสร้างสินค้าชิ้นแรกหรือนำเข้าจากไฟล์ CSV

อ่านเพิ่ม Learn more 
<section class="empty">
  <header>
    <figure><i class="icon icon-package" aria-hidden="true"></i></figure>
    <h3>ยังไม่มีสินค้า No products yet</h3>
    <p>คุณยังไม่ได้เพิ่มสินค้า เริ่มด้วยการสร้างสินค้าชิ้นแรกหรือนำเข้าจากไฟล์ CSV</p>
  </header>
  <footer>
    <div>
      <button type="button" class="btn" data-variant="primary">เพิ่มสินค้า Add product</button>
      <button type="button" class="btn">นำเข้า Import</button>
    </div>
    <a href="#" class="link" data-variant="muted">อ่านเพิ่ม Learn more<i class="icon icon-arrow-up-right" aria-hidden="true"></i></a>
  </footer>
</section>

Attributes

Attribute / element Values Description
.empty กล่องกึ่งกลาง ระยะ 32px บนล่าง ใช้กับ <section> หรือ <div>
> header กลุ่มไอคอน หัวข้อ และคำอธิบาย
figure กรอบไอคอน 40px พื้น subtle ใส่ .icon ข้างใน
h3 หัวข้อ 16px ตัวหนา
p คำอธิบายสีจาง กว้างไม่เกิน 28rem
> footer ไม่บังคับ ปุ่มและลิงก์เรียงตามแนวตั้ง
> footer > div แถวปุ่ม ตัดบรรทัดได้ ปุ่มหลักใช้ data-variant="primary"
> footer > a.link data-variant="muted" ลิงก์อ่านเพิ่มสีจาง ใต้แถวปุ่ม
