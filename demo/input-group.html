Input group

กล่องเดียวที่มี input พร้อมข้อความหรือไอคอนด้านหน้าและท้าย หน้าตาเดียวกับ Input

ไอคอนและจำนวนผลลัพธ์ Icon and a result count

<span> ก่อน input อยู่ด้านหน้า หลัง input อยู่ท้าย ไอคอนใส่ aria-hidden และ input ต้องมี aria-label หรือ label

12 รายการ 
<div class="stack docs-narrow">
  <div class="input-group">
    <span><i class="icon icon-search" aria-hidden="true"></i></span>
    <input type="search" placeholder="ค้นหาคำสั่งซื้อ Search orders" aria-label="ค้นหาคำสั่งซื้อ Search orders" />
    <span>12 รายการ</span>
  </div>
</div>

aria-invalid และ disabled ใส่ที่ input กล่องจะเปลี่ยนตามเอง

%
ไม่เกิน 100% Must be 100% or less

Attributes

Attribute / element Values Description
.input-group กล่องที่มีกรอบ ห่อ input หนึ่งตัวกับ span ด้านหน้า/ท้าย
.input-group > input ช่องไม่มีกรอบ ขยายเต็มที่เหลือ ต้องมี label หรือ aria-label
.input-group > span ข้อความหรือไอคอนสีเทา ตำแหน่งตามลำดับใน HTML (ก่อน input = หน้า, หลัง = ท้าย)
data-size sm, lg (ไม่มี = default 32px) ความสูงเท่ากับ .input / .btn
data-variant ghost (ไม่มี = มีกรอบ) ไม่มีกรอบและพื้น ใช้ในหัวการ์ดหรือ toolbar
aria-invalid true บน input: กรอบกล่องเป็นสี danger
disabled บน input: พื้นกล่องเป็น subtle
aria-hidden true บนไอคอนตกแต่งใน span
