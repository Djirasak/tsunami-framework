Colors

Semantic tokens เป็น CSS custom properties ที่เปลี่ยนค่าเองตามธีม component อ้างอิงเฉพาะ token เหล่านี้

ค่าสว่างและมืดในหน้านี้เป็นค่าคงที่ Light and dark columns are static

Token อยู่บน :root เท่านั้น data-theme ใส่ได้ที่ <html> ไม่ใช่ element ย่อย แถบสีสองคอลัมน์จึงวาดจากค่า hex ของทั้งสองธีมเพื่อเทียบกัน ส่วน Preview ทุกอันใช้ธีมปัจจุบัน

สถานะ Status

แต่ละสถานะเป็นคู่ -bg กับ -fg ใช้คู่กันเป็นพื้นอ่อนกับข้อความเข้ม (badge, alert) หรือใช้ -fg อย่างเดียวกับข้อความ ไอคอน และแถบ progress Each status is a soft fill and a dark text pair.

กราฟ Charts

tsunami ไม่มี token สำหรับชุดสีกราฟ และไม่มี component กราฟ ถ้าต้องการแท่งเทียบค่าง่าย ๆ ใช้ progress กับสี --fg และ -fg ของสถานะ กราฟเต็มรูปแบบอยู่นอกขอบเขต Charts are out of scope; status -fg tokens can colour simple bars.
