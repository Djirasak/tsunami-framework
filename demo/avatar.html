Attributes

Attribute / element Values Description
.avatar span กรอบ avatar มุมมน ตัวอักษรย่อสีเทา
img child รูปคนหรือโลโก้ อยู่ทับตัวอักษรย่อ พื้นขาวเสมอ ใส่ alt เป็นชื่อ
span child ตัวอักษรย่อหรือไอคอน แสดงเมื่อไม่มีรูป
data-size sm 24px · ไม่ใส่ (default) 32px · lg 40px ขนาด
data-variant ไม่ใส่ (default) มุมมน · circle วงกลม สำหรับรูปคน
span[data-count] ตัวเลข ใน .avatar: จำนวนที่มุมขวาบน เช่น จำนวนชิ้น
span[data-status] ok · warning · danger · info · ว่าง (default) เทา จุดสถานะที่มุมขวาล่าง ต้องมี role="img" + aria-label
.avatar-group div avatar ซ้อนกัน มีขอบสีพื้นหลังคั่น
.avatar-group > [data-count] ข้อความ เช่น +4 จำนวนที่เหลือ ต่อท้ายกลุ่ม
