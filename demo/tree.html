API

อยู่ใน js/tree.js tree ที่ไม่มีช่องค้นหาไม่ต้องใช้ JS ไม่มี event ของตัวเอง details ส่ง toggle ของ browser

Function Arguments Description
tsunami.tree.filter(tree, query) tree: element .tree, query: string แสดงเฉพาะไฟล์ที่ชื่อมี query (ไม่สนตัวพิมพ์เล็กใหญ่) ซ่อนโฟลเดอร์ที่ไม่มีไฟล์ตรง เปิดโฟลเดอร์ที่มี ค่าว่างแสดงทุกไฟล์และคืนสถานะโฟลเดอร์เดิม
input[type="search"] ใน .tree พิมพ์แล้วเรียก filter() ให้เอง
Tab / Enter / Space คีย์บอร์ด ของ browser เอง: ไปทีละโฟลเดอร์/ไฟล์ เปิดปิดโฟลเดอร์ เปิดลิงก์

Attributes

Attribute / element Values Description
.tree nav ใส่ aria-label (ul.tree ก็ได้)
ul > li child แต่ละรายการ ul ที่ซ้อนใน li ย่อหน้าบนเส้นนำ
details > summary ใน li โฟลเดอร์ มีลูกศรหมุนเมื่อเปิด ตามด้วย ul ของไฟล์
open บน details โฟลเดอร์เปิดอยู่ (ของ browser)
a / span ใน li ไฟล์ (ลิงก์) หรือรายการที่ไม่ใช่ลิงก์ ชื่อใน span ตัดด้วย … เมื่อยาว
.icon ใน summary / a ไม่บังคับ เช่น icon-folder, icon-file
aria-current page บนลิงก์: ไฟล์ที่เปิดอยู่
input[type="search"] ลูกตรงของ .tree ช่องค้นหา กรองขณะพิมพ์
p ลูกตรงของ .tree ข้อความเมื่อไม่พบไฟล์ ใส่ hidden ไว้ JS เปิด/ปิดให้
hidden บน li JS ใส่ให้ไฟล์/โฟลเดอร์ที่ไม่ตรงการค้นหา
