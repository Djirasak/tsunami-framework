tsunami 津波

CSS framework ขนาดเล็กสำหรับหน้าจอหลังบ้าน เงียบ แน่น และใช้งานได้จริง เขียนด้วย semantic HTML กับ data attributes ไม่มี dependency ตอนรันจริง

เริ่มใช้งาน Get started ดู components

หลักการ Principles

Native first

ใช้ dialog, popover, details และ button ก่อนเสมอ JS มีแค่ theme, tabs และ save bar

Zero specificity

ทุก selector อยู่ใน @layer components และ :where() CSS ของคุณจึง override ได้ทันที

Light / Dark

สลับธีมผ่าน CSS custom properties ตามระบบหรือตามที่เลือก และไม่กะพริบตอนโหลด

ไทย + Latin

Google Sans ตัวเดียวทั้งไทยและ Latin แบบ self-hosted woff2 ตัวเลขในตารางเป็น tabular-nums

ติดตั้ง Install

ใส่ไฟล์จาก dist/ และสคริปต์ใน <head> เพื่อกันธีมกะพริบ 

<link rel="stylesheet" href="dist/tsunami.min.css">
<script>
  try {
    const t = localStorage.getItem("tsunami-theme");
    if (t) document.documentElement.dataset.theme = t;
  } catch {}
</script>
<script type="module" src="dist/tsunami.min.js"></script>
