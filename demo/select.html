Select

เลือกจากรายการ native select และแบบมีรายการที่จัดรูปแบบเอง โดย select จริงยังเป็นตัวส่งค่า

ขนาด Sizes: sm, default และ lg

select แบบ native ใส่ class select อย่างเดียว ไม่ต้องใช้สคริปต์ ความสูงเท่ากับปุ่ม .btn ขนาดเดียวกัน 

<div class="stack" data-direction="row" data-gap="sm">
  <select class="select" data-size="sm" aria-label="ขนาดเล็ก Small">
    <option>เล็ก Small</option>
    <option>กลาง Medium</option>
  </select>
  <button type="button" class="btn" data-size="sm">ปุ่ม sm</button>
</div>
<div class="stack" data-direction="row" data-gap="sm">
  <select class="select" aria-label="ขนาดปกติ Default">
    <option>ปกติ Default</option>
    <option>กลาง Medium</option>
  </select>
  <button type="button" class="btn">ปุ่ม default</button>
</div>
<div class="stack" data-direction="row" data-gap="sm">
  <select class="select" data-size="lg" aria-label="ขนาดใหญ่ Large">
    <option>ใหญ่ Large</option>
    <option>กลาง Medium</option>
  </select>
  <button type="button" class="btn" data-size="lg">ปุ่ม lg</button>
</div>

Select แบบรายการจัดรูปแบบ Select with a styled list

ห่อ <select> จริงด้วย <div class="select"> สคริปต์จะวาดปุ่มและรายการให้ และเลือกตัวเลือกใน select เดิมตาม ฟอร์มจึงส่งค่าได้ตามปกติ ถ้าไม่มีสคริปต์จะเห็น select แบบ native ตัวเลือก value="" ที่มี hidden คือข้อความตอนยังไม่ได้เลือก 

<div class="select" style="width: 180px">
  <select name="theme" aria-label="ธีม Theme">
    <option value="" hidden>ธีม Theme</option>
    <option value="light">สว่าง Light</option>
    <option value="dark">มืด Dark</option>
    <option value="system">ตามระบบ System</option>
  </select>
</div>

พิมพ์ค่าเดียวในช่อง พร้อมปุ่มบนรายการ One choice typed in the control, with an action above the list

data-input ทำให้ช่องควบคุมเป็นช่องพิมพ์สำหรับค่าเดียว <header> ใน wrapper ถูกย้ายไปไว้บนรายการ (ไม่มีสคริปต์จะอยู่เหนือ select)

ตัวเลือกจากเซิร์ฟเวอร์ Remote options: data-url loads the options from the server

data-url บน wrapper คือที่อยู่สำหรับค้นหา ตัวเลือกที่ได้จะถูกใส่เป็น <option> ใน select จริง จึงส่งฟอร์มได้ตามปกติ ถ้าไม่มีช่องพิมพ์ สคริปต์จะเพิ่มช่องค้นหาในรายการให้

คำขอแต่ละครั้งส่ง q (ข้อความที่พิมพ์ ไม่ส่งถ้าว่าง) และ page (เริ่มที่ 1) ถ้า URL มี {page} จะถูกแทนด้วยเลขหน้าด้วย จึงใช้ไฟล์ JSON แบบ static ได้ เช่น data/countries-{page}.json 

GET data/countries-{page}.json?q=fra&page=1

{
  "results": [{ "id": "fr", "text": "France ฝรั่งเศส" }],
  "pagination": { "more": false }
}

หน้าเว็บกรองผลลัพธ์ซ้ำด้วยข้อความ (มีคำที่พิมพ์อยู่ใน text) เซิร์ฟเวอร์ที่ไม่สนใจ q อย่างไฟล์ static ก็ยังได้รายการที่ถูกต้อง เซิร์ฟเวอร์จริงควรตอบเฉพาะรายการที่ text มีคำนั้น

หลายค่าจากเซิร์ฟเวอร์ เริ่มด้วย France Remote options with several choices: France is the starting choice, written into the page

ค่าเริ่มต้นเขียนไว้ในหน้าเป็น <option selected> ไม่มีคำขอจนกว่าจะเปิดรายการ 

<div class="select" data-url="data/countries.json" data-placeholder="เลือกประเทศ Select countries" style="width: 100%; max-width: 320px">
  <select name="countries" multiple aria-label="ประเทศ Countries">
    <option value="fr" selected>France ฝรั่งเศส</option>
  </select>
</div>

ค่าเดียวจากเซิร์ฟเวอร์ เลื่อนจนสุดเพื่อโหลดหน้าถัดไป Remote options with one choice: scroll to the end and the next page loads

select ค่าเดียวต้องมี <option value=""> ไว้เป็นค่าว่าง เมื่อตอบกลับมี "more": true และเลื่อนรายการใกล้สุด (50px) จะขอหน้าถัดไป 

<div class="select" data-url="data/countries-{page}.json" data-search="ค้นหาประเทศ Search countries" style="width: 100%; max-width: 320px">
  <select name="country" aria-label="ประเทศ Country">
    <option value="" hidden>เลือกประเทศ Select a country</option>
  </select>
</div>

ตัวเลือกจากเซิร์ฟเวอร์ทำงานอย่างไร What a select with remote options does, case by case

เมื่อ When สิ่งที่เกิดขึ้น What happens
โหลดหน้า The page loads ไม่มีคำขอ ตัวเลือกที่เขียนในหน้าเป็นค่าเริ่มต้น No request; options in the markup are the starting choice.
เปิดรายการ The list opens ขอหน้า 1 โดยไม่มี q รายการขึ้น Searching… จนกว่าจะได้คำตอบ One request for page 1.
พิมพ์ A key is typed ยกเลิกคำขอเดิม (AbortController) แล้วส่งใหม่พร้อม q และ page=1 ระหว่างรอ รายการที่มีอยู่ถูกกรองบนหน้าทันที
คำตอบเก่ามาหลังคำตอบใหม่ An older reply arrives late ไม่สนใจ เพราะคำขอนั้นถูกยกเลิกแล้ว
คำตอบมี "more": true listbox ได้ data-more และมีบรรทัด Loading more… ใต้รายการ
เลื่อนรายการใกล้สุด 50px Scrolled near the end ขอหน้าถัดไปด้วย q เดิม ต่อท้ายรายการ ไม่ขอซ้ำระหว่างรอ (aria-busy) ถ้ารายการยังสั้นจนเลื่อนไม่ได้ จะขอหน้าถัดไปเอง
ไม่มีผลลัพธ์ No results แสดง No results หรือข้อความใน data-empty
คำขอล้มเหลวหรือไม่ใช่ JSON The request fails ล้างรายการ listbox ได้ data-error แสดงข้อความผิดพลาด และเขียน error ลง console พิมพ์ครั้งต่อไปจะลองใหม่
เลือกตัวเลือก An option is chosen เหมือน select ทั่วไป: option ใน select จริงถูกเลือก ส่ง input/change และ tsunami:select:change แบบหลายค่าจะล้างช่องพิมพ์และขอหน้า 1 ใหม่
ค่าที่เลือกไม่อยู่ในคำตอบ A chosen option is not in the reply ยังอยู่ใน select จริงแบบ hidden จึงยังถูกเลือกและถูกส่งกับฟอร์ม แต่ไม่แสดงในรายการ
ค่าที่เลือกอยู่ในคำตอบ A chosen option is in the reply แสดงครั้งเดียว ตามลำดับของเซิร์ฟเวอร์ พร้อมเครื่องหมายถูก
ปิดรายการ The list closes ยกเลิกคำขอที่ค้าง ล้างช่องค้นหา เปิดใหม่จะขอใหม่ ไม่มี cache

แท็ก Tags: data-tags lets the user create an option by typing it

data-tags เสนอข้อความที่พิมพ์เป็นตัวเลือกใหม่ (ค่าคือข้อความนั้น) พิมพ์คำที่ไม่มีในรายการแล้วกด Enter ตัวเลือกที่สร้างจะเป็น <option data-tag> ใน select จริง 

<div class="select" data-tags data-placeholder="เพิ่มแท็ก Add tags" style="width: 100%; max-width: 320px">
  <select name="tags" multiple aria-label="แท็ก Tags">
    <option value="summer" selected>summer</option>
    <option value="sale">sale</option>
    <option value="new-arrival">new-arrival</option>
  </select>
</div>

แท็กกับตัวเลือกจากเซิร์ฟเวอร์ Tags with remote options: choose a country from the server or create a new name 

<div class="select" data-url="data/countries.json" data-tags data-placeholder="เลือกหรือพิมพ์ประเทศ Country or new name" style="width: 100%; max-width: 320px">
  <select name="origin" multiple aria-label="แหล่งผลิต Origin"></select>
</div>

แท็กทำงานอย่างไร What a select with tags does, case by case

เมื่อ When สิ่งที่เกิดขึ้น What happens
พิมพ์ข้อความที่ไม่ตรงกับตัวเลือกใด Text names no option ข้อความถูกเสนอเป็นตัวเลือกแรก (ไอคอนบวก) และเป็นตัวที่ active Enter จึงสร้างได้ทันที
พิมพ์ตรงกับตัวเลือก ไม่สนตัวพิมพ์ Text names an option, any case ไม่เสนอแท็ก "SALE" เจอ "sale"
มีแต่ช่องว่าง Only spaces ไม่เสนอแท็ก ช่องว่างหน้าหลังถูกตัดออก
เลือกแท็กที่เสนอ The offered tag is chosen สร้าง <option data-tag selected> ใน select จริง ค่าและป้ายคือข้อความที่พิมพ์
ข้อความเปลี่ยนก่อนเลือก The text changes first แท็กที่เสนอเดิมหายไป และเสนอข้อความใหม่แทน
ลบแท็กที่สร้างไว้ A created tag is removed ยังอยู่ในรายการจนกว่าจะพิมพ์ครั้งถัดไป แล้วจึงถูกลบจาก select
มี data-url ด้วย แท็กแสดงเหนือผลลัพธ์จากเซิร์ฟเวอร์ ยกเว้นมีผลลัพธ์ชื่อเดียวกัน (เมื่อคำตอบมาถึง)

API

ทุกฟังก์ชันรับ element ใดก็ได้ใน wrapper (หรือ wrapper เอง) เป็นอาร์กิวเมนต์แรก select แบบ native ที่ใช้แค่ class select ไม่มี API นี้

Function Arguments Description
tsunami.select.open(el) el: Element เปิดรายการ (ไม่ทำอะไรถ้า select ถูก disabled)
tsunami.select.close(el, focus) el: Element, focus: boolean (default false) ปิดรายการ ถ้า focus เป็นจริงจะย้ายโฟกัสกลับช่องควบคุม
tsunami.select.value(el) el: Element คืนค่า: string สำหรับค่าเดียว, array ของ string สำหรับ multiple
tsunami.select.value(el, v) v: string หรือ string[] เลือกตัวเลือกที่มีอยู่ใน select ตามค่า ส่ง event เมื่อค่าเปลี่ยน
tsunami.select.refresh(el) el: Element วาดช่องควบคุมใหม่หลังจากเพิ่ม/ลบ/แก้ option ด้วยโค้ด (การ dispatch change บน select ก็วาดใหม่เช่นกัน)
Event On Detail
tsunami:select:change wrapper, bubbles { value, selected: [{ value, label }] } ส่งเมื่อค่าเปลี่ยนจากคลิก คีย์บอร์ด หรือ value() ไม่ส่งเมื่อเลือกค่าเดิมซ้ำ
input, change select จริง, bubbles ส่งพร้อมกัน ฟอร์มและ Save bar จึงทำงานเหมือนผู้ใช้เลือกใน select เอง
tsunami:select:open wrapper, bubbles ไม่มี detail ส่งเมื่อรายการเปิด
tsunami:select:close wrapper, bubbles ไม่มี detail ส่งเมื่อรายการปิด
Key Description
↓ ↑ ช่องที่ปิดอยู่: เปิดรายการ ในรายการ: เลื่อนตัวเลือกที่ active
Home End ไปตัวเลือกแรก/สุดท้าย (บนปุ่ม) ในช่องพิมพ์จะเลื่อนเคอร์เซอร์ตามปกติ
Enter, Space บนปุ่มที่ปิด: เปิด ในรายการ: เลือกตัวที่ active (Space ใช้ได้บนปุ่มเท่านั้น)
ตัวอักษร Letters บนปุ่ม: เปิดรายการและไปตัวเลือกที่ขึ้นต้นด้วยตัวที่พิมพ์ (type-ahead) ถ้ามีช่องค้นหา ตัวอักษรจะไปอยู่ในช่องค้นหา
Backspace หลายค่า ช่องพิมพ์ว่าง: ลบชิปตัวสุดท้าย
Escape ปิดรายการและคืนโฟกัสให้ช่องควบคุม
Tab ออกจากช่องและปิดรายการ

Attributes

Attribute / element Values Description
select.select select แบบ native จัดรูปแบบ ไม่ต้องใช้สคริปต์
div.select wrapper ของ <select> ลูกโดยตรง สคริปต์วาดช่องควบคุมและรายการ ไม่มีสคริปต์จะแสดง select เดิม
data-size sm, lg (ไม่ใส่ = default 2rem) ความสูง ใช้ได้ทั้งบน select.select และ div.select
data-placeholder ข้อความ (default: ข้อความของ option[value=""]) ข้อความตอนยังไม่ได้เลือก ใช้เป็น placeholder ของช่องพิมพ์ด้วย
data-search มี/ไม่มี, ค่าเป็น placeholder (default "ค้นหา Search") เพิ่มช่องค้นหาบนรายการ (ช่องควบคุมแบบปุ่ม)
data-input มี/ไม่มี (default ไม่มี) ช่องควบคุมเป็นช่องพิมพ์สำหรับค่าเดียว multiple ใช้ช่องพิมพ์เสมอ
data-tags มี/ไม่มี (default ไม่มี) เสนอข้อความที่พิมพ์เป็นตัวเลือกใหม่
data-url URL, รองรับ {page} ที่อยู่สำหรับโหลดตัวเลือก JSON ด้วย ?q=&page= ต้องมีช่องพิมพ์ (เพิ่มให้อัตโนมัติ)
data-empty ข้อความ (default "ไม่พบผลลัพธ์ No results") ข้อความเมื่อค้นหาไม่พบ
<header> ใน wrapper ย้ายไปไว้บนรายการ สำหรับปุ่มคำสั่ง เช่น สร้างลูกค้าใหม่
<select multiple> เลือกหลายค่า ช่องควบคุมเป็นชิปและช่องพิมพ์ listbox มี aria-multiselectable
<optgroup label> กลุ่มที่มีหัวข้อ (role="group" + <strong>)
option[value=""] ใส่ hidden เพื่อไม่ให้อยู่ในรายการ ค่าว่าง = ยังไม่ได้เลือก จำเป็นสำหรับ select ค่าเดียวที่ใช้ data-url
option[selected] ค่าเริ่มต้น
option[disabled] เลือกไม่ได้ แสดงจางพร้อม aria-disabled="true"
option[hidden] ไม่แสดงในรายการ แต่ยังถูกเลือกและส่งค่าได้
option[data-label] ข้อความ (default: ข้อความของ option) ชื่อที่แสดงบนปุ่ม/ชิป และใช้ค้นหา
option[data-text] ข้อความ บรรทัดคำอธิบายใต้หัวเรื่อง ค้นหาได้
option[data-avatar] ตัวย่อ หรือ URL รูป อวาตาร์ขนาด sm หน้าตัวเลือก
option[data-badge] ข้อความ badge ท้ายหัวเรื่อง
option[data-tag] ตั้งโดยสคริปต์ ตัวเลือกที่สร้างจากข้อความที่พิมพ์ (data-tags)
data-ready ตั้งโดยสคริปต์ บน wrapper เมื่อวาดช่องควบคุมแล้ว select จริงถูกซ่อนแบบมองไม่เห็น (ยังส่งค่าและ validate ได้)
data-has-value ตั้งโดยสคริปต์ บน wrapper ขณะมีค่าที่เลือก
role="combobox" ตั้งโดยสคริปต์ ปุ่มหรือช่องพิมพ์ มี aria-expanded, aria-controls, aria-activedescendant ป้ายมาจาก <label for> หรือ aria-label ของ select
[popover] > role="listbox" ตั้งโดยสคริปต์ รายการแบบ popover="manual" วางใต้ช่องควบคุม (กลับขึ้นบนถ้าที่ไม่พอ) role="option" มี aria-selected และ data-active
aria-busy, data-more, data-error ตั้งโดยสคริปต์ บน listbox เมื่อใช้ data-url: กำลังโหลด, มีหน้าถัดไป, โหลดล้มเหลว
