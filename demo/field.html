Field

Label, control และคำแนะนำ ใช้กับ input, select, textarea และ checkbox

แสดงบนใบเสร็จ Shown on receipts
รูปแบบอีเมลไม่ถูกต้อง Invalid email 
<form class="stack docs-narrow">
  <div class="field">
    <label for="f-name">ชื่อร้าน Store name</label>
    <input id="f-name" type="text" value="ร้านสมใจ Somjai Shop" aria-describedby="f-name-hint">
    <small id="f-name-hint">แสดงบนใบเสร็จ Shown on receipts</small>
  </div>
  <div class="field">
    <label for="f-email">อีเมล Email</label>
    <input id="f-email" type="email" value="hello@" aria-invalid="true" aria-describedby="f-email-hint">
    <small id="f-email-hint">รูปแบบอีเมลไม่ถูกต้อง Invalid email</small>
  </div>
  <div class="field">
    <label for="f-country">ประเทศ Country</label>
    <select id="f-country">
      <option>ไทย Thailand</option>
      <option>ญี่ปุ่น Japan</option>
    </select>
  </div>
  <div class="field">
    <label for="f-note">หมายเหตุ Note</label>
    <textarea id="f-note"></textarea>
  </div>
  <label class="field"><input type="checkbox" checked> รับข่าวสาร Subscribe to updates</label>
</form>

Attributes

Attribute / element Values Description
> label / > small ป้ายและคำแนะนำ ขนาดเล็กสีเทา
aria-invalid true บน control: ขอบและคำแนะนำเป็นสี danger
label.field > checkbox เรียงเป็นแถวเดียว ใช้ accent-color
