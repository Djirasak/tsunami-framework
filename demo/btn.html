Button

Button

ปุ่มเป็นแบบ outline โดยค่าเริ่มต้น ใช้ primary กับ action หลักของหน้าเท่านั้น

รูปแบบ Variants

ไม่ใส่ data-variant คือปุ่ม outline ใช้ primary หนึ่งปุ่มต่อหน้า 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn">ยกเลิก Cancel</button>
  <button type="button" class="btn" data-variant="primary">บันทึก Save</button>
  <button type="button" class="btn" data-variant="ghost">ข้าม Skip</button>
  <button type="button" class="btn" data-variant="danger">ลบ Delete</button>
</div>

ขนาด Sizes

ปุ่มไอคอนอย่างเดียวใช้ data-size="icon" หรือ icon-sm และต้องมี aria-label 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-size="sm">เล็ก Small</button>
  <button type="button" class="btn">ปกติ Default</button>
  <button type="button" class="btn" data-size="lg">ใหญ่ Large</button>
  <button type="button" class="btn" data-size="icon" aria-label="ตั้งค่า Settings"><i class="icon icon-settings" aria-hidden="true"></i></button>
  <button type="button" class="btn" data-size="icon-sm" aria-label="เพิ่ม Add"><i class="icon icon-plus" aria-hidden="true"></i></button>
</div>

ไอคอนและ disabled Icon and disabled

ใส่ไอคอนไว้ก่อนข้อความ ลิงก์ที่ปิดใช้งานใช้ aria-disabled="true"

เปิดหน้าร้าน Open store ดูใบเสร็จ View receipt 
<div class="stack" data-direction="row" data-gap="sm">
  <a class="btn" href="#"><i class="icon icon-external-link" aria-hidden="true"></i>เปิดหน้าร้าน Open store</a>
  <button type="button" class="btn" disabled>ส่งออก Export</button>
  <a class="btn" aria-disabled="true">ดูใบเสร็จ View receipt</a>
</div>

ปุ่มลบแบบไอคอน Delete icon button

ปุ่มลบเป็นไอคอนถังขยะสีแดงในกรอบ outline หรือแบบ ghost (data-variant="ghost danger") สำหรับแถวในตาราง 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-variant="danger" data-size="icon-sm" aria-label="ลบ Delete"><i class="icon icon-trash-2" aria-hidden="true"></i></button>
  <button type="button" class="btn" data-variant="danger" data-size="icon" aria-label="ลบ Delete"><i class="icon icon-trash-2" aria-hidden="true"></i></button>
  <button type="button" class="btn" data-variant="ghost danger" data-size="icon-sm" aria-label="ลบ Delete"><i class="icon icon-trash-2" aria-hidden="true"></i></button>
</div>

ปุ่มไม่หดเมื่อแถวแคบ (flex-shrink: 0) จึงอยู่ท้ายแถวขนาดเท่าเดิมเสมอ

กลุ่มปุ่ม Button group

.btn-group ต่อปุ่มชิดกันเป็นชุดเดียว ใส่ role="group" และ aria-label 

<div class="btn-group" role="group" aria-label="จัดการคำสั่งซื้อ Order actions">
  <button type="button" class="btn">เก็บถาวร Archive</button>
  <button type="button" class="btn">รายงาน Report</button>
  <button type="button" class="btn">พิมพ์ Print</button>
</div>

aria-pressed แสดงปุ่มที่เปิดอยู่ Pressed toggle buttons

aria-pressed="true" ทำให้ปุ่มมีพื้นเทาว่าเปิดอยู่ ใส่ data-pressed="single" ที่กลุ่มให้เลือกได้ทีละปุ่ม หรือ multiple ให้แต่ละปุ่มสลับเอง (ต้องใช้ JS) 

<div class="stack" data-direction="row" data-gap="sm">
  <div class="btn-group" role="group" aria-label="ขนาดตัวอย่าง Preview width" data-pressed="single">
    <button type="button" class="btn" data-size="icon" aria-pressed="true" aria-label="Desktop"><i class="icon icon-monitor" aria-hidden="true"></i></button>
    <button type="button" class="btn" data-size="icon" aria-pressed="false" aria-label="Tablet"><i class="icon icon-tablet" aria-hidden="true"></i></button>
    <button type="button" class="btn" data-size="icon" aria-pressed="false" aria-label="Mobile"><i class="icon icon-smartphone" aria-hidden="true"></i></button>
  </div>
  <div class="btn-group" role="group" aria-label="ตัวกรองสินค้า Product filters" data-pressed="multiple">
    <button type="button" class="btn" aria-pressed="true">พร้อมส่ง</button>
    <button type="button" class="btn" aria-pressed="false">ลดราคา</button>
    <button type="button" class="btn" aria-pressed="false">ใหม่</button>
  </div>
</div>

กลุ่มปุ่มพร้อมเมนู Button group with a menu

ปุ่มสุดท้ายของกลุ่มเปิด dropdown ด้วย popovertarget ตัว popover อยู่ในกลุ่มได้โดยไม่กระทบมุมโค้งของปุ่ม 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-size="icon" aria-label="ย้อนกลับ Go back"><i class="icon icon-arrow-left" aria-hidden="true"></i></button>
  <div class="btn-group" role="group" aria-label="จัดการ Manage">
    <button type="button" class="btn">เก็บถาวร Archive</button>
    <button type="button" class="btn">รายงาน Report</button>
  </div>
  <div class="btn-group" role="group" aria-label="เลื่อน Snooze">
    <button type="button" class="btn">เลื่อน Snooze</button>
    <button type="button" class="btn" data-size="icon" popovertarget="btn-more" aria-label="ตัวเลือกเพิ่มเติม More options"><i class="icon icon-ellipsis" aria-hidden="true"></i></button>
    <div class="dropdown" id="btn-more" popover>
      <button type="button" popovertarget="btn-more" popovertargetaction="hide"><i class="icon icon-mail-check" aria-hidden="true"></i>อ่านแล้ว Mark as read</button>
      <button type="button" popovertarget="btn-more" popovertargetaction="hide"><i class="icon icon-archive" aria-hidden="true"></i>เก็บถาวร Archive</button>
      <hr />
      <button type="button" popovertarget="btn-more" popovertargetaction="hide"><i class="icon icon-clock" aria-hidden="true"></i>เลื่อน Snooze</button>
      <button type="button" popovertarget="btn-more" popovertargetaction="hide"><i class="icon icon-calendar" aria-hidden="true"></i>เพิ่มในปฏิทิน Add to calendar</button>

      <button type="button" data-variant="danger" popovertarget="btn-more" popovertargetaction="hide"><i class="icon icon-trash-2" aria-hidden="true"></i>ลบ Trash</button>

Attributes

Attribute / element Values Description
.btn button, a ปุ่ม ใช้กับ <button type="button"> หรือลิงก์
data-variant (ไม่ใส่ = outline, ค่าเริ่มต้น), primary, ghost, danger, ghost danger รูปแบบปุ่ม ใส่ได้หลายค่าคั่นด้วยช่องว่าง เช่น ghost danger คือ ghost สีแดง
data-size (ไม่ใส่ = ปกติ 32px, ค่าเริ่มต้น), sm, lg, icon, icon-sm icon / icon-sm เป็นปุ่มจัตุรัส 32px / 26px สำหรับไอคอนอย่างเดียว
aria-label ข้อความ จำเป็นกับปุ่มไอคอนอย่างเดียว
.icon i, ชื่อไอคอน Lucide ไอคอนในปุ่ม ใส่ aria-hidden="true" เสมอ
aria-pressed true, false ปุ่มสลับ true มีพื้นเทาว่าเปิดอยู่
disabled boolean ปิดการใช้งานปุ่ม
aria-disabled true ปิดการใช้งานลิงก์ a.btn
.btn-group div กลุ่มปุ่มต่อกัน ปุ่มลูกคือ .btn ใส่ role="group" และ aria-label
data-pressed single, multiple ใส่ที่ .btn-group (หรือ element ใดก็ได้) ให้ JS สลับ aria-pressed ของปุ่มข้างใน: ทีละปุ่ม หรือสลับแยกแต่ละปุ่ม
.dropdown popover, id เมนูของกลุ่ม วางใน .btn-group ได้ เปิดด้วยปุ่มในกลุ่มที่มี popovertarget ไม่นับเป็นปุ่มเวลาคิดมุมโค้ง

API

ไม่มีฟังก์ชัน ปุ่มในกลุ่ม [data-pressed] ทำงานผ่าน event delegation จึงใช้กับปุ่มที่เพิ่มทีหลังได้

Event Detail Description
tsunami:pressedchange { button, pressed } ส่งจาก element ที่มี data-pressed (bubbles) หลังคลิกปุ่ม button คือปุ่มที่คลิก pressed คือสถานะใหม่ของปุ่มนั้น
