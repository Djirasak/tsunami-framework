Loader

Loader

วงหมุนระหว่างรอ ใช้สีของตัวอักษรรอบข้าง จึงเข้ากับปุ่มและข้อความได้เอง สำหรับบล็อกสีเทาแทนเนื้อหาดู Skeleton

วงหมุน Spinner

ใส่ role="status" และ aria-label บอกว่ากำลังโหลดอะไร 

<span class="loader" role="status" aria-label="กำลังโหลด Loading"></span>

ขนาด xs, sm, ปกติ และ lg Spinner sizes

<div class="stack" data-direction="row" data-gap="lg">
  <span class="loader" data-size="xs" role="status" aria-label="กำลังโหลด Loading"></span>
  <span class="loader" data-size="sm" role="status" aria-label="กำลังโหลด Loading"></span>
  <span class="loader" role="status" aria-label="กำลังโหลด Loading"></span>
  <span class="loader" data-size="lg" role="status" aria-label="กำลังโหลด Loading"></span>
</div>

วงหมุนในปุ่ม ใช้สีตัวอักษรของปุ่ม Spinner in a button

วงหมุนในปุ่มเป็นของตกแต่ง ใส่ aria-hidden="true" ข้อความปุ่มบอกสถานะแทน 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-variant="primary" disabled><span class="loader" data-size="xs" aria-hidden="true"></span>กำลังบันทึก Saving…</button>
  <button type="button" class="btn" disabled><span class="loader" data-size="xs" aria-hidden="true"></span>กำลังโหลด Loading…</button>
  <button type="button" class="btn" data-variant="danger" disabled><span class="loader" data-size="xs" aria-hidden="true"></span>กำลังลบ Deleting…</button>
</div>

วงหมุนข้างข้อความ Spinner beside text

กำลังประมวลผลการชำระเงิน Processing payment…

฿1,250.00
<article class="item" data-variant="muted">
  <figure><span class="loader" data-size="xs" role="status" aria-label="กำลังประมวลผล Processing"></span></figure>
  <section><h3>กำลังประมวลผลการชำระเงิน Processing payment…</h3></section>
  <aside>฿1,250.00</aside>
</article>

วงหมุนระหว่างโหลดเนื้อหาการ์ด Spinner while a card's content loads

ใส่ aria-busy="true" บนส่วนที่กำลังโหลด ถ้าข้างในมีแค่วงหมุน มันจะอยู่กลางกล่องสูงอย่างน้อย 128px

ยอดขายตามช่วงเวลา Sales over time

<div class="card">
  <header>
    <h2>ยอดขายตามช่วงเวลา Sales over time</h2>
  </header>
  <section aria-busy="true" style="min-height: 12rem">
    <span class="loader" role="status" aria-label="กำลังโหลดยอดขาย Loading sales"></span>
  </section>
</div>

Attributes

Attribute / element Values Description
.loader วงหมุน 16px เส้น 2px ใช้ currentColor ร่องจาง 20% ยังหมุน (ช้าลง) เมื่อ reduced motion
data-size xs, sm, lg (ไม่ใส่ = 16px) xs 12px (ในปุ่ม) sm 14px lg 24px
role status บนวงหมุนที่ยืนเดี่ยว คู่กับ aria-label บอกสิ่งที่กำลังโหลด
aria-label ข้อความ ชื่อที่โปรแกรมอ่านหน้าจออ่าน เช่น "กำลังโหลดยอดขาย"
aria-hidden true ในปุ่มหรือข้างข้อความที่บอกสถานะอยู่แล้ว
[aria-busy="true"] true บนกล่องที่กำลังโหลด ถ้ามีแค่ .loader ข้างใน จะจัดกึ่งกลาง สูงอย่างน้อย 128px สีจาง เอาออกเมื่อเนื้อหามาแล้ว
