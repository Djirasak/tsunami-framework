Loader

วงหมุนและ skeleton ระหว่างรอ วงหมุนใส่ role="status" และ aria-label 

<div class="stack" data-direction="row">
  <span class="loader" data-size="sm" role="status" aria-label="กำลังโหลด Loading"></span>
  <span class="loader" role="status" aria-label="กำลังโหลด Loading"></span>
  <span class="loader" data-size="lg" role="status" aria-label="กำลังโหลด Loading"></span>
  <button type="button" class="btn" disabled><span class="loader" data-size="sm" aria-hidden="true"></span>กำลังบันทึก Saving</button>
</div>

Skeleton: บล็อกสีเทาแทนเนื้อหาที่กำลังโหลด

<div class="stack" data-direction="row" aria-busy="true" aria-label="กำลังโหลด Loading">
  <span class="skeleton" data-variant="circle"></span>
  <div class="stack" data-gap="sm">
    <span class="skeleton" style="width: 15rem"></span>
    <span class="skeleton" style="width: 12rem"></span>
  </div>
</div>

Skeleton ในการ์ด In a card

<article class="card" aria-busy="true" aria-label="กำลังโหลด Loading">
  <header>
    <span class="skeleton" style="width: 10rem"></span>
  </header>
  <div class="stack" data-gap="sm">
    <span class="skeleton"></span>
    <span class="skeleton" style="width: 80%"></span>
    <span class="skeleton" style="width: 60%"></span>
  </div>
</article>

Skeleton: บรรทัดเดียว One line

<span class="skeleton" style="width: 15rem" aria-hidden="true"></span>

Attributes

Attribute / element Values Description
data-size sm, lg 12px หรือ 24px (ค่าเริ่มต้น 16px)
.skeleton บล็อกสูง 1em เต็มความกว้าง กำหนด width / height ตามเนื้อหาที่จะมาแทน
.skeleton[data-variant] circle วงกลม 40px สำหรับ avatar
aria-busy true บนกล่องที่กำลังโหลด เอาออกเมื่อเนื้อหามาแล้ว
