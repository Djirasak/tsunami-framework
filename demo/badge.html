ลบได้ Removable

ใส่ <button> ไว้ท้ายป้าย พร้อม aria-label หน้าเป็นผู้ลบป้ายเมื่อกด (ตัวอย่างนี้ใช้สคริปต์สั้น ๆ ในหน้า)

บัตรของขวัญ Gift card: ใช่ Yes หมวดหมู่ Category: เฟอร์นิเจอร์ 
<div class="stack" data-direction="row" data-gap="sm" id="badge-filters">
  <span class="badge">บัตรของขวัญ Gift card: ใช่ Yes<button type="button" aria-label="ลบตัวกรอง Remove filter Gift card"><i class="icon icon-x" aria-hidden="true"></i></button></span>
  <span class="badge" data-variant="outline">หมวดหมู่ Category: เฟอร์นิเจอร์<button type="button" aria-label="ลบตัวกรอง Remove filter Category"><i class="icon icon-x" aria-hidden="true"></i></button></span>
</div>
<script>
  document.getElementById("badge-filters").addEventListener("click", (e) => {
    e.target.closest(".badge > button")?.parentElement.remove();
  });
</script>

Attributes

Attribute / element Values Description
.badge ป้าย inline สูง 20px ตัวอักษร 12px พื้นสีกลาง
data-variant outline, ok, warning, info, danger (ไม่ใส่ = กลาง) outline ขอบ 1px พื้นโปร่ง สำหรับป้ายที่ไม่ใช่สถานะ ที่เหลือเป็นสีสถานะ
data-size lg (ไม่ใส่ = ปกติ 20px) lg สูง 28px ตัวอักษร 14px ใช้เป็นหัวการ์ด
> .icon ไอคอนหน้าข้อความ ขนาดตามข้อความ
> button ปุ่มลบท้ายป้าย ใส่ type="button" และ aria-label ข้างในเป็น .icon-x หน้าเป็นผู้ลบป้าย
h1 > .badge, h2 > .badge, h3 > .badge ในหัวข้อ ป้ายเว้นระยะ 8px จากชื่อและอยู่กึ่งกลางบรรทัด
