Save bar

Save bar

แถบติดด้านล่างที่แสดงเมื่อฟอร์มถูกแก้ไข และซ่อนเมื่อค่ากลับเป็นค่าเดิม ลองแก้ฟอร์มด้านล่างดู

มีการแก้ไขที่ยังไม่บันทึก Unsaved changes

<form id="sb-form" class="stack docs-narrow">
  <div class="field">
    <label for="sb-title">ชื่อสินค้า Product title</label>
    <input id="sb-title" type="text" value="เสื้อยืด T-shirt">
  </div>
  <label class="field"><input type="checkbox"> แสดงในหน้าร้าน Visible in store</label>
</form>
<div class="save-bar" data-form="sb-form" role="region" aria-label="Unsaved changes" hidden>
  <p>มีการแก้ไขที่ยังไม่บันทึก Unsaved changes</p>
  <div>
    <button type="reset" form="sb-form" class="btn" data-variant="ghost">ยกเลิก Discard</button>
    <button type="submit" form="sb-form" class="btn" data-variant="primary">บันทึก Save</button>
  </div>
</div>

Attributes

Attribute / element Values Description
data-form form id ฟอร์มที่ติดตาม ถ้าไม่ใส่จะแสดงตลอด
hidden เริ่มแบบซ่อน JS จะสลับให้
button[type=reset][form] ปุ่ม Discard คืนค่าเดิมแบบ native
