Attributes

Attribute / element Values Description
data-variant outline, muted, ok, danger ขอบ, พื้นเทา หรือพื้นสถานะแบบ soft
data-size sm padding และ figure เล็กลง
> figure / > section / > aside ไอคอนด้านหน้า, ข้อความ, action ด้านท้าย
.item-group ครอบหลาย item ใส่ <hr> คั่นได้
