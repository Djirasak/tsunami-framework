Card

กล่องพื้นขาวขอบ 1px ลูกโดยตรงแต่ละตัว (header, section, table, footer) เป็นส่วนหนึ่ง คั่นด้วยเส้น

การใช้งาน Usage

header มีชื่อ h2 คำอธิบาย p และ aside สำหรับปุ่มทางขวา ตามด้วยเนื้อหาใน section และ footer

การ์ดที่ต้องดู data-variant="warning"

เส้นบน 2px สีเตือน สำหรับการ์ดที่ต้องการความสนใจ ใช้ danger, info, ok ได้เหมือนกัน

ลูกค้าโต้แย้งการชำระเงิน Payment disputed

ตอบภายใน 4 สัปดาห์

ผู้ถือบัตรแจ้งว่าไม่ได้รับสินค้า The cardholder claims the order was not received. 

<section class="card" data-variant="warning" style="max-width: 28rem">
  <header>
    <h2>ลูกค้าโต้แย้งการชำระเงิน Payment disputed</h2>
    <aside><span class="badge" data-variant="warning">ตอบภายใน 4 สัปดาห์</span></aside>
  </header>
  <section>
    <p>ผู้ถือบัตรแจ้งว่าไม่ได้รับสินค้า The cardholder claims the order was not received.</p>
  </section>
</section>

Attributes

Attribute / element Values Description
.card article, section, div กล่องการ์ด ลูกโดยตรงทุกตัวได้ padding และเส้นคั่นด้านบน
> header หัวการ์ด: grid สองคอลัมน์ ข้อความซ้าย aside ขวา
> header h2 / h3 ชื่อการ์ด ขนาด 14px ตัวหนา
> header p คำอธิบายสีเทา ใต้ชื่อ
> header > aside ปุ่มหรือ badge ชิดขวา ครอบสองแถวเมื่อมีชื่อและคำอธิบาย
> header > strong ตัวเลขใหญ่ ทำให้ h2 กลายเป็นป้ายสีเทาเล็ก และ aside เรียงลงแนวตั้งชิดขวา
header [data-trend] up, down, ไม่ใส่ค่า = เทา การเปลี่ยนแปลงของตัวเลข: up = สี ok, down = สี danger
> section, > div เนื้อหา padding เท่ากันทุกส่วน
> footer ปุ่มชิดขวา p ตัวแรกชิดซ้ายสีเทา (เช่นจำนวนผลลัพธ์)
> .table, > .scroll-area > .table ตารางชิดขอบ cell แรกและสุดท้ายตรงกับ padding การ์ด
> .empty สถานะว่างแทนตาราง
> .stat, > .stat-group ตัวเลขสถิติ ดู Stat
data-variant warning, danger, info, ok; ไม่ใส่ = ปกติ (default) เส้นบน 2px สีตามสถานะ สำหรับการ์ดที่ต้องดู
data-direction row; ไม่ใส่ = เรียงลง (default) ลูกเรียงแนวนอน คั่นด้วยเส้นตั้ง ลูกตัวแรกกว้างพอดีเนื้อหา (เช่นปุ่มเลือกช่วงเวลา ข้างกลุ่ม stat)
