Attributes

Attribute / element Values Description
> header หัวการ์ด: h2 ตัวหนา และ p สีเทา
> div เนื้อหา padding เท่ากับ section อื่น
> footer ปุ่ม action ชิดขวา
> .table ตารางเต็มความกว้าง cell แรกและสุดท้ายตรงกับ padding การ์ด
