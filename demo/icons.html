Icons

Icons

ไอคอนจาก Lucide icon font (2,191 ชื่อ, 1,926 แบบ) ใช้สีและขนาดตามข้อความ

ไอคอนมาจาก Lucide Icons come from Lucide

Lucide icon font เวอร์ชัน 1.61.0 (lucide.dev, ISC license) รวมไว้ในไฟล์ฟอนต์เดียว fonts/lucide.woff2

ขนาดและสีตามข้อความ Size and colour follow the text

<div class="stack" data-direction="row">
  <i class="icon icon-webhook" data-size="sm" aria-hidden="true"></i>
  <i class="icon icon-webhook" aria-hidden="true"></i>
  <i class="icon icon-webhook" data-size="lg" aria-hidden="true"></i>
  <i class="icon icon-webhook" data-size="xl" aria-hidden="true"></i>
  <a href="#"><i class="icon icon-webhook" data-size="xl" aria-hidden="true"></i></a>
  <span style="color: var(--muted)"><i class="icon icon-webhook" data-size="xl" aria-hidden="true"></i></span>
</div>

ในปุ่ม In a button

<button type="button" class="btn"><i class="icon icon-plus" aria-hidden="true"></i>เพิ่มสินค้า Add product</button>

Attributes

Attribute / element Values Description
class icon icon-{name} ชื่อจากรายการด้านล่าง ใส่ aria-hidden="true" เสมอ
data-size sm, lg, xl 16, 20 หรือ 24px (ค่าเริ่มต้น 1.15em ของตัวอักษร)
color ใช้สีของข้อความ (currentColor)
