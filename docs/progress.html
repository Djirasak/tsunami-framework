Progress

แถบความคืบหน้า: track หนึ่งเส้นกับ span หนึ่งตัวต่อหนึ่งส่วน ความกว้างของ span คือสัดส่วนของมัน

โครงสร้าง: track และ span The markup is a track and a span for each part

ความกว้าง inline ของ span คือส่วนของมันบน track แถบที่แสดงค่าเดียวใส่ role="progressbar" กับ aria-valuenow บน track 

<div class="progress" role="progressbar" aria-label="กำลังอัปโหลด Uploading" aria-valuenow="66" aria-valuemin="0" aria-valuemax="100">
  <span style="width: 66%"></span>
</div>

หลาย span แบ่ง track Several spans divide the track

ส่วนที่ไม่ใส่สีจะไล่จากสีเข้มไปจาง แถบที่แบ่งหลายส่วนใช้ role="img" และ aria-label ที่บอกทุกส่วน ใช้ไม่เกิน 5 ส่วน

ส่วนว่าง data-variant="empty" เป็นตัวเว้น

    <span data-variant="danger" style="width: 35%"></span>

    <span data-variant="ok" style="width: 10%"></span>
  </div>
</div>

หน้าเลื่อนแถบโดยตั้ง width และ aria-valuenow พร้อมกัน The page moves the bar

ไม่มี JS ใน tsunami สำหรับ progress หน้าตั้งค่าทั้งสองเอง ตัวอย่างนี้ใช้สคริปต์สั้น ๆ ในหน้า 

<div class="stack" data-gap="sm">
  <div class="progress" id="pg-import" role="progressbar" aria-label="นำเข้าสินค้า Importing products" aria-valuenow="10" aria-valuemin="0" aria-valuemax="100">
    <span style="width: 10%"></span>
  </div>
  <div>
    <button type="button" class="btn" data-size="sm" id="pg-import-add">เพิ่ม Add 15%</button>
  </div>
</div>
<script>
  document.getElementById("pg-import-add").addEventListener("click", () => {
    const bar = document.getElementById("pg-import");
    const value = Math.min(100, Number(bar.getAttribute("aria-valuenow")) + 15);
    bar.setAttribute("aria-valuenow", value);
    bar.querySelector("span").style.width = value + "%";
  });
</script>

<progress> แบบ native

สำหรับค่าเดียวแบบง่าย ใช้ <progress class="progress"> ได้ ความหมาย progressbar มาในตัว ใช้ data-size และ data-variant บนตัว element

40% 
<progress class="progress" data-variant="ok" value="40" max="100" aria-label="อัปโหลดรูป Uploading images">40%</progress>

Attributes

Attribute / element Values Description
.progress track เต็มความกว้าง สูง 6px พื้น subtle มุม 4px ใช้กับ <div> (มี span) หรือ <progress>
data-size sm, lg, xl (ไม่ใส่ = 6px) บน track: sm 4px lg 12px xl 32px
> span หนึ่งส่วนของ track ตั้ง style="width: N%" ส่วนที่ติดกันมีเส้นคั่น 2px ส่วนที่ไม่ใส่สีไล่จาก --fg ไปจาง (ลำดับ 1-5)
> span[data-variant] ok, warning, info, danger, empty (ไม่ใส่ = --fg) สีของส่วน empty ไม่วาด ใช้เป็นตัวเว้นให้ส่วนถัดไปเริ่มกลาง track
progress[data-variant] ok, warning, info, danger สีของ <progress> แบบ native
role progressbar, img บน track: progressbar เมื่อแสดงค่าเดียว img เมื่อแบ่งหลายส่วน (พร้อม aria-label ที่บอกทุกส่วน)
aria-valuenow ตัวเลข บน track ที่เป็น progressbar ค่าปัจจุบัน ตั้งพร้อมกับ width ของ span
aria-valuemin 0 ค่าต่ำสุด
aria-valuemax 100 ค่าสูงสุด
aria-valuetext ข้อความ ไม่บังคับ ค่าที่อ่านออกเสียง เช่น "7.8 GB จาก 10 GB"
aria-label ข้อความ ชื่อของแถบ
aria-labelledby id ใช้แทน aria-label เมื่อชื่อแสดงอยู่ใน header
header + .progress <header> ก่อน track: ลูกแรกเป็นชื่อ ลูกสุดท้ายเป็นค่าสีจางชิดขวา ตัวอักษร 12px
.progress + ul > li รายการต่อจาก track: แต่ละแถวได้สีสัญลักษณ์ของส่วนลำดับเดียวกัน span สุดท้ายในแถวคือค่า ชิดขวาตัวหนา

API

Progress ไม่มีสคริปต์ ไม่มีฟังก์ชันและอีเวนต์ หน้าตั้ง style.width ของ span และ aria-valuenow (และ aria-valuetext ถ้ามี) พร้อมกัน ความกว้างที่เปลี่ยนจะเลื่อนอย่างนุ่มนวล 0.3 วินาที (ไม่เคลื่อนไหวเมื่อ reduced motion)
