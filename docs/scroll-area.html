Scroll area

พื้นที่เลื่อนแยกในกล่องที่สูงคงที่ พร้อม scrollbar บาง

การใช้งาน Usage

Attributes

Attribute / element Values Description
.scroll-area เลื่อนได้ทั้งสองแนว scrollbar บางสีเส้น การเลื่อนไม่ลามไปทั้งหน้า (overscroll-behavior: contain)
height, max-height ความยาว CSS ต้องกำหนดเอง (จาก CSS ของหน้าหรือ style) ไม่มีค่าเริ่มต้น
tabindex 0 ให้โฟกัสแล้วเลื่อนด้วยลูกศร/Page Up/Page Down ได้
aria-label ข้อความ ชื่อพื้นที่สำหรับ screen reader เมื่อโฟกัสได้
