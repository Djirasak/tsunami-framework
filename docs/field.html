Field

ฟอร์มที่อยู่จัดส่ง Shipping address form

ติ๊กบางส่วน Partly ticked (select all)

สถานะ indeterminate ตั้งจาก HTML ไม่ได้ ต้องใช้ script ตั้ง checkbox.indeterminate = true ตัวอย่างนี้เป็น checkbox เลือกทั้งหมดที่คุมตัวเลือกย่อยของสินค้า เบราว์เซอร์จะวาดขีดกลางให้เอง

เลือก 1 จาก 3 ตัวเลือก 1 of 3 variants selected 
<div class="field-group docs-narrow" data-gap="sm" id="pt-group" role="group" aria-label="ตัวเลือกสินค้า Variants">
  <div class="field">
    <input id="pt-all" type="checkbox" aria-controls="pt-1 pt-2 pt-3" aria-describedby="pt-all-hint" />
    <div>
      <label for="pt-all">นาฬิกา Timeless Watch</label>
      <small id="pt-all-hint">เลือก 1 จาก 3 ตัวเลือก 1 of 3 variants selected</small>
    </div>
  </div>
  <div class="field">
    <input id="pt-1" type="checkbox" checked />
    <label for="pt-1">สีเงิน Silver · ฿4,990</label>
  </div>
  <div class="field">
    <input id="pt-2" type="checkbox" />
    <label for="pt-2">สีทอง Gold · ฿5,490</label>
  </div>
  <div class="field">
    <input id="pt-3" type="checkbox" />
    <label for="pt-3">สีดำ Black · ฿4,990</label>
  </div>
</div>
<script>
  {
    const all = document.getElementById("pt-all");
    const rows = ["pt-1", "pt-2", "pt-3"].map((id) => document.getElementById(id));
    const hint = document.getElementById("pt-all-hint");
    const sync = () => {
      const n = rows.filter((r) => r.checked).length;
      all.checked = n === rows.length;
      all.indeterminate = n > 0 && n < rows.length;
      hint.textContent = "เลือก " + n + " จาก " + rows.length + " ตัวเลือก " + n + " of " + rows.length + " variants selected";
    };
    all.addEventListener("change", () => {
      for (const r of rows) r.checked = all.checked;
      sync();
    });
    for (const r of rows) r.addEventListener("change", sync);
    sync();
  }
</script>

สไลเดอร์ Slider

<input type="range" class="slider"> ใช้ min, max, step, value ของตัวเองตามปกติ script เติมแถบจนถึงตำแหน่งปุ่ม และเขียนค่าลง <output for="id"> ที่ชี้มา 

<div class="stack docs-narrow">
  <div class="field">
    <label for="sl-discount">ส่วนลด Discount: <output for="sl-discount">15</output>%</label>
    <input id="sl-discount" class="slider" type="range" min="0" max="50" step="5" value="15" />
  </div>
  <div class="field">
    <label for="sl-stock">แจ้งเตือนเมื่อสต็อกต่ำกว่า Low stock alert: <output for="sl-stock">20</output> ชิ้น</label>
    <input id="sl-stock" class="slider" type="range" min="0" max="100" value="20" />
  </div>
  <input class="slider" type="range" min="0" max="100" value="60" aria-label="ระดับเสียงแจ้งเตือน Alert volume" disabled />
</div>

API

สไลเดอร์ใช้ js/slider.js (Field อื่นไม่ต้องใช้ JS) ทำงานกับ .slider ที่เพิ่มเข้ามาภายหลังด้วย

Member Args Description
--value custom property บน input: ค่าปัจจุบันเป็นเปอร์เซ็นต์ (เช่น 30%) แถบสี accent กว้างเท่านี้ ตั้งเองใน style ได้ถ้าไม่โหลด JS
output[for] script เขียน value ลงทุก <output> ที่ for มี id ของสไลเดอร์
window.tsunami.slider.sync(el) el el คือ input.slider: วาดแถบและ output ใหม่ เรียกหลังตั้ง el.value จาก script (ค่าที่ตั้งจาก script ไม่ส่ง event input)
input event ของ input เอง: script วาดใหม่ทุกครั้งที่เลื่อน และหลัง form reset

Attributes

Attribute / element Values Description
.field ห่อ label + ช่อง + คำแนะนำ เรียงแนวตั้ง ถ้ามี checkbox/radio เป็นลูกตัวแรกจะเรียงเป็นแถว
.field > label ป้ายสีเทาขนาดเล็ก (ในแถว checkbox เป็นสีปกติ)
.field > small คำแนะนำหรือข้อความผิดพลาด ผูกกับช่องด้วย aria-describedby
.field > input / select / textarea ได้หน้าตาเดียวกับ .input โดยไม่ต้องใส่ class (ดูหน้า Input)
.field > div ในแถว checkbox: ห่อ label กับ small (หรือ h3) ให้ซ้อนกัน
aria-invalid true บนช่อง: ขอบและ small เป็นสี danger
disabled บน input: ป้ายในแถวเป็นสีเทา เคอร์เซอร์ not-allowed
data-variant card (ไม่มี = default) บน label.field: กรอบรอบทั้งแถว พื้นเปลี่ยนเมื่อติ๊ก
role switch บน input type=checkbox: วาดเป็นสวิตช์ ใช้ได้ทุกที่
.slider บน input[type=range]: แถบและปุ่มสีตาม token ดู API ด้านบน
.field-group fieldset หรือ div[role=group] ไม่มีกรอบ เรียง field ห่าง space-4
.field-group > legend หัวข้อกลุ่ม (ตัวหนา) ถ้า data-gap="sm" เป็นป้ายสีเทาเล็ก
.field-group > div div ที่ไม่มี class แบ่ง field ข้างในเป็นคอลัมน์เท่ากัน กว้างอย่างน้อย 9rem
data-gap sm (ไม่มี = space-4) บน .field-group: ระยะชิดสำหรับรายการ checkbox, radio, switch
