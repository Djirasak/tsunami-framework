<script type="module">
  document.getElementById("tb-keep").addEventListener("tsunami:closetab", (e) => {
    const kept = e.detail.tab.hasAttribute("data-unsaved");
    if (kept) e.preventDefault();
    document.getElementById("tb-keep-log").textContent =
      e.detail.tab.textContent.trim() + (kept ? " ถูกเก็บไว้ was kept open." : " ถูกปิด was closed.");
  });
</script>

API

อยู่ใน js/tabs.js ใช้ event delegation แท็บที่เพิ่มทีหลังก็ทำงาน

Function Arguments Description
tsunami.tabs.select(tab) tab: element [role="tab"] เลือกแท็บ แสดง panel ของมัน ซ่อน panel อื่น แท็บที่ปิดใช้งานไม่ทำอะไร
tsunami.tabs.close(tab) tab: element [role="tab"] ส่ง tsunami:closetab ก่อน ถ้าไม่ถูกยกเลิกก็ลบแท็บกับ panel แล้วเลือกแท็บถัดไป (หรือก่อนหน้า) ถ้าแท็บนั้นถูกเลือกอยู่ คืนค่าแท็บที่มาแทน (หรือ null) หรือ false ถ้าถูกเก็บไว้
Arrow Left / Right คีย์บอร์ด แท็บก่อน/ถัดไป วนรอบ ข้ามแท็บที่ปิดใช้งาน แนวตั้งใช้ Arrow Up / Down
Home / End คีย์บอร์ด แท็บแรก / สุดท้าย
Delete คีย์บอร์ด บนแท็บที่มี [data-close]: ปิดแท็บ แล้วโฟกัสแท็บที่มาแทน
Tab คีย์บอร์ด เฉพาะแท็บที่เลือกอยู่ในลำดับ Tab

Events

Event Detail Description
tsunami:closetab { tab, panel } ส่งจากแท็บก่อนปิด bubble ขึ้นไป ยกเลิกได้: preventDefault() เก็บแท็บไว้

Attributes

Attribute / element Values Description
.tabs div ครอบ tablist และ panel (data-tabs ก็ใช้ได้เหมือนกัน)
[role="tablist"] child แถวแท็บ ใส่ aria-label
data-variant ไม่ใส่ (default) segmented · line ขีดเส้นใต้ บน tablist: รูปแบบแท็บ
data-size ไม่ใส่ (default) 32px · sm 28px บน tablist: ขนาด sm สำหรับหัวการ์ด
aria-orientation horizontal (default) · vertical บน tablist: vertical วางแท็บข้าง panel ใช้ลูกศรขึ้น/ลง (tablist ต้องเป็นลูกตรงของ .tabs)
[role="tab"] button แท็บ ใส่ .icon ได้
aria-controls id ของ panel บนแท็บ: panel ที่แท็บนี้แสดง (ต้องมี)
aria-selected true · false บนแท็บ: แท็บที่เลือก ใส่ tabindex="-1" บนแท็บอื่น JS อัปเดตให้
disabled / aria-disabled true บนแท็บ: เลือกไม่ได้ คีย์บอร์ดข้ามไป
popovertarget id ของ .dropdown บนแท็บ: แท็บเป็น dropdown คลิกรายการในเมนูเพื่อเลือกแท็บ
[data-close] element ในแท็บ แท็บปิดได้ คลิกที่ element นี้หรือกด Delete เพื่อปิด
[role="tabpanel"] element เนื้อหา ใส่ aria-labelledby ชี้แท็บ และ hidden ยกเว้นอันที่เลือก
