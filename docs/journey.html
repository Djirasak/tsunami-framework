เติมขั้นถัดไปเมื่อเลือกหน้า Fill later steps on pick

ทุกครั้งที่เลือกหน้า ปุ่มจะส่งเหตุการณ์ tsunami:pick (bubbles) พร้อม detail.step (ลำดับขั้นเริ่มที่ 0) และ detail.value (ค่า value ของปุ่ม หรือชื่อหน้า) หน้าเว็บฟังเหตุการณ์นี้แล้วโหลดขั้นถัดไปมาแทนที่ เส้นจะวาดใหม่เองเมื่อขั้นหรือการเลือกเปลี่ยน

  1. ขั้นที่ 1 Step 11,000 sessionsเข้ามา entered

เลือกหน้าในขั้นที่ 1 Pick a page in step 1 

<div class="journey" role="group" aria-label="เลือกหน้า Pick a page" id="jn-fill">
  <ol>
    <li>
      <header><span>ขั้นที่ 1 Step 1</span><strong>1,000 sessions</strong><small>เข้ามา entered</small></header>
      <ul>
        <li><button type="button" aria-pressed="false" value="home"><span>หน้าแรก Home</span><data value="700">700</data></button></li>
        <li><button type="button" aria-pressed="false" value="blog"><span>บทความ Blog</span><data value="300">300</data></button></li>

<p id="jn-fill-output">เลือกหน้าในขั้นที่ 1 Pick a page in step 1</p>
<script type="module">
  // Next pages for each picked value; a real page would fetch them.
  const next = {
    home: [["product", "เสื้อยืด T-shirt", 420], ["sale", "โปรโมชั่น Sale", 180]],
    blog: [["product", "เสื้อยืด T-shirt", 90], ["home", "หน้าแรก Home", 60]],
    product: [["cart", "ตะกร้า Cart", 150]],
    sale: [["cart", "ตะกร้า Cart", 70]],
    cart: [["checkout", "ชำระเงิน Checkout", 120]],
  };
  const journey = document.getElementById("jn-fill");
  const output = document.getElementById("jn-fill-output");
  journey.addEventListener("tsunami:pick", (event) => {
    const { step, value } = event.detail;
    output.textContent = `เลือก Picked: ${value} ในขั้นที่ ${step + 1}`;
    const steps = journey.querySelectorAll(":scope > ol > li");
    for (const later of [...steps].slice(step + 1)) later.remove();
    const pages = next[value];
    if (!pages) return;
    const total = pages.reduce((sum, page) => sum + page[2], 0);
    const li = document.createElement("li");
    li.innerHTML = `<header><span>ขั้นที่ ${step + 2} Step ${step + 2}</span><strong>${total} reached</strong></header><ul></ul>`;
    for (const [key, name, count] of pages) {
      const item = document.createElement("li");
      item.innerHTML = `<button type="button" aria-pressed="false"><span></span><data></data></button>`;
      const button = item.firstElementChild;
      button.value = key;
      button.querySelector("span").textContent = name;
      button.querySelector("data").value = count;
      button.querySelector("data").textContent = count;
      li.querySelector("ul").append(item);
    }
    journey.querySelector(":scope > ol").append(li);
  });
</script>

API

journey.js ทำงานกับทุก .journey ในหน้า รวมถึงที่เพิ่มทีหลัง ไม่ต้องเรียก init ฟังก์ชันอยู่ที่ window.tsunami.journey

Function / event Arguments / detail Description
pick(button) button: ปุ่มหน้าหรือผลลัพธ์ใน journey เลือกหน้าเหมือนคลิก: ตั้ง aria-pressed="true" ล้างการเลือกในขั้นเดียวกันและทุกขั้นถัดไป ส่ง tsunami:pick แล้ววาดเส้นใหม่
draw(journey) journey: element .journey วาดเส้นใหม่ทันที (ปกติวาดเองเมื่อขนาด ขั้น หรือการเลือกเปลี่ยน)
tsunami:pick { step, value } ส่งจากปุ่มหลังเลือกหน้า bubbles ขึ้นไป step คือลำดับขั้นเริ่มที่ 0, value คือ value ของปุ่ม หรือข้อความใน <span> แรกถ้าไม่มี
Key Description
Tab ไปหน้าถัดไป (ของ browser เอง ทุกหน้าโฟกัสได้)
Enter, Space เลือกหน้า (คลิกปุ่มของ browser เอง)
↓, ↑ ไปหน้าถัดไป/ก่อนหน้าในขั้นเดียวกัน แบบแนวตั้งไปข้ามขั้นได้
→, ← ไปหน้าที่เลือกไว้ในขั้นถัดไป/ก่อนหน้า (ถ้าไม่มีไปหน้าแรกของขั้น) สลับทิศเมื่อ dir="rtl" แบบแนวตั้งไม่ใช้ปุ่มนี้

Attributes

Attribute / element Values Description
.journey กล่องนอกสุด เลื่อนแนวนอนได้เมื่อขั้นเกินความกว้าง ใส่ role="group" และ aria-label เพื่อตั้งชื่อให้ screen reader
data-orientation vertical; ไม่ใส่ = คอลัมน์ (ค่าเริ่มต้น) เรียงขั้นจากบนลงล่าง แต่ละขั้นเยื้องเข้าไป 1.5rem (สูงสุด 40%) หน้าเต็มแถว
data-view picked; ไม่ใส่ = ทุกหน้า (ค่าเริ่มต้น) แสดงเฉพาะหน้าและผลลัพธ์ที่เลือกในแต่ละขั้น
> ol > li หนึ่งขั้น
li > header span, strong, small หัวขั้น: span ชื่อขั้น (สีเทา), strong จำนวน session, small จำนวนที่ออก
li > ul > li หนึ่งหน้าในขั้น
button[aria-pressed] true, false หน้า (หรือผลลัพธ์) เลือกได้ true = หน้าที่เลือกในขั้นนี้ (กรอบเข้ม) JS ตั้งให้เมื่อคลิก ใส่ value เพื่อส่งไปกับ tsunami:pick
button > span ชื่อหน้า ตัดด้วย … เมื่อยาวเกิน
button > small path ของหน้า (ตัวพิมพ์ mono สีเทา) เมื่อมี small ในแบบคอลัมน์ ตัวเลขจะเรียงใต้ชื่อ
button > data value ตัวเลข: อันแรกคือ session (ชิดขวาบรรทัดชื่อ) อันที่สองคือรายได้ · RPV (สีเทา)
li[data-outcomes] มี / ไม่มี หน้าที่มีผลลัพธ์ เช่น upsell: span ชื่อ, small path แล้ว <div> ของปุ่มผลลัพธ์ (ปฏิเสธ / ยอมรับ + CVR) เส้นต่อเข้าที่แถวนี้
> svg เส้นเชื่อมหน้าที่เลือก JS สร้างและวาดให้เอง (aria-hidden) ไม่ต้องเขียนเอง
