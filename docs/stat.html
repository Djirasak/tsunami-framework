Stat

ตัวเลขหนึ่งค่า: ป้าย ค่า และการเปลี่ยนแปลง วางเดี่ยว ในการ์ด หรือเรียงเป็นกลุ่มด้วย .stat-group

ป้าย ค่า และการเปลี่ยนแปลง A label, a value and an optional change

span ตัวแรกคือป้าย strong คือค่า และ span[data-trend] บอกว่าเปลี่ยนไปอย่างไร (ใส่หรือไม่ก็ได้)

คำสั่งซื้อใหม่ New orders 128 12.5% 
<div class="stat" style="max-width: 14rem">
  <span>คำสั่งซื้อใหม่ New orders</span>
  <strong>128</strong>
  <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>12.5%</span>
</div>

aria-busy="true" แสดงวงหมุนแทนค่าระหว่างโหลด Loading

ใส่ .loader ไว้ใน stat แล้วสลับ aria-busy ระหว่างดึงข้อมูล ค่าและการเปลี่ยนแปลงจะถูกซ่อน

คำสั่งซื้อใหม่ New orders 128 12.5%
สินค้าที่สั่ง Items ordered 342 8.1% 
<div class="stack" data-gap="sm">
  <div class="card" style="max-width: 28rem">
    <div class="stat-group" id="stat-loading">
      <div class="stat" aria-busy="true">
        <span>คำสั่งซื้อใหม่ New orders</span>
        <strong>128</strong>
        <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>12.5%</span>
        <span class="loader" role="status" aria-label="กำลังโหลด Loading"></span>
      </div>
      <div class="stat" aria-busy="true">
        <span>สินค้าที่สั่ง Items ordered</span>
        <strong>342</strong>
        <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>8.1%</span>
        <span class="loader" role="status" aria-label="กำลังโหลด Loading"></span>
      </div>
    </div>
  </div>
  <div>
    <button type="button" class="btn" data-size="sm" id="stat-busy-btn">สลับการโหลด Toggle loading</button>
  </div>
</div>
<script>
  const busyBtn = document.getElementById("stat-busy-btn");
  busyBtn.addEventListener("click", () => {
    const group = document.getElementById("stat-loading");
    for (const s of group.children) {
      const busy = s.getAttribute("aria-busy") === "true";
      s.setAttribute("aria-busy", String(!busy));
    }
  });
</script>

ตัวเลขที่เลือกว่ากราฟแสดงอะไร Stats that pick what a chart shows

stat เป็น button ตัวที่เลือกอยู่ aria-pressed="true" และ data-even ที่กลุ่มทำให้ทุกช่องกว้างเท่ากัน 

<div class="card">
  <div class="stat-group" data-even id="stat-pick">
    <button type="button" class="stat" aria-pressed="false">
      <span>ผู้เข้าชมใหม่ New sessions</span>
      <strong>4,812</strong>
      <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>12.4%</span>
    </button>
    <button type="button" class="stat" aria-pressed="false">
      <span>คำสั่งซื้อ Orders</span>
      <strong>238</strong>
      <span data-trend="down"><i class="icon icon-arrow-down" aria-hidden="true"></i>3.2%</span>
    </button>
    <button type="button" class="stat" aria-pressed="true">
      <span>ยอดขาย Sales</span>
      <strong>฿214,026</strong>
      <span data-trend="down"><i class="icon icon-arrow-down" aria-hidden="true"></i>5.7%</span>
    </button>
  </div>
</div>
<script>
  document.getElementById("stat-pick").addEventListener("click", (e) => {
    const picked = e.target.closest(".stat");
    if (!picked) return;
    for (const s of e.currentTarget.children) {
      s.setAttribute("aria-pressed", String(s === picked));
    }
  });
</script>

Attributes

Attribute / element Values Description
.stat div, a, button ตัวเลขหนึ่งค่า; a เมื่อทั้งช่องเป็นลิงก์ (ค่าสี accent), button เมื่อใช้เลือกสิ่งที่แสดง
> span:first-child ป้ายสีเทา 12px ตัดด้วย … เมื่อไม่พอ; ใส่ button ไอคอนต่อท้ายเพื่อเปิดคำอธิบายได้
> strong ค่า 24px ตัวเลขกว้างเท่ากัน
> span[data-trend] up, down, ไม่ใส่ค่า = เทา การเปลี่ยนแปลง ชิดขวาบนแถวเดียวกับค่า up = สี ok, down = สี danger; ใส่ไอคอนนำหน้า
> .loader วงหมุน แสดงแทนค่าเมื่อ aria-busy="true" (ซ่อนเมื่อไม่โหลด)
aria-busy true; ไม่ใส่ = แสดงค่า (default) ซ่อนค่าและการเปลี่ยนแปลง แสดง .loader
aria-pressed true, false บน button.stat: ตัวที่เลือกอยู่มีพื้นเทาเข้ม
data-reverse (boolean) สลับสี: ขึ้นเป็น danger ลงเป็น ok สำหรับตัวเลขที่ขึ้นแล้วแย่
data-variant danger; ไม่ใส่ = ปกติ (default) ป้ายและค่าเป็นสีแดง สำหรับจำนวนที่เป็นปัญหา
data-size sm; ไม่ใส่ = ปกติ (default) กล่องเล็กมีขอบ จัดกลาง สำหรับวางข้างชื่อหน้า
.stat-group div แถวของ stat คั่นด้วยเส้น ขึ้นบรรทัดใหม่บนจอแคบ ใส่ใน .card จะชิดขอบ
.stat-group[data-even] (boolean) ทุกช่องกว้างเท่ากัน แต่ไม่แคบกว่าข้อความ
dl.stat div > dt + dd + dd แบบเดิม: กล่องหลายช่องในกรอบเดียว; dd[data-variant] = ok, danger
