Stat

Stat

A single figure: a label, a value and a change. Use it alone, in a card, or in a row with .stat-group.

A label, a value and an optional change

The first span is the label and strong is the value. An optional span[data-trend] shows how it changed.

New orders 128 12.5% 
<div class="stat" style="max-width: 14rem">
  <span>New orders</span>
  <strong>128</strong>
  <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>12.5%</span>
</div>

One stat in a card

Net revenue $1,377.43 4.2% 
<div class="card" style="max-width: 20rem">
  <div class="stat">
    <span>Net revenue</span>
    <strong>$1,377.43</strong>
    <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>4.2%</span>
  </div>
</div>

A link to the records and an info button on the label

The whole stat can be an a, and the value turns the accent color. For an explanation, a button in the label opens a .popover (place the popover outside the link).

Total sales $4,148.64 40.1%

Total sales from all orders before returns.

<div class="card" style="max-width: 20rem">

    <strong><a href="#">$4,148.64</a></strong>
    <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>40.1%</span>
  </div>
  <div class="popover" id="stat-info" popover>
    <p>Total sales from all orders before returns.</p>
  </div>
</div>

data-reverse: when a rise is bad news

Add data-reverse to a stat to swap the colors: up is red, down is green.

Loading: aria-busy="true" shows a spinner in place of the value

Put a .loader in the stat and toggle aria-busy while fetching data. The value and the change are hidden.

New orders 128 12.5%
Items ordered 342 8.1% 
<div class="stack" data-gap="sm">
  <div class="card" style="max-width: 28rem">
    <div class="stat-group" id="stat-loading">
      <div class="stat" aria-busy="true">
        <span>New orders</span>
        <strong>128</strong>
        <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>12.5%</span>
        <span class="loader" role="status" aria-label="Loading"></span>
      </div>
      <div class="stat" aria-busy="true">
        <span>Items ordered</span>
        <strong>342</strong>
        <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>8.1%</span>
        <span class="loader" role="status" aria-label="Loading"></span>
      </div>
    </div>
  </div>
  <div>
    <button type="button" class="btn" data-size="sm" id="stat-busy-btn">Toggle loading</button>
  </div>
</div>
<script>
  const busyBtn = document.getElementById("stat-busy-btn");
  busyBtn.addEventListener("click", () => {
    const group = document.getElementById("stat-loading");
    for (const s of group.children) {
      const busy = s.getAttribute("aria-busy") === "true";
      s.setAttribute("aria-busy", String(!busy));
    }
  });
</script>

Stats that pick what a chart shows

Each stat is a button, and the selected one has aria-pressed="true". data-even on the group makes every cell the same width. 

<div class="card">
  <div class="stat-group" data-even id="stat-pick">
    <button type="button" class="stat" aria-pressed="false">
      <span>New sessions</span>
      <strong>4,812</strong>
      <span data-trend="up"><i class="icon icon-arrow-up" aria-hidden="true"></i>12.4%</span>
    </button>
    <button type="button" class="stat" aria-pressed="false">
      <span>Orders</span>
      <strong>238</strong>
      <span data-trend="down"><i class="icon icon-arrow-down" aria-hidden="true"></i>3.2%</span>
    </button>
    <button type="button" class="stat" aria-pressed="true">
      <span>Sales</span>
      <strong>$6,115</strong>
      <span data-trend="down"><i class="icon icon-arrow-down" aria-hidden="true"></i>5.7%</span>
    </button>
  </div>
</div>
<script>
  document.getElementById("stat-pick").addEventListener("click", (e) => {
    const picked = e.target.closest(".stat");
    if (!picked) return;
    for (const s of e.currentTarget.children) {
      s.setAttribute("aria-pressed", String(s === picked));
    }
  });
</script>

Attributes

Attribute / element Values Description
.stat div, a, button A single figure; a when the whole cell is a link (accent-colored value), button when it picks what to show
> span:first-child 12px gray label, cut off with … when it does not fit; a trailing icon button can open an explanation
> strong 24px value with tabular numbers
> span[data-trend] up, down; empty = gray The change, on the right of the value's row. up = ok color, down = danger color; add a leading icon
> .loader Spinner shown in place of the value when aria-busy="true" (hidden otherwise)
aria-busy true; omit to show the value (default) Hides the value and the change, shows the .loader
aria-pressed true, false On button.stat: the selected one gets a darker gray fill
data-reverse (boolean) Swaps the colors: up is danger, down is ok. For figures where a rise is bad
data-variant danger; omit for normal (default) Red label and value, for counts that signal a problem
data-size sm; omit for normal (default) Small bordered box, centered, for use beside a page title
.stat-group div A row of stats separated by lines. Wraps on narrow screens. Runs edge to edge inside a .card
.stat-group[data-even] (boolean) Every cell gets the same width, but never narrower than its text
dl.stat div > dt + dd + dd Legacy: several cells in one box; dd[data-variant] = ok, danger
