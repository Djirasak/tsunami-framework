Attributes

Attribute / element Values Description
.table table เต็มความกว้าง ตัวเลขกว้างเท่ากัน หัวสีเทาเล็ก เส้นคั่นแถว แถวมีพื้นเทาเมื่อ hover
caption คำอธิบายตาราง สีเทาเล็ก ชิดซ้ายเหนือหัว
thead th หัวคอลัมน์ 12px สีเทา ไม่ตัวหนา ไม่ขึ้นบรรทัดใหม่
tbody th[scope="row"] cell ที่บอกชื่อแถว สีเข้มน้ำหนัก 500
tfoot แถวรวม: เส้นบน ตัวหนา
data-align end; ไม่ใส่ = ชิดซ้าย (default) บน th/td: ชิดขวา สำหรับเงินและตัวเลข
data-truncate (boolean) บน td: ใช้พื้นที่ที่เหลือ ตัดด้วย … ไม่แคบกว่า 8rem; ใส่ข้อความเต็มใน title
td > .avatar / img:first-child รูปหน้าข้อความใน cell (img 32px มุมมน)
th[aria-sort] none, ascending, descending คอลัมน์เรียงได้ ไอคอนตามทิศทาง JS ตั้งค่าเองเมื่อคลิก
th[aria-sort] > button ปุ่มเรียง คลิกสลับ ascending/descending (ใช้ a ถ้าเรียงฝั่ง server)
th[data-sort-type] number, date, text; ไม่ใส่ = ตรวจเอง (default) บังคับชนิดการเรียงของคอลัมน์
td[data-sort-value] ค่าใดก็ได้ ค่าที่ใช้เรียงแทนข้อความ เช่น 2026-03-02
td:first-child > input[type=checkbox] checkbox เลือกแถว แถวที่เลือกมีพื้นเทา (CSS :has)
th:first-child > input[type=checkbox] ใน thead: เลือกทั้งหมด เป็น indeterminate เมื่อเลือกบางแถว
tr[aria-selected] true, false JS ตั้งตาม checkbox ของแถว
.card > .table, .card > .scroll-area > .table ตารางชิดขอบการ์ด
.scroll-area > .table ห่อตารางที่กว้างให้เลื่อนแนวนอนได้บนจอแคบ

API

src/js/table.js ทำงานผ่าน event delegation บน document ใช้กับตารางที่เพิ่มทีหลังได้ทันที ฟังก์ชันอยู่ที่ window.tsunami.table

Function / event Arguments / detail Description
sort(table, columnIndex, direction) table: element, columnIndex: เลข cell ในหัว, direction: "ascending" (default) หรือ "descending" เรียงแถวใน tbody ตั้ง aria-sort คืน false ถ้า event ถูกยกเลิก
select(table, rows, checked) rows: รายการ tr, checked: boolean (default true) เลือก/ยกเลิกแถว แล้วส่ง tsunami:select
selected(table) table: element คืน array ของ tr ที่เลือกอยู่
sync(table) table: element ตั้ง aria-selected และสถานะ checkbox เลือกทั้งหมดใหม่ หลังแก้ checkbox เอง (ทำให้อัตโนมัติตอนโหลดหน้า)
tsunami:sort { column, direction, header } ส่งจาก table ก่อนเรียง bubbles และ cancelable: preventDefault() เพื่อเรียงเอง (เช่นดึงจาก server)
tsunami:select { rows, count } ส่งจาก table ทุกครั้งที่การเลือกเปลี่ยน bubbles
