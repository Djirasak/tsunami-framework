A quiet table: small gray headers, row dividers and tabular numbers. Sort columns and select rows with table.js.

Sortable columns

Add aria-sort to the th and a button inside it. A click toggles ascending and descending. Numbers, dates and text each sort by their own type (a data-sort-value on a cell is used in place of its text, such as an ISO date). For server-side sorting, use an a instead of a button.

Attributes

Attribute / element Values Description
.table table Full width, tabular numbers, small gray headers and row dividers. Rows get a gray fill on hover
caption Table description. Small, gray, left-aligned above the headers
thead th Column header. 12px, gray, not bold, no wrapping
tbody th[scope="row"] Cell that names the row. Dark, weight 500
tfoot Total row: top border, bold
data-align end; omit for left-aligned (default) On th/td: right-aligned, for money and numbers
data-truncate (boolean) On td: takes the remaining space, cut off with …, never narrower than 8rem; put the full text in title
td > .avatar / img:first-child Picture before the text in a cell (img is 32px with rounded corners)
th[aria-sort] none, ascending, descending Sortable column with a direction icon. JS sets it on click
th[aria-sort] > button Sort button. A click toggles ascending/descending (use a for server-side sorting)
th[data-sort-type] number, date, text; omit to detect (default) Forces the column's sort type
td[data-sort-value] Any value Value to sort by instead of the text, such as 2026-03-02
td:first-child > input[type=checkbox] Row checkbox. Selected rows get a gray fill (CSS :has)
th:first-child > input[type=checkbox] In thead: selects all. Indeterminate when some rows are selected
tr[aria-selected] true, false Set by JS from the row's checkbox
.card > .table, .card > .scroll-area > .table Table runs to the card's edges
.scroll-area > .table Wraps a wide table so it scrolls horizontally on narrow screens

API

src/js/table.js uses event delegation on document, so it works on tables added later right away. The functions live at window.tsunami.table.

Function / event Arguments / detail Description
sort(table, columnIndex, direction) table: element, columnIndex: index of the header cell, direction: "ascending" (default) or "descending" Sorts the rows in tbody and sets aria-sort. Returns false if the event was canceled
select(table, rows, checked) rows: a list of tr, checked: boolean (default true) Selects or deselects rows, then fires tsunami:select
selected(table) table: element Returns an array of the selected tr elements
sync(table) table: element Resets aria-selected and the select-all checkbox state after you change checkboxes yourself (runs on page load automatically)
tsunami:sort { column, direction, header } Fired on the table before sorting. Bubbles and is cancelable: call preventDefault() to sort yourself (such as fetching from the server)
tsunami:select { rows, count } Fired on the table whenever the selection changes. Bubbles
