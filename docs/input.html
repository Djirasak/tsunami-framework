Input

Input

ช่องกรอกข้อมูล input, file และ textarea ใช้ .input เมื่อวางเดี่ยว หรือวางใน .field ได้เลยโดยไม่ต้องใส่ class

ช่องเดี่ยว Standalone input

นอก .field ใส่ class="input" และ aria-label เพราะไม่มีป้ายให้เห็น ใน .field ช่องจะได้หน้าตาเดียวกันโดยไม่ต้องใส่ class 

<div class="stack docs-narrow">
  <input class="input" type="email" placeholder="อีเมลลูกค้า Customer email" aria-label="อีเมลลูกค้า Customer email" />
  <div class="field">
    <label for="in-sku">รหัสสินค้า SKU</label>
    <input id="in-sku" type="text" value="TS-001-BLK" />
  </div>
</div>

ขนาด sm, default และ lg Sizes

data-size ใช้ได้ทั้งบน .input และช่องใน .field 

<div class="stack docs-narrow">
  <input class="input" data-size="sm" type="text" placeholder="เล็ก Small" aria-label="Small input" />
  <input class="input" type="text" placeholder="ปกติ Default" aria-label="Default input" />
  <input class="input" data-size="lg" type="text" placeholder="ใหญ่ Large" aria-label="Large input" />
</div>

แต่ละขนาดคู่กับปุ่มขนาดเดียวกัน Each size beside the button of the same size

ความสูงของ input เท่ากับ .btn ขนาดเดียวกัน (26, 32, 40px) จึงวางคู่กันในแถวได้พอดี 

<div class="stack">
  <div class="stack" data-direction="row" data-gap="sm">
    <input class="input" data-size="sm" type="text" placeholder="โค้ดส่วนลด Discount code" aria-label="Discount code" style="width: 14rem" />
    <button type="button" class="btn" data-size="sm">ใช้โค้ด Apply</button>
  </div>
  <div class="stack" data-direction="row" data-gap="sm">
    <input class="input" type="text" placeholder="โค้ดส่วนลด Discount code" aria-label="Discount code" style="width: 14rem" />
    <button type="button" class="btn">ใช้โค้ด Apply</button>
  </div>
  <div class="stack" data-direction="row" data-gap="sm">
    <input class="input" data-size="lg" type="text" placeholder="โค้ดส่วนลด Discount code" aria-label="Discount code" style="width: 14rem" />
    <button type="button" class="btn" data-size="lg">ใช้โค้ด Apply</button>
  </div>
</div>

ปิดใช้งาน Disabled

<div class="stack docs-narrow">
  <input class="input" type="email" value="somjai@example.com" aria-label="อีเมล Email" disabled />
</div>

เลือกไฟล์ File

ปุ่มเลือกไฟล์ของเบราว์เซอร์ถูกวาดชิดในกรอบ ใช้ accept และ multiple ตามปกติ

ไม่เกิน 5 MB Up to 5 MB 
<div class="stack docs-narrow">
  <input class="input" type="file" accept="image/*" aria-label="อัปโหลดรูปสินค้า Upload product image" />
  <div class="field">
    <label for="in-csv">นำเข้าสินค้า Import products (CSV)</label>
    <input id="in-csv" type="file" accept=".csv" aria-describedby="in-csv-hint" />
    <small id="in-csv-hint">ไม่เกิน 5 MB Up to 5 MB</small>
  </div>
</div>

มีไอคอนและข้อความข้างช่อง With an icon and text beside the field

ใช้ .input-group: <span> ที่อยู่ก่อนหรือหลัง input จะอยู่ด้านหน้าหรือท้ายตามลำดับใน HTML ดูเพิ่มที่หน้า Input group

12 รายการ results 
<div class="stack docs-narrow">
  <div class="input-group">
    <span><i class="icon icon-search" aria-hidden="true"></i></span>
    <input type="search" placeholder="ค้นหาคำสั่งซื้อ Search orders" aria-label="ค้นหาคำสั่งซื้อ Search orders" />
    <span>12 รายการ results</span>
  </div>
</div>

Ghost สำหรับช่องค้นหาในหัวการ์ด Ghost, for a search field in a card header

data-variant="ghost" ไม่มีกรอบและพื้น จึงกลืนไปกับหัวการ์ด กรอบสี accent ขึ้นเมื่อโฟกัส

สินค้า Product ราคา Price
เสื้อยืด T-shirt ฿390
กระเป๋าผ้า Tote bag ฿250 
<div class="card">
  <header>
    <div class="input-group" data-variant="ghost">
      <span><i class="icon icon-search" aria-hidden="true"></i></span>
      <input type="search" placeholder="ค้นหาจากชื่อสินค้า Search by product title" aria-label="ค้นหาจากชื่อสินค้า Search by product title" />
    </div>
  </header>
  <table class="table">
    <thead>
      <tr><th scope="col">สินค้า Product</th><th scope="col">ราคา Price</th></tr>
    </thead>
    <tbody>
      <tr><td>เสื้อยืด T-shirt</td><td>฿390</td></tr>
      <tr><td>กระเป๋าผ้า Tote bag</td><td>฿250</td></tr>
    </tbody>
  </table>
</div>

ช่องข้อความหลายบรรทัด Textarea

<textarea class="input"> สูงอย่างน้อย 5rem ผู้ใช้ลากขยายแนวตั้งได้ ใช้ rows กำหนดความสูงเริ่มต้น 

<div class="stack docs-narrow">
  <textarea class="input" placeholder="พิมพ์ข้อความถึงลูกค้า Type your message here" aria-label="ข้อความ Message"></textarea>
</div>

Attributes

Attribute / element Values Description
.input บน input / select / textarea ที่อยู่นอก .field ช่องใน .field ได้หน้าตาเดียวกันโดยไม่ต้องใส่
data-size sm, lg (ไม่มี = default 32px) ความสูง 26 / 32 / 40px เท่ากับ .btn ขนาดเดียวกัน
data-variant ghost (ไม่มี = มีกรอบ) ไม่มีกรอบและพื้น ขอบ accent เมื่อโฟกัส
type="file" ปุ่มเลือกไฟล์ชิดซ้ายในกรอบ
textarea.input สูงอย่างน้อย 5rem ลากขยายแนวตั้ง
placeholder ข้อความตัวอย่างสีเทา ไม่ใช้แทน label
aria-label จำเป็นเมื่อไม่มี <label> ให้เห็น
aria-invalid true ขอบสี danger
disabled พื้น subtle ตัวอักษรเทา เคอร์เซอร์ not-allowed
