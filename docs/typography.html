Typography

Typography

One typeface, Google Sans, for both Thai and Latin. Base size 14px, line-height 1.55. Wrap long content in .prose to get spacing, lists and quotes.

Headings: h1 to h6

The base style resets the margin of every element. Add class="prose" to a wrapper to give headings, paragraphs and lists article spacing.

A full article

Shipping protection

Cover orders that are lost, stolen or damaged on the way to the customer.

How it works

Customers add protection at checkout for $2.99. If a parcel does not arrive, the customer opens a claim from the order status page and chooses a refund or a reshipment.

What is covered

  • Parcels marked as delivered that never arrived
  • Items damaged in transit
  • Parcels lost by the carrier

Claims can be opened within 30 days of the ship date.

Setting it up

  1. Open Settings and go to Shipping.
  2. Turn on protection and set the price.
  3. Save. A shipping-protection product is created for you.

Thai and Latin

Google Sans covers both scripts, so Thai and Latin share one baseline and line-height. Mark Thai text with lang="th".

คำสั่งซื้อเปลี่ยนเป็น Fulfilled เมื่อจัดส่งสินค้าครบทุกรายการ

An order becomes Fulfilled once every item has shipped.

Attributes

Attribute / element Values Description
.prose class Wrapper for long content. Adds spacing between blocks and styles h1-h6, list markers, quotes, pre and hr.
p[data-variant] lead, muted (omit for default) lead: 16px grey, muted: grey. Used in .prose.
small 12px grey in .prose.
ul, ol, li Markers disc / circle (nested) / decimal in --muted.
dl > dt, dd Two columns: dt is a grey label, dd is the value.
blockquote 2px --line on the left, grey text.
pre > code Code block on --subtle. Scrolls horizontally.
code, mark, del, ins, abbr[title], sub, sup, a, strong Inline styles in .prose (underlined links, mark on --warning-bg).
hr 1px --line with 24px space above and below in .prose.
.kbd class Keyboard key that works anywhere. In .prose, a plain <kbd> works.
