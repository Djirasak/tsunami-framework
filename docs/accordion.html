Accordion

รายการพับได้จาก <details> ของ browser ไม่ต้องใช้ JS

การใช้งาน Usage

แต่ละรายการคือ <details> ที่มี <summary> (มีลูกศรให้เอง) ใส่ name เดียวกันทุกอันเพื่อให้เปิดได้ทีละอัน เปิดอันใหม่แล้วอันเดิมปิดเอง และใส่ open ให้อันที่ต้องเปิดไว้ก่อน

จัดส่งกี่วัน How long is shipping?

2-3 วันทำการในกรุงเทพฯ 2-3 business days in Bangkok.

คืนสินค้าได้ไหม Can I return items?

คืนได้ภายใน 30 วัน Within 30 days of delivery.

ชำระเงินแบบไหนได้บ้าง Payment methods

บัตรเครดิต, PromptPay และโอนผ่านธนาคาร Card, PromptPay and bank transfer. 

<div class="accordion">
  <details name="faq" open>
    <summary>จัดส่งกี่วัน How long is shipping?</summary>
    <p>2-3 วันทำการในกรุงเทพฯ 2-3 business days in Bangkok.</p>
  </details>
  <details name="faq">
    <summary>คืนสินค้าได้ไหม Can I return items?</summary>
    <p>คืนได้ภายใน 30 วัน Within 30 days of delivery.</p>
  </details>
  <details name="faq">
    <summary>ชำระเงินแบบไหนได้บ้าง Payment methods</summary>
    <p>บัตรเครดิต, PromptPay และโอนผ่านธนาคาร Card, PromptPay and bank transfer.</p>
  </details>
</div>

รายการที่ปิดใช้งาน A disabled item

ใส่ aria-disabled="true" ที่ <details> และ tabindex="-1" ที่ <summary> รายการจะเป็นสีเทา คลิกและ Tab ไปไม่ได้

บัตรเครดิต Credit card

Visa, Mastercard, JCB

เก็บเงินปลายทาง Cash on delivery (ยังไม่เปิด Not available)

ยังไม่รองรับ Not supported yet.

<div class="accordion">
  <details name="pay">
    <summary>บัตรเครดิต Credit card</summary>
    <p>Visa, Mastercard, JCB</p>
  </details>
  <details name="pay" aria-disabled="true">
    <summary tabindex="-1">เก็บเงินปลายทาง Cash on delivery (ยังไม่เปิด Not available)</summary>
    <p>ยังไม่รองรับ Not supported yet.</p>
  </details>
</div>

ฟังเหตุการณ์ toggle Listen for toggle

toggle เป็นเหตุการณ์ของ browser ส่งจาก <details> ทุกครั้งที่เปิดหรือปิด ไม่ bubble จึงต้องฟังแบบ capture ที่ตัวกล่อง (หรือฟังที่ details แต่ละอัน) อ่านสถานะจาก event.newState หรือ details.open เปิดหรือปิดด้วยโค้ดโดยตั้ง details.open = true

Kerry Express

1-2 วัน ฿45.00

ไปรษณีย์ไทย Thailand Post

2-4 วัน ฿35.00

ยังไม่มีการเปิด Nothing opened yet 

<div class="stack" data-gap="sm">
  <div class="accordion" id="acc-events">
    <details name="ship">
      <summary>Kerry Express</summary>
      <p>1-2 วัน ฿45.00</p>
    </details>
    <details name="ship">
      <summary>ไปรษณีย์ไทย Thailand Post</summary>
      <p>2-4 วัน ฿35.00</p>
    </details>
  </div>
  <p id="acc-events-output">ยังไม่มีการเปิด Nothing opened yet</p>
  <div>
    <button type="button" class="btn" data-size="sm" id="acc-events-open">เปิดอันแรกด้วยโค้ด Open the first</button>
  </div>
</div>
<script type="module">
  const accordion = document.getElementById("acc-events");
  const output = document.getElementById("acc-events-output");
  // toggle does not bubble: listen in the capture phase.
  accordion.addEventListener(
    "toggle",
    () => {
      const open = accordion.querySelector("details[open] > summary");
      output.textContent = open ? `เปิดอยู่ Open: ${open.textContent}` : "ปิดทั้งหมด All closed";
    },
    { capture: true },
  );
  document.getElementById("acc-events-open").addEventListener("click", () => {
    accordion.querySelector("details").open = true;
  });
</script>

API

Accordion ไม่มี JS ของตัวเอง ใช้ property และเหตุการณ์ของ <details> ได้เลย

Property / event / key Values / detail Description
details.open true, false อ่านหรือตั้งเพื่อเปิด/ปิดรายการด้วยโค้ด
toggle event.oldState, event.newState: "open" / "closed" ส่งจาก details หลังเปิดหรือปิด ไม่ bubble (ฟังแบบ { capture: true } ที่ .accordion)
Enter, Space บน summary: เปิดหรือปิดรายการ (ของ browser เอง)

Attributes

Attribute / element Values Description
.accordion กล่องมีกรอบ รายการคั่นด้วยเส้น
> details หนึ่งรายการ
details[name] ข้อความ; ไม่ใส่ = เปิดได้หลายอัน (ค่าเริ่มต้น) ชื่อเดียวกันทั้งกลุ่ม เปิดได้ทีละอัน (browser ปิดอันอื่นให้)
details[open] มี / ไม่มี; ไม่มี = ปิด (ค่าเริ่มต้น) รายการเปิดอยู่ browser ใส่และเอาออกเอง เขียนไว้เพื่อเปิดตั้งแต่ต้น
details[aria-disabled] true ปิดใช้งาน: summary สีเทา คลิกไม่ได้ ใส่ tabindex="-1" ที่ summary ด้วย
summary หัวข้อ มีลูกศรด้านขวา หมุนเมื่อเปิด
details > :not(summary) เนื้อหา (p, div, section ...) สีเทา เยื้องตรงกับหัวข้อ
