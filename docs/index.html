Tsunami 津波

A small CSS framework for back-office screens. Quiet, dense and practical. Written with semantic HTML and data attributes, with no runtime dependencies.

Get started Browse components

Principles

Native first

Reach for dialog, popover, details and button first. JS covers only theme, tabs and the save bar.

Zero specificity

Every selector sits in @layer components and :where(), so your CSS overrides it right away.

Light / Dark

Themes switch through CSS custom properties, following the system or the user's choice, with no flash on load.

Thai + Latin

One self-hosted woff2 Google Sans for both Thai and Latin. Table numbers use tabular-nums.

ภาษาไทยกับ Latin ในบรรทัดเดียวกัน 1,234.50

Install

Add the files from dist/, plus this script in <head> to stop the theme from flashing. 

<link rel="stylesheet" href="dist/tsunami.min.css">
<script>
  try {
    const t = localStorage.getItem("tsunami-theme");
    if (t) document.documentElement.dataset.theme = t;
  } catch {}
</script>
<script type="module" src="dist/tsunami.min.js"></script>
