Image field

ช่องรูปภาพที่มีปุ่มเปลี่ยนและล้างรูป ฟอร์มเป็นตัวส่งไฟล์ An image with change and clear buttons; the form sends the file.

ตัวอย่าง: ชี้ที่รูปเพื่อแสดงปุ่มเปลี่ยนและล้าง Preview: point at the image for the change and clear buttons

แสดงในแท็บเบราว์เซอร์และบุ๊กมาร์ก Shown in browser tabs and bookmarks. 
<div class="field">
  <label for="if-icon">ไอคอนร้าน Store icon</label>
  <div class="image-field">
    <img src="img/logo-acme.svg" alt="ไอคอนร้านปัจจุบัน Current store icon">
    <i class="icon icon-image" aria-hidden="true"></i>
    <button type="button" class="btn" data-size="icon-xs" id="if-icon" data-change aria-label="เปลี่ยนไอคอนร้าน Change store icon" data-tooltip="เปลี่ยน Change"><i class="icon icon-pencil" aria-hidden="true"></i></button>
    <button type="button" class="btn" data-size="icon-xs" data-clear aria-label="ล้างไอคอนร้าน Clear store icon" data-tooltip="ล้าง Clear"><i class="icon icon-x" aria-hidden="true"></i></button>
    <input type="file" name="icon" accept="image/*">
  </div>
  <small>แสดงในแท็บเบราว์เซอร์และบุ๊กมาร์ก Shown in browser tabs and bookmarks.</small>
</div>

data-fit="contain" แสดงรูปทั้งรูปในกล่องกว้าง สำหรับโลโก้ Shows the whole image in a wide box, for a logo 

<div class="field">
  <label for="if-logo">โลโก้ร้าน Store logo</label>
  <div class="image-field" data-fit="contain" style="width: 18rem">
    <img src="img/logo-acme.svg" alt="โลโก้ร้านปัจจุบัน Current store logo">
    <i class="icon icon-image" aria-hidden="true"></i>
    <button type="button" class="btn" data-size="icon-xs" id="if-logo" data-change aria-label="เปลี่ยนโลโก้ Change store logo" data-tooltip="เปลี่ยน Change"><i class="icon icon-pencil" aria-hidden="true"></i></button>
    <button type="button" class="btn" data-size="icon-xs" data-clear aria-label="ล้างโลโก้ Clear store logo" data-tooltip="ล้าง Clear"><i class="icon icon-x" aria-hidden="true"></i></button>
    <input type="file" name="logo" accept="image/*">
  </div>
</div>

data-empty: ยังไม่มีรูป จึงแสดงไอคอนและปุ่มเลือกเท่านั้น No image yet: the icon and only the change button

  <label for="if-empty">รูปหมวดหมู่ Category image</label>

    <img alt="รูปหมวดหมู่ปัจจุบัน Current category image">
    <i class="icon icon-image" aria-hidden="true"></i>
    <button type="button" class="btn" data-size="icon-xs" id="if-empty" data-change aria-label="เลือกรูปหมวดหมู่ Choose a category image" data-tooltip="เลือก Choose"><i class="icon icon-pencil" aria-hidden="true"></i></button>
    <button type="button" class="btn" data-size="icon-xs" data-clear aria-label="ล้างรูปหมวดหมู่ Clear category image" data-tooltip="ล้าง Clear"><i class="icon icon-x" aria-hidden="true"></i></button>
    <input type="file" name="image" accept="image/*">
  </div>
</div>

checkbox ในช่องจะถูกติ๊กเมื่อล้างรูป และฟอร์มได้รับ change A checkbox is checked while the image is cleared, and the form hears change

icon-clear: ไม่ได้ส่ง not sent

      <button type="button" class="btn" data-size="icon-xs" data-clear aria-label="ล้างไอคอนร้าน Clear store icon" data-tooltip="ล้าง Clear"><i class="icon icon-x" aria-hidden="true"></i></button>

<script>
  document.getElementById("if-form").addEventListener("change", (event) => {
    const sent = new FormData(event.currentTarget).get("icon-clear");
    document.getElementById("if-result").textContent = "icon-clear: " + (sent ?? "ไม่ได้ส่ง not sent");
  });
</script>

API

ช่องนี้ไม่อัปโหลดเอง ฟอร์มที่มันอยู่เป็นตัวส่งไฟล์ อ่านไฟล์จาก input ได้โดยตรง The field never uploads; the form sends the file. Read it through the input.

Event On Description
input, change input[type=file], bubbles ส่งเมื่อเลือกไฟล์ (โดยเบราว์เซอร์) และเมื่อล้างรูป หลังล้าง event.target.files ว่าง Sent when a file is chosen and when the image is cleared.
Key Description
Tab ไปที่ปุ่มเปลี่ยน แล้วปุ่มล้าง ปุ่มทั้งสองแสดงเมื่อปุ่มใดปุ่มหนึ่งมี focus Moves to the change button, then the clear button.
Enter, Space ปุ่มเปลี่ยนเปิดตัวเลือกไฟล์ ปุ่มล้างล้างรูปแล้วย้าย focus ไปปุ่มเปลี่ยน Change opens the picker; clear empties the field and focuses change.

Attributes

Attribute / element Values Description
.image-field กล่องสี่เหลี่ยม 96px ล้อม img, ไอคอน, ปุ่ม และ input A 96px square box.
data-fit contain แสดงรูปทั้งรูปในกล่อง 2:1 ค่าเริ่มต้น (ไม่ใส่) รูปเต็มกล่องและถูกครอป Default: the image fills the box and is cropped.
data-empty present ตั้งโดยสคริปต์ขณะไม่มีรูป เขียนเองได้เพื่อให้ถูกตั้งแต่ก่อนสคริปต์ทำงาน Set by the script while there is no image.
> img[src] URL รูปเริ่มต้น ไม่มี src = ว่าง The starting image; without src the field is empty.
> .icon ไอคอนที่แสดงเมื่อว่าง เช่น icon-image Shown while empty.
> [data-change] button เปิดตัวเลือกไฟล์ ต้องมี Opens the file picker. Required.
> [data-clear] button ล้างรูป ไม่ใส่ถ้ารูปลบไม่ได้ Clears the image; leave out if it cannot be removed.
> input[type=file] name, accept ส่งไฟล์ไปกับฟอร์ม Sends the chosen file with the form.
> input[type=checkbox] name ไม่บังคับ ติ๊กเมื่อล้างรูป เพื่อบอก server ให้ลบไฟล์ Optional; checked while cleared.
aria-label, data-tooltip text บนปุ่มไอคอนทั้งสอง On both icon buttons.
