Sidebar

เมนูหลักของแอปด้านซ้าย ย่อเหลือไอคอนได้ App navigation on the left, collapsible to icons.

การใช้งาน Usage

nav แบ่งเป็น header / section / footer แต่ละกลุ่มเป็น [role="group"] มี h3 กับ ul ลิงก์ย่อยเป็น ul ซ้อนใน li ปุ่มท้ายเมนูย่อ/ขยายด้วย command="--toggle-collapsed"

ย่อเหลือไอคอน พร้อม tooltip Collapsed to icons, with tooltips

data-collapsed="true" ซ่อนหัวข้อ ลิงก์ย่อย และ badge ชื่อใน span ของลิงก์กลายเป็น tooltip เมื่อชี้หรือโฟกัส ลิงก์ระดับบนสุดจึงควรมีไอคอนทุกอัน ใช้คู่กับ Subnav

  • หน้าหลัก Home
  • สินค้า Products
  • คำสั่งซื้อ Orders
  • ลูกค้า Customers

  <nav aria-label="เมนูหลัก Main">

API

อยู่ใน js/sidebar.js sidebar ไม่ส่ง event ของตัวเอง อ่านสถานะจาก data-collapsed

Function Arguments Description
tsunami.sidebar.collapse(sidebar) sidebar: element .sidebar ย่อเหลือไอคอน (ตั้ง data-collapsed="true")
tsunami.sidebar.expand(sidebar) sidebar: element กลับเป็นความกว้างเต็ม (data-collapsed="false")
tsunami.sidebar.toggle(sidebar) sidebar: element สลับย่อ/ขยาย
command="--toggle-collapsed" ปุ่มที่มี commandfor="sidebar-id" สลับย่อ/ขยาย จากปุ่มที่อยู่ตรงไหนก็ได้ ไม่ต้องเขียน JS ยังมี --collapse และ --expand

Attributes

Attribute / element Values Description
.sidebar aside กว้าง 15rem สูงเต็มจอ เลื่อนในตัวเอง แอปเรียงเป็นแถวกับ element ถัดไปให้เอง
popover + id บน .sidebar ต่ำกว่า 48rem เป็น drawer เปิดด้วยปุ่ม .sidebar-toggle[popovertarget] ตั้งแต่ 48rem แสดงตลอด
data-collapsed ไม่ใส่ / false (default) เต็ม · true ไอคอน ย่อเหลือคอลัมน์ไอคอน 3.5rem ชื่อลิงก์เป็น tooltip
nav child ใส่ aria-label ลิงก์กับ h2 ตรง ๆ ก็ได้ หรือแบ่งเป็น header / section / footer
nav > header child ส่วนบน เช่น ชื่อร้านพร้อม .avatar
nav > section child กลุ่มเมนู เว้นระยะระหว่างกลุ่ม
nav > footer child ชิดล่าง เช่น ปุ่มย่อ/ขยาย
[role="group"] div กลุ่มลิงก์ ใส่ aria-labelledby ชี้ไปที่ h3
h2, h3 ใน nav หัวข้อกลุ่ม ตัวเล็กสีเทา
ul > li > a ใน nav ลิงก์ ไอคอน .icon หรือ img 16px ตามด้วยชื่อใน span
li > ul ลิงก์ย่อย ย่อหน้าบนเส้นนำ ซ่อนเมื่อย่อ
.badge ใน a ป้ายท้ายลิงก์ เช่น ใหม่ New ซ่อนเมื่อย่อ
hr ใน section เส้นคั่นกลุ่ม
aria-current page บน a: หน้าปัจจุบัน พื้นเทา ตัวหนาปานกลาง
