Subnav

เมนูรองของหมวด อยู่ข้างเนื้อหา Section links beside the content.

ข้าง sidebar ที่ย่อไว้ตลอด Beside a sidebar that stays collapsed

หน้าตั้งค่าที่มีหลายหมวด: sidebar หลักย่อเหลือไอคอน (data-collapsed="true") แล้ว subnav แสดงหมวดย่อย element ที่ตามหลัง .subnav คือเนื้อหา ได้ระยะขอบให้ ต่ำกว่า 48rem subnav อยู่เหนือเนื้อหา

Attributes

Attribute / element Values Description
.subnav nav เมนูรอง กว้าง 13rem ใส่ aria-label
h2 child ชื่อหมวด ตัวหนาปานกลาง
ul > li > a child ลิงก์ .icon + ชื่อใน span (ใส่ a ตรง ๆ ไม่มี ul ก็ได้)
aria-current page บน a: หมวดที่เปิดอยู่
.subnav + * element ถัดไป เนื้อหา: กินพื้นที่ที่เหลือ มีระยะขอบ parent เรียงเป็นแถวตั้งแต่ 48rem มีเส้นคั่นขวา ต่ำกว่านั้นซ้อนลง มีเส้นคั่นล่าง
.sidebar[data-collapsed="true"] ข้าง ๆ sidebar หลักที่ย่อเหลือไอคอน ดูหน้า Sidebar
