Popover

[popover] แบบ native เปิดด้วยปุ่ม popovertarget และวางติดกับปุ่มด้วย CSS anchor positioning ไม่ต้องใช้ JS. A native popover, opened by its button and placed beside it with no script.

ป๊อปโอเวอร์ที่เปิดด้วยปุ่ม A popover opened by a button

ปุ่มชี้ไปที่ id ของป๊อปโอเวอร์ด้วย popovertarget. A click outside or Escape closes it, and opening another popover closes this one. The popover lines up with the start of the button, below it.

ค่าธรรมเนียมบัตร Card fees

คิดต่อธุรกรรม Charged per transaction.

2.9% + ฿10

<button type="button" class="btn" popovertarget="pop-fees"><i class="icon icon-info" aria-hidden="true"></i>ค่าธรรมเนียม Fees</button>
<div class="popover" id="pop-fees" popover>
  <header>
    <h3>ค่าธรรมเนียมบัตร Card fees</h3>
    <p>คิดต่อธุรกรรม Charged per transaction.</p>
  </header>
  <p><strong>2.9% + ฿10</strong></p>
</div>

ด้าน: ล่าง บน ซ้าย และขวาของปุ่ม Side: below, above, left and right of the button

data-side บนป๊อปโอเวอร์. When the popover does not fit, it flips to the opposite side.

ล่าง Bottom

เปิดใต้ปุ่ม ค่าเริ่มต้น Opens below the button. The default.

บน Top

เปิดเหนือปุ่ม Opens above the button.

ซ้าย Left

เปิดทางซ้าย Opens to the left of the button.

ขวา Right

เปิดทางขวา Opens to the right of the button.

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" popovertarget="pop-side-bottom">ล่าง Bottom</button>
  <div class="popover" id="pop-side-bottom" popover>
    <header><h3>ล่าง Bottom</h3><p>เปิดใต้ปุ่ม ค่าเริ่มต้น Opens below the button. The default.</p></header>
  </div>
  <button type="button" class="btn" popovertarget="pop-side-top">บน Top</button>
  <div class="popover" id="pop-side-top" popover data-side="top">
    <header><h3>บน Top</h3><p>เปิดเหนือปุ่ม Opens above the button.</p></header>
  </div>
  <button type="button" class="btn" popovertarget="pop-side-left">ซ้าย Left</button>
  <div class="popover" id="pop-side-left" popover data-side="left">
    <header><h3>ซ้าย Left</h3><p>เปิดทางซ้าย Opens to the left of the button.</p></header>
  </div>
  <button type="button" class="btn" popovertarget="pop-side-right">ขวา Right</button>
  <div class="popover" id="pop-side-right" popover data-side="right">
    <header><h3>ขวา Right</h3><p>เปิดทางขวา Opens to the right of the button.</p></header>
  </div>
</div>

การจัดแนว: ต้น กลาง และท้ายของปุ่ม Alignment: start, center and end of the button

data-align: for a popover on the left or right, start is the top edge of the button and end its bottom edge.

ต้น Start

ชิดขอบต้นของปุ่ม ค่าเริ่มต้น Lines up with the start of the button. The default.

กลาง Center

อยู่กึ่งกลางปุ่ม Centred on the button.

ท้าย End

ชิดขอบท้ายของปุ่ม Lines up with the end of the button.

  </div>
  <button type="button" class="btn" popovertarget="pop-align-end">ท้าย End</button>
  <div class="popover" id="pop-align-end" popover data-align="end">

API

Methods (native)

Member Type Description
showPopover() method เปิด. Opens the popover; any other open auto popover closes.
hidePopover() method ปิด. Closes the popover.
togglePopover(force?) method สลับเปิดปิด. Opens it when closed, closes it when open; force picks one. Returns the new state.
:popover-open CSS ตรงเมื่อเปิดอยู่. Matches while it is open: el.matches(":popover-open").

Events (native)

Event Detail Description
beforetoggle oldState, newState ("open" / "closed") ก่อนเปิดหรือปิด. Before it opens or closes; preventDefault() stops an opening.
toggle oldState, newState หลังเปิดหรือปิด. After it has opened or closed.

Keyboard

Key Description
Enter / Space บนปุ่ม: เปิดหรือปิด. On the button: opens or closes the popover.
Tab จากปุ่มเข้าไปในป๊อปโอเวอร์ (ลำดับถัดจากปุ่ม). From the button into the popover, which comes next in the focus order.
Esc ปิดป๊อปโอเวอร์ และคืนโฟกัสให้ปุ่ม. Closes the popover only; a dialog around it stays open.

ไม่มี JS: ทั้งหมดเป็นของเบราว์เซอร์. No script. Without CSS anchor positioning the browser shows the popover in the middle of the window.

Attributes

Attribute / element Values Description
class="popover" on the panel สไตล์ป๊อปโอเวอร์. The component: a bordered panel up to 20rem wide.
popover none or auto (default), manual ทำให้เป็นป๊อปโอเวอร์. auto closes on an outside click, Escape, or another popover; manual only by its button.
id unique id ให้ปุ่มชี้มา. What the button's popovertarget names.
popovertarget the popover's id บนปุ่มที่เปิด. On the button; also makes it the anchor the popover is placed against.
popovertargetaction toggle (default), show, hide บนปุ่ม. What a click on the button does.
data-side none or bottom (default), top, left, right ด้านของปุ่มที่เปิด. Flips to the other side when it does not fit.
data-align none or start (default), center, end จัดแนวกับปุ่ม. Start/end: left/right edge below or above; top/bottom edge on the left or right.
> header h3, .badge, p ชื่อเรื่องกับ badge บรรทัดเดียว p บรรทัดใหม่. Title and count on one row, description below.
autofocus on a control in the popover ได้โฟกัสเมื่อเปิด. Takes focus when the popover opens.
