Dialog

Dialog

A native modal <dialog>, opened and closed by buttons with commandfor and command. No script needed.

The markup: a dialog with a header, a div and a footer

The parts are direct children of <dialog>: <header> (title, description, close button), <div> (body) and <footer> (buttons). Tsugi wraps the parts in one child; Tsunami puts them straight in the dialog, or in a <form method="dialog">. Every part is optional.

Edit customer

Change the details, then save.

 
<button type="button" class="btn" commandfor="dlg-edit" command="show-modal">Edit customer</button>
<dialog class="dialog" id="dlg-edit" aria-labelledby="dlg-edit-title" aria-describedby="dlg-edit-desc" closedby="any">
  <header>
    <h2 id="dlg-edit-title">Edit customer</h2>
    <p id="dlg-edit-desc">Change the details, then save.</p>
    <button type="button" class="btn" data-variant="ghost" data-size="icon" commandfor="dlg-edit" command="close" aria-label="Close"><i class="icon icon-x" aria-hidden="true"></i></button>
  </header>
  <div class="stack">
    <div class="field">
      <label for="dlg-edit-name">Name</label>
      <input id="dlg-edit-name" type="text" value="Emma Wilson" autofocus>
    </div>
    <div class="field">
      <label for="dlg-edit-email">Email</label>
      <input id="dlg-edit-email" type="email" value="emma@example.com">
    </div>
  </div>
  <footer>
    <button type="button" class="btn" commandfor="dlg-edit" command="close">Cancel</button>
    <button type="button" class="btn" data-variant="primary" commandfor="dlg-edit" command="close">Save changes</button>
  </footer>
</dialog>

Buttons open and close it with commandfor and command

command="show-modal" matches Tsugi's data-dialog-open, and command="close" matches data-dialog-close. The button names the dialog's id in commandfor; the browser calls showModal() or close(). Esc closes it too.

A click on the backdrop closes it; closedby keeps it open

closedby="any": Escape and a click on the backdrop close it. No closedby: only Escape closes it (like Tsugi's data-dialog-static). closedby="none": only a button closes it. A browser without closedby support ignores it: Escape still closes the dialog.

Escape or a click on the backdrop closes it.

A form with method="dialog" closes it, and the page reads returnValue

A submit button in a <form method="dialog"> closes the dialog without sending the form, and its value becomes returnValue. Read it in the close event. Escape leaves it empty. A close button with command="close" and a value sets it the same way.

An alert dialog asks a question the user has to answer

role="alertdialog" on .dialog: no dividers and no close button. Use it to confirm something that cannot be undone. Leave closedby out so a stray click on the backdrop does not answer; Escape still cancels.

API

Methods and properties (native)

Member Type Description
showModal() method Opens the dialog over the dimmed page; what command="show-modal" calls.
close(returnValue?) method Closes it; the optional string becomes returnValue. What command="close" calls.
requestClose(returnValue?) method Like Escape: fires cancel first, which can keep it open. command="request-close".
returnValue property The value from close(value) or from the value of the button that submits a method="dialog" form. Not reset on open: clear it yourself.
open property true while open. Do not set the open attribute by hand: that dialog is not modal.

Events (native)

Event Detail Description
close none After the dialog has closed, however it closed. Read returnValue here.
cancel none Before Escape (or a backdrop click) closes it; preventDefault() keeps it open.

Keyboard

Key Description
Esc Closes the dialog, unless closedby="none"; a popover open inside it closes first.
Tab Moves between the controls of the dialog only.
Enter In a field: submits the form, which closes the dialog when it has method="dialog".

Everything here is the browser's own dialog element; Tsunami adds only styles.

Attributes

Attribute / element Values Description
class="dialog" on <dialog> The component.
data-size sm (24rem), none (default, 32rem), lg (42rem), xl (56rem) Width; never wider than the window less 1rem each side.
role="alertdialog" on the dialog A question with answers; with data-size="sm" it is centred and its two buttons are equal width.
aria-labelledby id of the <h2> Names the dialog. Required.
aria-describedby id of the <p> Reads the line under the title as the description.
closedby any, closerequest (default for a modal), none any: Escape and a backdrop click; closerequest: Escape only; none: buttons only.
commandfor + command dialog id + show-modal, close, request-close On a button: opens or closes the dialog it names.
value text, on a close or submit button Becomes the dialog's returnValue.
autofocus on a control in the dialog The control that gets focus on open. Without it the first focusable control does.
> form[method=dialog] optional wrapper Wraps the parts; a submit closes the dialog.
> header h2, p, close button, figure The close button sits at the end of the first row.
> header > figure data-variant: none (gray, default), ok, danger, warning, info A round icon beside the title.
> div any content The body; scrolls when it is long.
> footer buttons Buttons at the end, main action last.
