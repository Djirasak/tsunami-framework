Dialog

<dialog> แบบ native เปิดด้วย commandfor + command ไม่ต้องใช้ JS. A native modal dialog, opened and closed by buttons with no script.

โครงสร้าง: dialog ที่มี header, div และ footer The markup: a dialog with a header, a div and a footer

ส่วนประกอบเป็นลูกโดยตรงของ <dialog>: <header> (หัวเรื่อง คำอธิบาย ปุ่มปิด), <div> (เนื้อหา) และ <footer> (ปุ่ม). Tsugi wraps the parts in one child; tsunami puts them straight in the dialog, or in a <form method="dialog">. Every part is optional.

แก้ไขข้อมูลแล้วกดบันทึก Change the details, then save.

เปิดและปิดด้วย commandfor และ command Buttons open and close it with commandfor and command

command="show-modal" เท่ากับ data-dialog-open ของ Tsugi และ command="close" เท่ากับ data-dialog-close. The button names the dialog's id in commandfor; the browser calls showModal() or close(). Esc closes it too.

คลิกพื้นหลังเพื่อปิด และแบบที่เปิดค้างไว้ A click on the backdrop closes it; closedby keeps it open

closedby="any": Esc และคลิกพื้นหลังปิดได้. ไม่ใส่ closedby: ปิดด้วย Esc เท่านั้น (เหมือน data-dialog-static ของ Tsugi). closedby="none": ปิดด้วยปุ่มเท่านั้น. A browser without closedby support ignores it: Escape still closes the dialog.

คลิกนอกกรอบเพื่อปิด Click outside to close

Esc หรือคลิกพื้นหลังก็ปิดได้ Escape or a click on the backdrop closes it.

ฟอร์ม method="dialog" ปิด dialog และหน้าอ่านปุ่มที่กดจาก returnValue A form with method="dialog" closes it, and the page reads returnValue

ปุ่ม submit ใน <form method="dialog"> ปิด dialog โดยไม่ส่งข้อมูล และ value ของปุ่มกลายเป็น returnValue. Read it in the close event. Escape leaves it empty. A close button with command="close" and a value sets it the same way.

API

Methods and properties (native)

Member Type Description
showModal() method เปิดแบบ modal บนพื้นหลังมืด โฟกัสอยู่ใน dialog. Opens the dialog over the dimmed page; what command="show-modal" calls.
close(returnValue?) method ปิด และคืนโฟกัสให้ปุ่มที่เปิด. Closes it; the optional string becomes returnValue. What command="close" calls.
requestClose(returnValue?) method เหมือน Esc: ส่ง cancel ก่อน ซึ่งยกเลิกได้. Like Escape: fires cancel first, which can keep it open. command="request-close".
returnValue property ค่าจาก close(value) หรือ value ของปุ่มที่ submit ฟอร์ม method="dialog". Not reset on open: clear it yourself.
open property true ขณะเปิด. Do not set the open attribute by hand: that dialog is not modal.

Events (native)

Event Detail Description
close none หลังปิด ไม่ว่าวิธีใด. After the dialog has closed, however it closed. Read returnValue here.
cancel none เมื่อกด Esc หรือคลิกพื้นหลัง ก่อนปิด. Before Escape (or a backdrop click) closes it; preventDefault() keeps it open.

Keyboard

Key Description
Esc ปิด dialog (ยกเว้น closedby="none"). Closes the dialog; a popover open inside it closes first.
Tab วนอยู่ในตัว dialog ไม่ไปถึงหน้าข้างหลัง. Moves between the controls of the dialog only.
Enter ในช่องกรอก: submit ฟอร์ม ซึ่งปิด dialog เมื่อ method="dialog". In a field: submits the form.

tsunami ไม่มี JS สำหรับ dialog: ทั้งหมดเป็นของเบราว์เซอร์. Everything here is the browser's own dialog element; tsunami adds only styles.

Attributes

Attribute / element Values Description
class="dialog" on <dialog> สไตล์ dialog. The component.
data-size sm (24rem), none (default, 32rem), lg (42rem), xl (56rem) ความกว้าง. Width; never wider than the window less 1rem each side.
role="alertdialog" on the dialog คำถามที่ต้องตอบ: ไม่มีเส้นคั่น. A question with answers; with data-size="sm" it is centred and its two buttons are equal width.
aria-labelledby id of the <h2> ชื่อ dialog สำหรับ screen reader (จำเป็น). Names the dialog. Required.
aria-describedby id of the <p> คำอธิบาย. Reads the line under the title as the description.
closedby any, closerequest (default for a modal), none any: Esc และคลิกพื้นหลังปิดได้; closerequest: Esc เท่านั้น; none: ปุ่มเท่านั้น.
commandfor + command dialog id + show-modal, close, request-close บนปุ่ม เปิดหรือปิด dialog. On a button: opens or closes the dialog it names.
value text, on a close or submit button กลายเป็น returnValue. Becomes the dialog's returnValue.
autofocus on a control in the dialog ช่องที่ได้โฟกัสเมื่อเปิด. Without it the first focusable control does.
> form[method=dialog] optional wrapper ห่อ header/div/footer; ปุ่ม submit ปิด dialog. Wraps the parts; a submit closes the dialog.
> header h2, p, close button, figure หัวเรื่อง คำอธิบาย ปุ่มปิด (ท้ายแถวแรก). The close button sits at the end of the first row.
> header > figure data-variant: none (gray, default), ok, danger, warning, info ไอคอนกลมข้างคำถาม. A round icon beside the title.
> div any content เนื้อหา เลื่อนได้เมื่อยาว. The body; scrolls when it is long.
> footer buttons ปุ่มชิดขวา. Buttons at the end, main action last.
