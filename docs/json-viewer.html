JSON viewer

แสดง JSON เป็น tree ที่พับได้ จาก textarea ที่มี JSON อยู่ ถ้าไม่มี JS จะเห็น textarea ตามปกติ A foldable tree drawn from a textarea that holds the JSON.

markup คือ textarea ที่มี JSON The markup is a textarea holding the JSON 

<div class="json-viewer" id="jv-main">
  <textarea class="input" readonly aria-label="ข้อมูลที่ส่งไป Raw post params">{"transaction": {"amount": 12900, "currency_code": "THB", "email": "somchai@example.com", "billing_address": {"name": "สมชาย ใจดี", "address1": "48 ถนนสุขุมวิท", "address2": "", "city": "Bangkok", "zip": "10110", "country": "TH", "phone": null}, "retain_on_success": true, "splits": [{"type": "BalanceAccount", "amount": {"currency": "THB", "value": 12513}}, {"type": "Commission", "amount": {"currency": "THB", "value": 387}, "description": "ค่าธรรมเนียม Fixed fee"}]}}</textarea>
</div>

data-collapsed เริ่มแบบพับเหลือชั้นบนสุด Starts the tree folded to its top level 

<div class="json-viewer" data-collapsed>
  <textarea class="input" readonly aria-label="คำสั่งซื้อ Order">{"number": "110963", "status": "open", "total": "259.96", "lines": [{"sku": "LAMP-BLK", "quantity": 2}, {"sku": "SHEET-TWIN", "quantity": 1}], "shipping": {"method": "Standard", "tracking": null}}</textarea>
</div>

data-view="raw" เริ่มที่ textarea Starts on the textarea 

<div class="json-viewer" data-view="raw">
  <textarea class="input" readonly aria-label="คำสั่งซื้อ Order">{"number": "110963", "status": "open", "total": "259.96", "lines": [{"sku": "LAMP-BLK", "quantity": 2}], "shipping": {"method": "Standard", "tracking": null}}</textarea>
</div>

ถ้าไม่ใส่ readonly แก้ใน raw ได้ และข้อความที่ไม่ใช่ JSON ถูกทำเครื่องหมาย Without readonly the raw view can be edited; text that is not JSON is marked invalid

กดแสดงแบบ tree เพื่อวาดจากข้อความที่พิมพ์ ฟอร์มส่ง textarea Show parsed draws the tree from what is typed. 
<div class="field">
  <label for="jv-edit">ข้อมูลเพิ่มเติม Metadata</label>
  <div class="json-viewer" data-view="raw">
    <textarea class="input" id="jv-edit" name="metadata">{
  "gift_wrap": true,
  "note": "วางไว้ที่ประตูข้าง Leave at the side door",
  "priority": 2
}</textarea>
  </div>
  <small>กดแสดงแบบ tree เพื่อวาดจากข้อความที่พิมพ์ ฟอร์มส่ง textarea Show parsed draws the tree from what is typed.</small>
</div>

หน้าพับ tree ด้วย collapse() และ expand() และเปลี่ยน JSON ด้วย value() The page folds the tree and replaces the JSON

API

JSON viewer ไม่ส่ง event ของตัวเอง textarea ส่ง input / change ตามปกติเมื่อถูกแก้ ปุ่มแสดง raw จัดย่อหน้า 2 ช่อง สี: key สีข้อความ, string เขียว, number/boolean ฟ้า, null แดง

Function Returns Description
tsunami.jsonViewer.expand(el) คลี่ทุก object และ list Unfolds every object and list.
tsunami.jsonViewer.collapse(el) พับทุกชั้นยกเว้นชั้นนอกสุด Folds everything inside the outermost one.
tsunami.jsonViewer.view(el, v?) "parsed" | "raw" อ่านหรือตั้งมุมมอง Reads or sets the view.
tsunami.jsonViewer.value(el, v?) text อ่านข้อความ หรือตั้งด้วยข้อความ JSON / object แล้ววาดใหม่ Reads the text, or sets JSON text or an object and redraws.
Key Description
Tab ไปที่ปุ่ม แล้วแต่ละ object และ list ใน tree Through the button, then each object and list.
Enter, Space บน object หรือ list: พับหรือคลี่ (พฤติกรรมของ details) Folds or unfolds it.

Attributes

Attribute / element Values Description
.json-viewer กล่องที่ล้อม textarea สคริปต์เพิ่ม header กับ tree The box; the script adds a header and the tree.
data-view parsed (default), raw raw เริ่มที่ textarea สคริปต์อัปเดตค่าเมื่อสลับ Starts on the textarea; kept up to date.
data-collapsed present เริ่มแบบพับเหลือชั้นบนสุด Starts folded to its top level.
> textarea[readonly] present แก้ไม่ได้ใน raw ไม่ใส่ = ช่องกรอกปกติ Cannot be edited in the raw view.
> textarea[name] text ส่ง JSON ไปกับฟอร์ม Sends the JSON with the form.
aria-invalid true สคริปต์ตั้งเมื่อข้อความไม่ใช่ JSON และคงอยู่ที่ raw เอาออกเมื่อพิมพ์ Set when the text is not JSON.
details[open] present สคริปต์ตั้งขณะ object หรือ list คลี่อยู่ Present while that node is unfolded.
