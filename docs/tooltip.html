Tooltip

ข้อความสั้นหนึ่งบรรทัดเมื่อชี้เมาส์หรือโฟกัสด้วยคีย์บอร์ด ใช้ attribute เดียว ไม่ต้องใช้ JS. One line of text on hover or keyboard focus, from one attribute.

Tooltip คือ attribute เดียว ไม่ต้องใช้ script A tooltip is one attribute and needs no script

data-tooltip แสดงข้อความเหนือ element เมื่อชี้เมาส์ หรือเมื่อโฟกัสด้วยคีย์บอร์ด. The text is plain text taken from the attribute. 

<button type="button" class="btn" data-tooltip="เพิ่มลงคอลเลกชัน Add to collection">ชี้เมาส์ Hover</button>

data-side วางไว้ด้านบน ล่าง ซ้าย หรือขวา data-side puts it above, below, left or right 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-tooltip="ด้านบน ค่าเริ่มต้น Above, the default" data-side="top">บน Top</button>
  <button type="button" class="btn" data-tooltip="ด้านล่าง Below" data-side="bottom">ล่าง Bottom</button>
  <button type="button" class="btn" data-tooltip="ทางซ้าย Left" data-side="left">ซ้าย Left</button>
  <button type="button" class="btn" data-tooltip="ทางขวา Right" data-side="right">ขวา Right</button>
</div>

data-align จัดชิดต้น กึ่งกลาง หรือท้ายของ element data-align lines it up with the start, the centre or the end

ด้านซ้ายหรือขวา: start คือขอบบน end คือขอบล่าง. On the left or right side, start is the top edge and end the bottom edge. 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-tooltip="ชิดขอบต้น Lined up with the start" data-align="start">ต้น Start</button>
  <button type="button" class="btn" data-tooltip="กึ่งกลาง ค่าเริ่มต้น Centred, the default" data-align="center">กลาง Center</button>
  <button type="button" class="btn" data-tooltip="ชิดขอบท้าย Lined up with the end" data-align="end">ท้าย End</button>
</div>

ปุ่มไอคอนยังต้องมี aria-label: tooltip ไม่ใช่ชื่อของปุ่ม An icon button keeps its aria-label: the tooltip is not its name

screen reader ไม่อ่าน tooltip. A screen reader does not read the tooltip, so the button is named by aria-label. 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-size="icon" aria-label="ทำสำเนา Copy" data-tooltip="ทำสำเนา Copy"><i class="icon icon-copy" aria-hidden="true"></i></button>
  <button type="button" class="btn" data-size="icon" aria-label="ดาวน์โหลด Download" data-tooltip="ดาวน์โหลด Download"><i class="icon icon-download" aria-hidden="true"></i></button>
  <button type="button" class="btn" data-size="icon" data-variant="danger" aria-label="ลบ Delete" data-tooltip="ลบ Delete"><i class="icon icon-trash-2" aria-hidden="true"></i></button>
</div>

ใช้ได้กับทุก element ที่มีเนื้อหา: badge ไอคอน หรือคำ It works on any element that can hold content: a badge, an icon, a word

<abbr data-tooltip> ได้เส้นใต้แบบจุด. An abbr gets a dotted underline. Give an element that is not focusable tabindex="0" when keyboard users need the text too.

ชำระแล้ว Paid MRR 
<div class="stack" data-direction="row">
  <span class="badge" data-variant="ok" data-tooltip="ชำระเมื่อ 3 ต.ค. 2569 Paid on Oct 3, 2026">ชำระแล้ว Paid</span>
  <span data-tooltip="ยืนยันด้วย 3D Secure Verified by 3D Secure"><i class="icon icon-shield-check" aria-hidden="true"></i></span>
  <abbr data-tooltip="รายได้ประจำต่อเดือน Monthly recurring revenue" tabindex="0">MRR</abbr>
</div>

ช่องกรอกวาด tooltip เองไม่ได้ จึงใส่ attribute ที่ตัวห่อ A field cannot draw a tooltip itself, so the attribute goes on a wrapper

input, select, textarea และ img ไม่มี ::after. The wrapper shows the tooltip on hover and while the field inside it has keyboard focus. 

<div class="field" data-tooltip="ตัวอักษรและตัวเลขเท่านั้น Letters and numbers only" data-align="start" style="max-width: 16rem">
  <label for="tt-coupon">โค้ดส่วนลด Coupon code</label>
  <input id="tt-coupon" type="text" placeholder="SALE2026">
</div>

ข้อความยาวอยู่บรรทัดเดียวและถูกตัดที่ 320px Long text stays on one line and is cut off at 320px

เกิน 20rem (320px) จะแสดง … Longer text ends in an ellipsis. Use a popover for anything longer. 

<button type="button" class="btn" data-tooltip="การชำระเงินนี้ผ่านเกตเวย์ในครั้งแรกและโอนเข้าบัญชีในวันทำการถัดไป This payment was captured on the first attempt and settled the next business day" data-align="start">ข้อความยาว Long text</button>

สิ่งที่ tooltip ไม่ทำ What a tooltip does not do

ข้อจำกัด Limit ควรทำ What to do
แสดงเมื่อชี้เมาส์และโฟกัสด้วยคีย์บอร์ดเท่านั้น จอสัมผัสไม่มี hover. It shows on hover and keyboard focus only; a touch screen has no hover. อย่าใส่ข้อมูลที่ไม่มีที่อื่นบนหน้า. Never put information only in a tooltip.
screen reader ไม่อ่าน. A screen reader does not read it. ตั้งชื่อปุ่มไอคอนด้วย aria-label. Name an icon button with aria-label.
ข้อความธรรมดาบรรทัดเดียว ตัดที่ 320px ใส่ลิงก์หรือปุ่มไม่ได้. One line of plain text, cut off at 320px; no links, buttons or formatting. ใช้ popover สำหรับข้อความยาวหรือสิ่งที่ต้องคลิก. Use a popover.
input, select, textarea, img วาดไม่ได้. These cannot draw one. ใส่ data-tooltip ที่ตัวห่อ. Put it on a wrapper.
element ที่ใช้ ::after อยู่แล้วใช้ไม่ได้. An element that already uses ::after cannot have one. ใส่ที่ตัวห่อ. Put it on a wrapper.
พื้นที่ที่เลื่อนได้ตัด tooltip ที่ขอบ. A scrolling area cuts it off at its edge. เลือก data-side ที่ชี้เข้าในพื้นที่. Choose a side that points into the area.
ใกล้ขอบขวาของหน้า tooltip ล้นออกนอกจอ. Near the right edge it reaches past the window. ใส่ data-align="end". Give that element data-align="end".
ไม่สลับด้านเองเมื่อไม่พอที่. It never flips to another side. เลือก data-side และ data-align ตามตำแหน่ง. Choose them for where the element sits.

Attributes

Attribute / element Values Description
data-tooltip text ข้อความ tooltip บรรทัดเดียว. The text, plain, one line. On any element that can hold content.
data-side none or top (default), bottom, left, right ด้านที่แสดง. The side of the element the tooltip is on.
data-align none or center (default), start, end จัดแนวกับ element. Above or below: left edge, centre, right edge. Left or right: top edge, centre, bottom edge.
aria-label text ชื่อของปุ่มไอคอน (จำเป็น). Names an icon-only button; the tooltip does not.
tabindex="0" on a non-focusable element ให้คีย์บอร์ดเห็น tooltip. Lets keyboard users focus it and see the tooltip.
abbr[data-tooltip] คำย่อ: เส้นใต้แบบจุด. A word or abbreviation with a dotted underline.
