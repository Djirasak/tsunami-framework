Dropdown

เมนูการทำงานใน [popover] แบบ native เปิดด้วยปุ่ม popovertarget ไม่ต้องใช้ JS. A menu of actions in a native popover, opened by its button with no script.

เมนูการทำงาน A menu of actions

ลูกของ .dropdown คือ <button> และ <a>. Give each button popovertarget + popovertargetaction="hide" so a click closes the menu; listen for the button's own click to act. <hr> separates groups.

ดูหน้าร้าน View in store 
<button type="button" class="btn" popovertarget="dd-actions">การทำงาน Actions <i class="icon icon-chevron-down" aria-hidden="true"></i></button>
<div class="dropdown" id="dd-actions" popover>
  <button type="button" popovertarget="dd-actions" popovertargetaction="hide"><i class="icon icon-pencil" aria-hidden="true"></i>แก้ไข Edit</button>
  <button type="button" popovertarget="dd-actions" popovertargetaction="hide"><i class="icon icon-copy" aria-hidden="true"></i>ทำสำเนา Duplicate</button>
  <a href="#"><i class="icon icon-external-link" aria-hidden="true"></i>ดูหน้าร้าน View in store</a>
  <hr>
  <button type="button" data-variant="danger" popovertarget="dd-actions" popovertargetaction="hide"><i class="icon icon-trash-2" aria-hidden="true"></i>ลบ Delete</button>
</div>

หัวข้อ ปุ่มลัด และรายการที่ใช้ไม่ได้ Headings, shortcuts and a disabled item

<h3> เป็นหัวข้อสีเทา <kbd> ชิดขวา และ disabled ทำให้รายการกดไม่ได้และข้ามด้วย Tab. A link cannot be disabled: use aria-disabled="true" and remove its href. The shortcut is only a label: wire the key yourself.

jane@example.com

<button type="button" class="btn" popovertarget="dd-account"><i class="icon icon-user" aria-hidden="true"></i>บัญชี Account</button>
<div class="dropdown" id="dd-account" popover>
  <h3>jane@example.com</h3>
  <button type="button" popovertarget="dd-account" popovertargetaction="hide">โปรไฟล์ Profile<kbd>⇧⌘P</kbd></button>
  <button type="button" popovertarget="dd-account" popovertargetaction="hide">การชำระเงิน Billing<kbd>⌘B</kbd></button>
  <button type="button" disabled>API keys</button>
  <hr>
  <button type="button" data-variant="danger" popovertarget="dd-account" popovertargetaction="hide">ออกจากระบบ Sign out<kbd>⇧⌘Q</kbd></button>
</div>

รายการ checkbox: เลือกคอลัมน์ที่จะแสดง Checkbox items: choose which columns to show

ใช้ <input type="checkbox"> ใน <label>. Native checkboxes: Space ticks the focused one, the menu stays open, and the page listens for change and reads checked.

แสดงคอลัมน์ Show columns

<button type="button" class="btn" popovertarget="dd-columns">คอลัมน์ Columns</button>
<div class="dropdown" id="dd-columns" popover>
  <h3>แสดงคอลัมน์ Show columns</h3>
  <label><input type="checkbox" name="columns" value="variants" checked> ตัวเลือก Variants</label>
  <label><input type="checkbox" name="columns" value="visibility" checked> การแสดงผล Visibility</label>
  <label><input type="checkbox" name="columns" value="ranking"> อันดับ Ranking</label>
</div>

รายการ radio: เลือกได้หนึ่งอย่าง Radio items: choose one

ใช้ <input type="radio"> ที่มี name เดียวกัน. The arrow keys move the choice within the group, as in any radio group.

เรียงตาม Sort by

<button type="button" class="btn" popovertarget="dd-sort">เรียงตาม Sort by</button>
<div class="dropdown" id="dd-sort" popover>
  <h3>เรียงตาม Sort by</h3>
  <label><input type="radio" name="dd-sort" value="newest" checked> ใหม่สุด Newest</label>
  <label><input type="radio" name="dd-sort" value="oldest"> เก่าสุด Oldest</label>
  <label><input type="radio" name="dd-sort" value="total"> ยอดรวม Order total</label>
</div>

API

Methods (native)

Member Type Description
showPopover() method เปิดเมนู. Opens the menu.
hidePopover() method ปิดเมนู. Closes the menu.
togglePopover(force?) method สลับ. Opens it when closed, closes it when open.

Events (native)

Event Detail Description
toggle newState: "open" / "closed" บนเมนู หลังเปิดหรือปิด. On the menu, after it opens or closes.
click none บนรายการ: ทำงานตามรายการ. On an item: do its action.
change none บน checkbox หรือ radio: อ่าน checked. On a checkbox or radio item.

Keyboard

Key Description
Enter / Space บนปุ่ม: เปิดหรือปิดเมนู. On the button: opens or closes the menu. On an item: chooses it.
Tab / Shift Tab ไปยังรายการถัดไปหรือก่อนหน้า (เมนูอยู่ถัดจากปุ่มในลำดับโฟกัส). Moves through the items; the menu comes right after its button in the focus order.
↑ ↓ ในกลุ่ม radio: เปลี่ยนตัวเลือก. In a radio group: moves the choice.
Esc ปิดเมนูและคืนโฟกัสให้ปุ่ม. Closes the menu and returns focus to the button.

ไม่มี JS และไม่ใช้ role="menu": รายการเป็นปุ่มและลิงก์ธรรมดา จึงใช้ Tab แทนลูกศร. No script and no role="menu": items are plain buttons and links, so Tab moves between them instead of the arrow keys.

Attributes

Attribute / element Values Description
class="dropdown" on the menu สไตล์เมนู. The component: a bordered list at least 10rem wide.
popover + id auto (default) ทำให้เป็นป๊อปโอเวอร์. Closes on an outside click, Escape, or another menu.
popovertarget the menu's id บนปุ่มที่เปิด. On the button; the menu is placed against it.
popovertargetaction hide on an item, toggle (default) on the button บนรายการ เพื่อปิดเมนูหลังคลิก. On an item button: closes the menu on click.
data-side none or bottom (default), top, left, right ด้านของปุ่มที่เมนูเปิด. Flips when it does not fit.
data-align none or start (default), center, end จัดแนวกับปุ่ม. How the menu lines up with the button.
> button, > a items รายการ. An icon before the text is gray.
> label > input type="checkbox" or type="radio" รายการเลือก. A checkbox or radio item; the menu stays open.
> h2, > h3, > h4 text หัวข้อกลุ่ม สีเทา ตัวเล็ก. A small gray group heading.
> hr เส้นคั่นกลุ่ม. Separates groups.
kbd inside an item ปุ่มลัด ชิดขวา. A shortcut label at the end of the item.
disabled, aria-disabled disabled on a button or input, aria-disabled="true" on a link รายการที่ใช้ไม่ได้. Grayed out; a disabled button is skipped by Tab.
data-variant danger บนรายการที่ทำลายข้อมูล. A destructive item, in red.
