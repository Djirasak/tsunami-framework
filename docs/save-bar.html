Save bar

แถบติดด้านล่างที่แสดงเมื่อฟอร์มถูกแก้ไข และซ่อนเมื่อค่ากลับเป็นค่าเดิม ลองแก้ฟอร์มในตัวอย่างดู

แถบบันทึก The bar

ข้อความทางซ้าย ปุ่มทางขวา ปุ่ม Discard เป็น type="reset" คืนค่าเดิมแบบ native ส่วน Save เป็น type="submit" ทั้งคู่ชี้ฟอร์มด้วย form="id" จึงวางนอกฟอร์มได้

มีการแก้ไขที่ยังไม่บันทึก Unsaved changes

  <div>
    <button type="button" class="btn" data-variant="ghost">ยกเลิก Discard</button>

  </div>
</div>

แถบบอกชื่อฟอร์มด้วย data-form The bar names its form with data-form

data-form คือ id ของฟอร์มที่แถบติดตาม วางแถบหลังฟอร์มและเริ่มด้วย hidden ตัวอย่างในหน้านี้ใช้ method="dialog" เพื่อไม่ให้หน้าโหลดใหม่ตอนกดบันทึก

<script>
  {
    const form = document.getElementById("sb-events");
    const result = document.getElementById("sb-events-result");
    form.addEventListener("tsunami:dirty", () => {
      result.textContent = "dirty: มีการแก้ไขที่ยังไม่บันทึก";

    form.addEventListener("tsunami:clean", () => {

      window.tsunami.saveBar.markClean(form);

  }

API

js/save-bar.js ทำงานกับแถบและฟอร์มที่เพิ่มเข้ามาภายหลังด้วย ไม่ต้องเรียก init

Function Arguments Description
tsunami.saveBar.check(target) target: .save-bar หรือ form เทียบฟอร์มตอนนี้ แสดง/ซ่อนแถบ ตั้ง data-dirty และส่ง event ถ้าสถานะเปลี่ยน คืนค่า true ถ้ามีการแก้ เรียกหลัง script เปลี่ยนค่าช่องโดยไม่ส่ง input/change
tsunami.saveBar.markClean(target) target: .save-bar หรือ form ให้ค่าปัจจุบันเป็นค่าที่บันทึกแล้ว (อัปเดต defaultValue / defaultChecked / defaultSelected จึงใช้กับปุ่ม reset ได้ต่อ) แล้วซ่อนแถบ
Event On Detail
tsunami:dirty form (bubbles) { form, bars } ส่งเมื่อฟอร์มเริ่มต่างจากค่าที่บันทึก
tsunami:clean form (bubbles) { form, bars } ส่งเมื่อกลับมาตรงกับค่าที่บันทึก ทั้งจากการแก้กลับ reset, submit หรือ markClean()

เทียบอย่างไร: checkbox/radio เทียบ checked กับ defaultChecked, select เทียบ selected กับ defaultSelected, file เทียบไฟล์ที่เลือก, input type=hidden เทียบกับค่าตอนที่ script เห็นฟอร์มครั้งแรก, ช่องอื่นเทียบ value กับ defaultValue จำนวนช่องที่เปลี่ยน (เพิ่ม/ลบแถว) ก็นับเป็นการแก้ โดย script ที่เพิ่มแถวต้องส่ง event input บนฟอร์ม ไม่เทียบ: ปุ่ม, fieldset, output, ช่องใน dialog, ช่องค้นหาของ select และ [data-save-bar-ignore] หลัง submit ค่าจะถือว่าบันทึกแล้ว

Attributes

Attribute / element Values Description
.save-bar แถบ sticky ติดด้านล่าง ขอบบน 1px
.save-bar > p ข้อความสีเทาทางซ้าย
.save-bar > div กลุ่มปุ่มทางขวา
data-form id ของ form ฟอร์มที่แถบติดตาม ถ้าไม่ใส่ script จะไม่แตะแถบ
hidden มี / ไม่มี ใส่เพื่อเริ่มแบบซ่อนแล้วให้ script สลับ ถ้าไม่ใส่แถบแสดงตลอด
data-warn-on-leave มี / ไม่มี (default ไม่มี) ถามก่อนออกจากหน้าเมื่อมีการแก้ (beforeunload) ปุ่ม Discard / Save และลิงก์ในแถบไม่ถาม
data-dirty true, false script ตั้งให้: ฟอร์มมีการแก้ที่ยังไม่บันทึกหรือไม่ ใช้เขียน CSS หรืออ่านจาก script
role="region" + aria-label ให้ screen reader หาแถบเจอ
button[type=reset][form] ปุ่ม Discard คืนค่าเดิมแบบ native แถบซ่อนเอง
button[type=submit][form] ปุ่ม Save ส่งฟอร์มจากนอกฟอร์ม หลัง submit ค่าถือว่าบันทึกแล้ว
a[href=""] ทางเลือกของ Discard: โหลดหน้าใหม่เพื่อคืนค่าที่บันทึก ไม่ถามก่อนออก
data-save-bar-ignore บนช่องในฟอร์ม: ไม่นำมาเทียบ (เช่นช่องกรองที่ไม่ได้บันทึก)
