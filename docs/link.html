Attributes

Attribute / element Values Description
a ไม่มี class สี accent ขีดเส้นใต้เมื่อชี้ สำหรับลิงก์ในเนื้อหา
.link a ใช้สีของข้อความรอบ ๆ ขีดเส้นใต้สี accent เมื่อชี้
data-variant ไม่ใส่ (default) สีข้อความ · primary สี accent · muted สีเทา สีของลิงก์
data-weight ไม่ใส่ (default) ปกติ · medium ตัวหนาปานกลาง สำหรับชื่อที่ต้องเด่น หรือลิงก์ของแถวนั้นในตาราง
.link > .icon child ไอคอนท้ายลิงก์ เช่น icon-external-link มีระยะห่างให้
