Theme switcher

Theme switcher

ธีมอยู่ที่ data-theme บน <html> ปุ่มเลือกธีมจำค่าไว้ใน localStorage และตั้ง aria-pressed ให้เอง

ธีมอยู่ที่ data-theme บน html The theme is data-theme on html

<html data-theme="dark"> หรือ "light" คือเลือกธีมไว้ ถ้าไม่มี attribute จะใช้ธีมของระบบ (prefers-color-scheme) ปุ่ม data-theme-toggle เปลี่ยนค่านี้และบันทึกไว้ใน localStorage คีย์ tsunami-theme ทุก token สีมีค่าที่สองสำหรับ dark 

<html lang="th" data-theme="dark">
  ...
  <div class="theme-switcher" role="group" aria-label="ธีม Theme">
    <button type="button" data-theme-toggle="light" aria-label="Light"><i class="icon icon-sun" aria-hidden="true"></i></button>
    <button type="button" data-theme-toggle="dark" aria-label="Dark"><i class="icon icon-moon" aria-hidden="true"></i></button>
    <button type="button" data-theme-toggle="system" aria-label="System"><i class="icon icon-monitor" aria-hidden="true"></i></button>
  </div>

ปุ่มสลับ Toggle

data-theme-toggle ที่ไม่มีค่าสลับ light / dark จากธีมที่ใช้อยู่ตอนนี้ 

<button type="button" class="btn" data-theme-toggle>สลับธีม Toggle theme</button>

ใส่สคริปต์ใน head ก่อนวาดหน้า Apply the saved theme in the head

วางไว้ใน <head> ก่อน stylesheet ถ้าไม่มี คนที่เลือก dark จะเห็นหน้าขาวกะพริบทุกครั้งที่โหลด ถ้า localStorage ถูกบล็อก ธีมยังเปลี่ยนได้แต่จำไว้แค่หน้านั้น 

<script>
  try {
    const t = localStorage.getItem("tsunami-theme");
    if (t) document.documentElement.dataset.theme = t;
  } catch {}
</script>

ไอคอนและข้อความตามธีมโดยไม่ใช้สคริปต์ Icon and label follow the theme

data-theme-show="dark" แสดงเฉพาะตอน dark และ "light" เฉพาะตอน light ใช้ CSS ล้วน (อ่าน html[data-theme] หรือ prefers-color-scheme) จึงถูกต้องตั้งแต่ก่อน JS โหลด 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-variant="ghost" data-size="icon-sm" data-theme-toggle aria-label="สลับธีม Toggle theme">
    <i class="icon icon-sun" data-theme-show="dark" aria-hidden="true"></i>
    <i class="icon icon-moon" data-theme-show="light" aria-hidden="true"></i>
  </button>
  <button type="button" class="btn" data-size="sm" data-theme-toggle>
    <i class="icon icon-sun" data-theme-show="dark" aria-hidden="true"></i>
    <i class="icon icon-moon" data-theme-show="light" aria-hidden="true"></i>
    <span data-theme-show="dark">โหมดสว่าง Light mode</span>
    <span data-theme-show="light">โหมดมืด Dark mode</span>
  </button>
</div>

set() เลือกธีมตามชื่อ set() picks a theme by name

window.tsunami.theme.set(name) รับ "light", "dark" หรือ "system" ใช้เมื่อเปลี่ยนธีมจากโค้ด เช่นหลังผู้ใช้บันทึกการตั้งค่าบัญชี 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn" data-size="sm" onclick="window.tsunami.theme.set('light')"><i class="icon icon-sun" aria-hidden="true"></i>สว่าง Light</button>
  <button type="button" class="btn" data-size="sm" onclick="window.tsunami.theme.set('dark')"><i class="icon icon-moon" aria-hidden="true"></i>มืด Dark</button>
  <button type="button" class="btn" data-size="sm" onclick="window.tsunami.theme.set('system')"><i class="icon icon-monitor" aria-hidden="true"></i>ตามระบบ System</button>
</div>

อ่านธีมด้วย get() และฟัง tsunami:themechange Read with get(), listen for a change

get() คืน "dark" หรือ "light" ตามที่แสดงจริง event ส่งที่ document ทุกครั้งที่ set() / toggle() / ปุ่มถูกกด และเมื่อธีมระบบเปลี่ยนตอนเลือก system 

<div class="stack" data-gap="sm">
  <div><button type="button" class="btn" data-size="sm" onclick="window.tsunami.theme.toggle()">สลับ Toggle</button></div>
  <p id="theme-result"></p>
</div>
<script>
  document.addEventListener("DOMContentLoaded", () => {
    const result = document.getElementById("theme-result");
    result.textContent = "get() คืนค่า " + window.tsunami.theme.get();
    document.addEventListener("tsunami:themechange", (e) => {
      result.textContent = "tsunami:themechange: theme = " + e.detail.theme + ", choice = " + e.detail.choice;
    });
  });
</script>

คอมโพเนนต์วาดใหม่เมื่อธีมเปลี่ยน Components redraw on a change

CSS เปลี่ยนสีเองอยู่แล้ว แต่ canvas หรือ iframe ที่หน้าวาดเองต้องฟัง tsunami:themechange แล้วอ่าน token สีใหม่มาวาดซ้ำ 

<canvas id="theme-chart" style="width: 100%; max-width: 20rem; height: 7.5rem" aria-label="ยอดขาย 7 วัน Sales, last 7 days" role="img"></canvas>
<script>
  (() => {
    const canvas = document.getElementById("theme-chart");
    const sales = [12, 18, 9, 22, 16, 27, 20];
    function draw() {
      const css = getComputedStyle(canvas);
      const w = canvas.clientWidth;
      const h = canvas.clientHeight;
      canvas.width = w * devicePixelRatio;
      canvas.height = h * devicePixelRatio;
      const ctx = canvas.getContext("2d");
      ctx.scale(devicePixelRatio, devicePixelRatio);
      ctx.fillStyle = css.getPropertyValue("--subtle");
      ctx.fillRect(0, 0, w, h);
      const bar = w / sales.length;
      ctx.fillStyle = css.getPropertyValue("--accent");
      sales.forEach((v, i) => {
        const y = h - (v / 30) * h;
        ctx.fillRect(i * bar + 4, y, bar - 8, h - y);
      });
    }
    document.addEventListener("tsunami:themechange", draw);
    draw();
  })();
</script>

Attributes

Attribute / element Values Description
html[data-theme] (ไม่ใส่ = ตามระบบ, ค่าเริ่มต้น), light, dark ธีมที่เลือก ตั้งโดย JS และสคริปต์ใน head ไม่มี attribute จะใช้ prefers-color-scheme
.theme-switcher div + role="group", aria-label กรอบปุ่มเลือกธีมแบบ segmented ลูกคือ <button> ที่มีไอคอน
data-theme-toggle (ว่าง), light, dark, system ใส่ที่ปุ่มใดก็ได้ ว่าง = สลับ light / dark, ค่าอื่น = set(ค่า); system ลบค่าที่เลือกไว้
aria-pressed true, false JS ตั้งให้ปุ่ม data-theme-toggle ที่มีค่า ตรงกับค่าที่เลือกอยู่ (system เมื่อไม่มี data-theme)
aria-label ข้อความ จำเป็นกับปุ่มไอคอนอย่างเดียว
data-theme-show light, dark แสดง element นี้เฉพาะในธีมนั้น ใช้ CSS ล้วน
tsunami-theme light, dark คีย์ใน localStorage เก็บค่าที่เลือก ลบออกเมื่อเลือก system

API

ฟังก์ชันอยู่ที่ window.tsunami.theme

Function / event Arguments / detail Description
theme.get() - คืน "dark" หรือ "light" ตามธีมที่แสดงอยู่จริง (รวมกรณีตามระบบ)
theme.set(name) name: "light", "dark", "system" ตั้งธีมและบันทึก ค่าอื่นนอกจาก light / dark ถือเป็น system
theme.toggle() - สลับไปอีกธีมจากที่แสดงอยู่
tsunami:themechange { theme, choice } ส่งที่ document หลังทุก set() / toggle() / คลิกปุ่ม (แม้ค่าไม่เปลี่ยน) และเมื่อธีมระบบเปลี่ยนตอนเลือก system theme = "dark" | "light", choice = "light" | "dark" | "system"
