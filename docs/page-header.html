Page header

หัวของหน้า: breadcrumb แถวบน ปุ่มย้อนกลับ ชื่อหน้า และปุ่มการทำงานทางขวา

การใช้งาน Usage

Attributes

Attribute / element Values Description
.page-header header แถว flex ที่ขึ้นบรรทัดใหม่ได้ จัดกลางแนวตั้ง
> nav nav.breadcrumb breadcrumb แถวบนสุด เต็มความกว้าง
> .btn ปุ่มย้อนกลับหน้าชื่อ ไม่ยืดไม่หด (ใช้ data-size="icon" และ aria-label)
> h1 ชื่อหน้า ยืดเต็มพื้นที่; .badge ข้างในวางต่อท้ายชื่อ
> hgroup ชื่อ h1 พร้อม p สีเทาใต้ชื่อ
> div:first-child กล่องชื่อแบบเดิม: breadcrumb, h1, p เรียงลง
> div:last-child กลุ่มปุ่มการทำงาน ชิดขวา (ถ้าไม่ใช่ลูกตัวแรกหรือกล่องชื่อหลัง nav)
p ข้อความรองสีเทา
