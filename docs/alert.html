Attributes

Attribute / element Values Description
.alert กล่องแจ้งเตือน: grid สองคอลัมน์ ไอคอนอยู่ซ้าย ลูกอื่นทั้งหมดอยู่คอลัมน์ขวา
data-variant ok, warning, info, danger (ไม่ใส่ = กลาง) สีพื้นอ่อนและตัวอักษรตามสถานะ ค่าเริ่มต้นพื้น surface ขอบ 1px
> .icon ไม่บังคับ ไอคอนตัวแรก ถ้าไม่มี ข้อความเต็มความกว้าง
> strong, > h2, h3, h4 หัวข้อ ตัวหนา 14px
> p, > section เนื้อความ
> footer แถวปุ่ม ห่างจากเนื้อความ 8px
role status, alert, note status แจ้งทั่วไป alert ข้อผิดพลาดที่ต้องประกาศทันที note ข้อความคงที่ในหน้า
