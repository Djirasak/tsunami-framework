Timeline

Timeline

A vertical list of events for an order or a job, built with <ol> and <time>.

Usage

Each event is an <li>: text followed by a <time>. Put the newest at the top.

  1. Payment captured Oct 29, 2026 18:41
  2. Order #1042 placed Oct 29, 2026 18:40 
<ol class="timeline">
  <li>
    Payment captured
    <time datetime="2026-10-29T18:41">Oct 29, 2026 18:41</time>
  </li>
  <li>
    Order #1042 placed
    <time datetime="2026-10-29T18:40">Oct 29, 2026 18:40</time>
  </li>
</ol>

An event that opens to show details

Put a <details> in the event. The <summary> is the heading (it gets its own arrow) and a <dl> holds the details. Add open to start it open.

  1. Refund issued
    Amount
    $52.00
    Reason
    Item arrived damaged
    Oct 28, 2026 10:05
  2. Delivered Oct 26, 2026 16:36 
<ol class="timeline">
  <li>
    <details open>
      <summary>Refund issued</summary>
      <dl>
        <dt>Amount</dt>
        <dd>$52.00</dd>
        <dt>Reason</dt>
        <dd>Item arrived damaged</dd>
      </dl>
    </details>
    <time datetime="2026-10-28T10:05">Oct 28, 2026 10:05</time>
  </li>
  <li>
    Delivered
    <time datetime="2026-10-26T16:36">Oct 26, 2026 16:36</time>
  </li>
</ol>

Error events

Steps of a job

An .icon or .loader placed first in an event replaces the dot. Add aria-busy="true" to the step in progress and data-variant="pending" to steps not started yet (grey text, hollow dot).

  1. Creating your account
  2. Initializing your store
  3. Importing products
<ol class="timeline">
  <li data-variant="ok">
    <i class="icon icon-circle-check" aria-hidden="true"></i>
    Creating your account
  </li>
  <li aria-busy="true">
    <span class="loader" role="status" aria-label="In progress"></span>
    Initializing your store
  </li>
  <li data-variant="pending">Importing products</li>
</ol>

Steps played by a script

The page script changes the attributes itself. The running step gets a .loader, which turns into a check icon when done, then the next step starts. Timeline has no JS of its own.

  1. Creating your account
  2. Initializing your store
  3. Importing products
<div class="stack" data-gap="sm">
  <ol class="timeline" id="tl-steps">
    <li data-variant="pending">Creating your account</li>
    <li data-variant="pending">Initializing your store</li>
    <li data-variant="pending">Importing products</li>
  </ol>
  <div>
    <button type="button" class="btn" data-size="sm" id="tl-steps-play">Play</button>
  </div>
</div>
<script type="module">
  const steps = [...document.querySelectorAll("#tl-steps > li")];
  const play = document.getElementById("tl-steps-play");
  const spinner = '<span class="loader" role="status" aria-label="In progress"></span>';
  const check = '<i class="icon icon-circle-check" aria-hidden="true"></i>';
  const start = (step) => {
    step.removeAttribute("data-variant");
    step.setAttribute("aria-busy", "true");
    step.insertAdjacentHTML("afterbegin", spinner);
  };
  play.addEventListener("click", () => {
    play.disabled = true;
    for (const step of steps) {
      step.querySelector(".icon, .loader")?.remove();
      step.removeAttribute("aria-busy");
      step.dataset.variant = "pending";
    }
    let current = 0;
    start(steps[current]);
    const timer = setInterval(() => {
      const step = steps[current];
      step.removeAttribute("aria-busy");
      step.dataset.variant = "ok";
      step.querySelector(".loader").outerHTML = check;
      current += 1;
      if (steps[current]) return start(steps[current]);
      clearInterval(timer);
      play.disabled = false;
    }, 1500);
  });
</script>

A note with Edit and Delete

A staff note is an <article> in the event: an <h4> author name, a <time>, a <p> message and a <footer> of buttons. Show the buttons only while the note can still be edited.

  1. Order placed on hold Oct 23, 2026 08:15

  2. James Carter

    Oct 23, 2026 08:10

    The address looks wrong. Emailed the customer to confirm it before shipping.

  3. Order placed Oct 22, 2026 18:40 
<ol class="timeline">
  <li>
    Order placed on hold
    <time datetime="2026-10-23T08:15">Oct 23, 2026 08:15</time>
  </li>
  <li>
    <article>
      <h4>James Carter</h4>
      <time datetime="2026-10-23T08:10">Oct 23, 2026 08:10</time>
      <p>The address looks wrong. Emailed the customer to confirm it before shipping.</p>
      <footer>
        <button type="button" class="btn" data-size="sm">Edit</button>
        <button type="button" class="btn" data-variant="danger" data-size="sm">Delete</button>
      </footer>
    </article>
  </li>
  <li>
    Order placed
    <time datetime="2026-10-22T18:40">Oct 22, 2026 18:40</time>
  </li>
</ol>

A form for adding a note

The first event is a <form> with a <textarea> and a <footer> of buttons plus a <small> hint. In the example, the page script adds the new note below the form on Save. Cancel is a type="reset" button.

  1. Notes are editable for 5 minutes.
  2. Confirmation email sent Oct 3, 2026 00:36
  3. Fulfillment status changed from Unfulfilled to On hold Oct 3, 2026 00:35 
<ol class="timeline" id="tl-notes">
  <li>
    <label for="tl-note">Add a note</label>
    <form id="tl-note-form">
      <textarea id="tl-note" name="note" placeholder="Add order note..." required></textarea>
      <footer>
        <button type="submit" class="btn" data-variant="primary" data-size="sm">Save</button>
        <button type="reset" class="btn" data-size="sm">Cancel</button>
        <small>Notes are editable for 5 minutes.</small>
      </footer>
    </form>
  </li>
  <li>
    Confirmation email sent
    <time datetime="2026-10-03T00:36">Oct 3, 2026 00:36</time>
  </li>
  <li>
    Fulfillment status changed from Unfulfilled to On hold
    <time datetime="2026-10-03T00:35">Oct 3, 2026 00:35</time>
  </li>
</ol>
<script type="module">
  const form = document.getElementById("tl-note-form");
  form.addEventListener("submit", (event) => {
    event.preventDefault();
    const now = new Date();
    const li = document.createElement("li");
    const article = document.createElement("article");
    const name = document.createElement("h4");
    const time = document.createElement("time");
    const text = document.createElement("p");
    name.textContent = "You";
    time.dateTime = now.toISOString();
    time.textContent = now.toLocaleString("en-US", {
      dateStyle: "medium",
      timeStyle: "short",
    });
    text.textContent = form.elements.note.value;
    article.append(name, time, text);
    li.append(article);
    form.closest("li").after(li);
    form.reset();
  });
</script>

Attributes

Attribute / element Values Description
ol.timeline List of events, newest at the top
> li One event, with a dot and a line to the next event (except the last)
li[data-variant] ok, danger, pending; none = default (grey dot) ok: green dot and leading icon. danger: red dot and text. pending: a step not started yet, with grey text and a hollow dot
li[aria-busy] true Tells screen readers this step is in progress (pair with .loader)
li > .icon:first-child, li > .loader:first-child An icon or loader placed first replaces the dot
time datetime Time of the event, on its own line in small grey text
details > summary open An event that opens to show details. The summary gets its own arrow
dl > dt + dd Name/value details in two columns inside a frame
article A note: h4 author and time on one line, followed by p and footer
footer Button row of a note or form. A small inside it is a grey hint
form, textarea Add-note form in an event; the textarea is full width
