Badge

A short status label with a light fill and dark text. Use it in tables, card headers and next to page titles.

Variants

The default is neutral. Use outline for labels that are not a status, such as a customer type.

Removable

Add a <button> at the end of the badge, with an aria-label. The page removes the badge on click (this example uses a short inline script).

Gift card: Yes Category: Furniture 
<div class="stack" data-direction="row" data-gap="sm" id="badge-filters">
  <span class="badge">Gift card: Yes<button type="button" aria-label="Remove filter Gift card"><i class="icon icon-x" aria-hidden="true"></i></button></span>
  <span class="badge" data-variant="outline">Category: Furniture<button type="button" aria-label="Remove filter Category"><i class="icon icon-x" aria-hidden="true"></i></button></span>
</div>
<script>
  document.getElementById("badge-filters").addEventListener("click", (e) => {
    e.target.closest(".badge > button")?.parentElement.remove();
  });
</script>

Attributes

Attribute / element Values Description
.badge Inline label, 20px tall, 12px text, neutral fill.
data-variant outline, ok, warning, info, danger (omit for neutral) outline has a 1px border and no fill, for labels that are not a status. The rest are status colours.
data-size lg (omit for the default 20px) lg is 28px tall with 14px text. Use it as a card heading.
> .icon Icon before the text, sized to the text.
> button Remove button at the end of the badge. Set type="button" and an aria-label, with an .icon-x inside. The page removes the badge.
h1 > .badge, h2 > .badge, h3 > .badge In a heading, the badge sits 8px from the title and is centred on the line.
