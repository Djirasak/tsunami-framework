Link

Links in text and data. A bare a is the accent colour; .link takes the text colour.

Default: the text colour, underlined in accent on hover

Use it for links mixed into data, so the page is not full of colour.

Primary: the text is the accent colour too

Attributes

Attribute / element Values Description
a no class Accent colour, underlined on hover. For links in body text.
.link a Takes the surrounding text colour, underlined in accent on hover
data-variant unset (default) text colour · primary accent · muted gray Link colour
data-weight unset (default) normal · medium Medium weight, for a name that should stand out or a row's own link in a table
.link > .icon child Trailing icon such as icon-external-link, spaced for you
