Tsunami 津波

A quiet UI framework for back-office apps. Semantic HTML, data-* attributes and a little vanilla JS, with 53 components, Lucide icons and country flags, and no runtime dependencies.

Get started Browse components

Principles

Native first

Reach for dialog, popover, details and button first. A small vanilla script adds only what HTML cannot: theme, tabs, select, tree, table, journey and a few more.

Zero specificity

Every selector sits in @layer components and :where(), so your CSS overrides it right away.

Light / Dark

Themes switch through CSS custom properties, following the system or the user's choice, with no flash on load.

Thai + Latin

One self-hosted woff2 Google Sans for both Thai and Latin. Table numbers use tabular-nums.

ภาษาไทยกับ Latin ในบรรทัดเดียวกัน 1,234.50

Install

Add the files from dist/. Load the script in <head> as a plain script, not type="module": it then applies the saved theme before the first paint, so there is no flash and no inline script to add. 

<link rel="stylesheet" href="dist/tsunami.min.css">
<script src="dist/tsunami.min.js"></script>
