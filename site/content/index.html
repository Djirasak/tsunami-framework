Tsunami 津波

A quiet UI framework. Semantic HTML, data-* attributes and a little vanilla JS, with {{components}} components, Lucide icons and country flags. The core has no runtime dependencies; a few components (editor, chart, date picker, drag and drop) load a library of their own.

Principles

Native first

Reach for dialog, popover, details and button first. A small vanilla script adds only what HTML cannot: theme, tabs, select, tree, table, journey and a few more.

Zero specificity

Every selector sits in @layer components and :where(), so your CSS overrides it right away.

Light / Dark

Themes switch through CSS custom properties, following the system or the user's choice, with no flash on load.

Thai + Latin

One self-hosted woff2 Google Sans for both Thai and Latin. Table numbers use tabular-nums.

ภาษาไทยกับ Latin ในบรรทัดเดียวกัน 1,234.50

Install

Load the files from jsDelivr, which serves each release tag of the GitHub repository. Load the script in <head> as a plain script, not type="module": it then applies the saved theme before the first paint, so there is no flash and no inline script to add. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Djirasak/tsunami-framework@v{{version}}/dist/tsunami.min.css">
<script src="https://cdn.jsdelivr.net/gh/Djirasak/tsunami-framework@v{{version}}/dist/tsunami.min.js"></script>

The fonts and flags load from the same tag, next to dist/. The libraries some components need come from the same place, for example @v{{version}}/dist/chart.min.js, loaded before the Tsunami script. That includes the code editor's dist/monaco/vs/loader.js.

Or install it from npm, for an app with a bundler. The package holds dist/, fonts/ and flags/ side by side, and its TypeScript declarations type window.tsunami and the tsunami:* events once you import it. 

npm install @djirasak/tsunami-ui
pnpm add @djirasak/tsunami-ui
yarn add @djirasak/tsunami-ui
bun add @djirasak/tsunami-ui
import "@djirasak/tsunami-ui/css";
import "@djirasak/tsunami-ui";

A bundler runs the script after the first paint, so people who chose dark can see a flash. To avoid it, load node_modules/@djirasak/tsunami-ui/dist/tsunami.min.js as a plain <script> in <head> instead. The libraries some components need (chart, date picker, editor, code editor, drag and drop) are files in dist/ that you load with a <script> before the Tsunami script.

To host the files yourself, copy dist/, fonts/ and flags/ side by side and link dist/tsunami.min.css and dist/tsunami.min.js.

Example

One class names the component, and one attribute picks its variant. The elements are plain HTML, so a button is a <button> and a dialog is a <dialog>.

Paid Pending Cancelled
Used for the receipt.

A native dialog

It opens with command="show-modal", so Esc and focus work with no script.

 
<button type="button" class="btn">Cancel</button>
<button type="button" class="btn" data-variant="primary">Save</button>
<button type="button" class="btn" data-variant="danger">Delete</button>

<span class="badge" data-variant="ok">Paid</span>
<span class="badge" data-variant="warning">Pending</span>
<span class="badge" data-variant="danger">Cancelled</span>

<div class="field">
  <label for="email">Email</label>
  <input id="email" class="input" type="email" placeholder="you@example.com">
  <small>Used for the receipt.</small>
</div>

<button type="button" class="btn" commandfor="my-dialog" command="show-modal">Open dialog</button>
<dialog id="my-dialog" aria-labelledby="my-dialog-title" closedby="any">
  <header><h2 id="my-dialog-title">A native dialog</h2></header>
  <section><p>It opens with command="show-modal", so Esc and focus work with no script.</p></section>
  <footer><button type="button" class="btn" commandfor="my-dialog" command="close">Close</button></footer>
</dialog>

Browser support

Tsunami targets current evergreen browsers and uses modern CSS and HTML without fallbacks: cascade layers, :has(), native popover, <dialog>, the commandfor and command attributes, color-mix() and range media queries.

The newest of these, commandfor, sets the floor: Chrome and Edge 135, Firefox 144 and Safari 26.2 or later. Check caniuse.com before supporting anything older. Without JavaScript the native parts still work; the components that need a script do not.

Libraries it loads

The core, tsunami.min.js, has no dependencies. Five components use a library of their own. It is vendored in this repository at a pinned version, served from dist/, and loaded only by a page that has that component.
