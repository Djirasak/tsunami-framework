Stepper

A form spread over several panels, one step at a time, with a header that shows where you are.

Linear with validation

The header is an <ol> of buttons. Each <section> after it is the panel of the step in the same position. With data-linear a user cannot jump ahead, and with data-validate the fields of the current panel must pass before Next moves on. The last Next fires tsunami:stepcomplete. The last panel here is a review, filled from a tsunami:stepchange listener.

<script type="module">
  const wiz = document.getElementById("wiz");
  const log = document.getElementById("wz-log");
  wiz.addEventListener("tsunami:stepchange", (e) => {
    log.textContent = `Step ${e.detail.index + 1} of 3.`;
    if (e.detail.index !== 2) return;
    const review = document.getElementById("wz-review");
    review.replaceChildren();
    for (const id of ["wz-name", "wz-email", "wz-plan"]) {
      const dt = document.createElement("dt");
      dt.textContent = document.querySelector(`label[for="${id}"]`).textContent;
      const dd = document.createElement("dd");
      dd.textContent = document.getElementById(id).value;
      review.append(dt, dd);
    }
  });
  wiz.addEventListener("tsunami:stepcomplete", () => {
    log.textContent = "Done. Nothing was sent: this is a demo.";
  });
</script>

Vertical, with an optional step

data-orientation="vertical" stacks the steps (under 40rem they always stack). A panel with data-optional is not validated, so the user can move past it empty. Without data-linear the header steps are free to click, but going forward still validates the current panel.

Behavior

JS sets data-state (done, current or upcoming) on each step button from the current step, and aria-current="step" on the current one. It shows only the current panel and gives each panel role="group", labelled by its step. The first step is current unless the markup marks another with data-state="current". Moving with a button or the API moves focus to the panel heading, or to its first field when there is no heading. Going back never validates. Pressing Enter in a field works as Next, unless the panel has a submit button.

API

Lives in js/stepper.js. It uses event delegation, so steppers added later work too. Each function takes the stepper or any element inside it, or a selector.

Methods

FunctionArgumentsDescription
tsunami.stepper.go(el, index)index: number from 0Opens a step. Going forward validates first (every panel on the way when linear). Returns false if blocked or out of range.
tsunami.stepper.next(el)Next step. On the last step it validates and fires tsunami:stepcomplete.
tsunami.stepper.prev(el)Previous step. Never validates.
tsunami.stepper.index(el)The current step number, from 0.

Events

Both fire on the stepper and bubble.

EventDetailDescription
tsunami:stepchange{ index, step, panel }After a step opens. step is its header <li>.
tsunami:stepcomplete{ index }Next on the last step, once its fields are valid.

Keyboard

KeyContextDescription
Tab / Shift+TabheaderSteps are buttons. Disabled steps are skipped.
Arrow keysheaderMove focus between enabled steps, wrapping. They do not open one.
Home / EndheaderFocus the first / last enabled step.
Enter / SpaceheaderOpen the focused step.
Enterfield in a panelSame as Next, unless the panel has a submit button.

Attributes

Attribute / elementValuesDescription
.stepperdivWraps the <ol> and the panels
> ol > li > buttontype="button"A step. Holds a span with strong (label) and an optional small (description).
> sectionone per step, in orderA panel. Put a heading first and a footer with the buttons.
data-statedone · current · upcomingOn a step button. Set by JS. In markup, current picks the first step.
data-linearpresent / absentOn the stepper: steps after the current one are disabled (aria-disabled).
data-validatepresent / absentOn the stepper: Next and forward jumps run reportValidity() on the current panel's fields.
data-optionalpresent / absentOn a panel: not validated.
data-orientationverticalOn the stepper: stack the steps. Under 40rem it is always vertical.
data-next · data-prevon a button in a panelNext (or finish on the last panel) and Back.
