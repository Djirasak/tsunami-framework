Stack

Spaces out child elements. Vertical by default.

Vertical

Children run top to bottom, 16px apart. Use it to lay out page sections or forms without margins.

First line

Second line

Third line

<div class="stack">
  <p>First line</p>
  <p>Second line</p>
  <p>Third line</p>
</div>

Row: data-direction="row"

Lays children out in a row, centered vertically, and wraps when space runs out. Good for button groups or badges. 

<div class="stack" data-direction="row" data-gap="sm">
  <button type="button" class="btn">Save draft</button>
  <button type="button" class="btn" data-variant="primary">Publish</button>
</div>

Nested in a form

Stacks can nest, such as a vertical form with a row of buttons at the bottom. 

<form class="stack docs-narrow">
  <div class="field">
    <label for="st-name">Product name</label>
    <input id="st-name" value="Cotton T-shirt" />
  </div>
  <div class="field">
    <label for="st-price">Price ($)</label>
    <input id="st-price" type="number" value="24" />
  </div>
  <div class="stack" data-direction="row" data-gap="sm">
    <button type="submit" class="btn" data-variant="primary">Save</button>
    <button type="reset" class="btn">Cancel</button>
  </div>
</form>

Attributes

Attribute / element Values Description
.stack Vertical flex with 16px between children. Works on any element (div, form, section ...)
data-direction row; omit for vertical (default) Horizontal, wraps, and centers items vertically
data-gap sm, lg; omit for 16px (default) 8px or 32px gap
