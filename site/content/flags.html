Attributes

Attribute / element Values Description
.flag A 4:3 box, 16px tall, with a hairline edge so white flags show on a white background.
.flag-{code} ISO 3166 code, e.g. th, gb-eng Picks the flag; see the list below.
data-size sm, default, lg, xl Height 12, 16, 24 or 32px.
role="img" + aria-label text For a flag on its own, so it has a name.
aria-hidden="true" When the country name is next to it.
