Description list

Label and value pairs for a detail page, such as an order or a customer. A semantic dl in three layouts.

Stacked

The default. A muted label above each value. Wrap each label and value in a div.

Long values

Values wrap, even a string with no spaces.

Tracking URL
https://tracking.example.com/parcels/9f8e7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928
Delivery note
Leave with the neighbour at number 14 if nobody answers, and ring the bell twice because it is quiet.
<dl class="desc" data-layout="inline">
  <div><dt>Tracking URL</dt><dd>https://tracking.example.com/parcels/9f8e7d6c5b4a39281706f5e4d3c2b1a09f8e7d6c5b4a3928</dd></div>
  <div><dt>Delivery note</dt><dd>Leave with the neighbour at number 14 if nobody answers, and ring the bell twice because it is quiet.</dd></div>
</dl>

Behavior

Pure CSS, no script. An empty dd shows a muted dash. A dd that holds only whitespace is not empty for CSS, so mark it with data-empty.

Attributes

Attribute / elementValuesDescription
dl.descThe list. Each pair sits in a div.
dtLabel, muted and small
ddValue. Long text wraps.
data-layoutinline, grid (default stacked)Label on the left, or several columns
data-dividedpresent / absentLines between rows
dd[data-empty]present / absentShows a dash for a dd with only whitespace
