Search

An input[data-table-search="table-id"] keeps the rows that contain the text in any cell, ignoring case. It waits 150 ms after typing. When nothing matches, the content of template[data-table-empty] is shown in one cell that spans the visible columns.

Column filters

A second header row, tr[data-filters], can hold an input or a select under any column; the cell must sit at that column's index. An input keeps rows whose cell contains the text and a select keeps rows whose cell equals the chosen option (the empty option clears it). Filters combine with the search and send the table back to page 1.

Column visibility

A .dropdown with data-table-columns="table-id" lists the columns. If it has no checkboxes the script writes one per header (value = column index, label = header text); you can also write them yourself. An unchecked column gets hidden on its th and td, and the last visible column cannot be hidden. Add data-table-remember to a table with an id to keep the choice in localStorage.

API

src/js/table.js uses event delegation on document, so it works on tables added later right away. The functions live at window.tsunami.table. Sorting, filtering and paging work together: the rows are sorted, filtered, then cut into pages.

Function / event Arguments / detail Description
sort(table, columnIndex, direction) table: element, columnIndex: index of the header cell, direction: "ascending" (default) or "descending" Sorts the rows in tbody and sets aria-sort. Returns false if the event was canceled
select(table, rows, checked) rows: a list of tr, checked: boolean (default true) Selects or deselects rows, then fires tsunami:select
selected(table) table: element Returns an array of the selected tr elements
sync(table) table: element Resets aria-selected and the select-all checkbox state after you change checkboxes yourself (runs on page load automatically)
refresh(table) table: element Reads the rows again after you add, remove or change them, and redraws the page
page(table, n) n: page number (kept within range) Shows page n
filter(table, text) text: the search text; "" clears it Sets the global search (and the search input), goes to page 1
tsunami:tablechange { page, pageSize, total, filtered, sort, hidden } Fired on the table after a page, filter, sort or column change. Bubbles. total counts all rows, filtered those matching; sort is { column, direction } or null; hidden lists hidden column indexes
tsunami:sort { column, direction, header } Fired on the table before sorting. Bubbles and is cancelable: call preventDefault() to sort yourself (such as fetching from the server)
tsunami:select { rows, count } Fired on the table whenever the selection changes. Bubbles
