Colors

The colours are CSS variables that change value with the theme. Components only use these variables.

Light and dark columns are static

The variables live on :root only, and data-theme goes on <html>, not on a child element. So the two swatch columns are drawn from the hex values of both themes for comparison. Every Preview uses the current theme.

Lines and fields

Form fields have no colour variables of their own. They use --line for the border, --surface for the fill and a 2px --accent focus ring, like every element.

Charts

Tsunami has no chart colour variables of its own. A chart takes the accent and the status -fg colours in turn. For simple comparison bars, use progress with --fg and the status -fg colours.
