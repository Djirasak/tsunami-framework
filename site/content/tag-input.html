Tag input

A box that looks like an input and holds tags. Type a word and press Enter or comma to add it; Backspace takes the last one away. A form gets the tags as one comma-separated value.

Tags in a form

Press Enter or comma to add. Backspace removes the last. 
<div class="field">
  <label id="ti-label" for="ti-text">Labels</label>
  <div class="tag-input" role="group" aria-labelledby="ti-label" data-name="labels" data-value="design,billing">
    <input type="text" id="ti-text" placeholder="Add a label" />
  </div>
  <small>Press Enter or comma to add. Backspace removes the last.</small>
</div>

A limit, and a change event

No tags yet. 
<div class="tag-input" id="ti2" role="group" aria-label="Recipients" data-max="3" data-name="to">
  <input type="text" placeholder="Up to 3 emails" />
</div>
<small id="ti2-out" aria-live="polite">No tags yet.</small>
<script>
  document.getElementById("ti2").addEventListener("tsunami:tagschange", (e) => {
    document.getElementById("ti2-out").textContent = e.detail.value.length + " of 3: " + e.detail.value.join(", ");
  });
</script>

Invalid and disabled

<div class="tag-input" role="group" aria-label="Locked tags" data-value="read,only" data-disabled></div>

Behavior

  • Enter or comma adds the typed text as a tag. Enter never submits the form from this box.
  • Backspace in the empty box removes the last tag. The remove button on a tag does the same for that tag.
  • A paste with commas or new lines is split into tags. A paste of one plain word goes into the box as usual.
  • Leaving the box with text in it adds that text as a tag.
  • A tag that is already there is ignored, and nothing is added past data-max.
  • The text box is added if the markup has none. Add your own when a label needs an id to point at.
  • The hidden input named by data-name holds the tags joined with commas. A form reset restores the start tags.

API

.tag-input is started on load, and so is one added to the page later.

Methods

MethodDescription
tsunami.tagInput.mount(root?)Starts every .tag-input inside root (default: the document) that is not started yet.
tsunami.tagInput.value(el)The tags as an array of strings.
tsunami.tagInput.set(el, list)Replaces the tags. Duplicates are dropped and data-max applies.
tsunami.tagInput.clear(el)Removes every tag.

Events

EventOnDescription
tsunami:tagschangethe .tag-input, bubblesSent when a tag is added or removed. event.detail.value is the array of tags.
